# Summaries Directory — Agent Guidelines

> **Context**: LLM-Generated Content

## Purpose

This directory stores **automated summaries** of course content. Files here are typically generated by scripts, not written by hand.

## Rules for Agents

1. **Do Not Manually Edit**: These files are regenerateable artifacts. Manual edits may be lost if the summary script is re-run.
2. **Source of Truth**: The source of truth is always the `course_development/` directory. If a summary is inaccurate, fix the source module content, not the summary file.
3. **Naming Convention**:
   - `[course_id]_summary.md` (e.g., `ai-philosophy_summary.md`)

## Generation Protocol

When asked to generate a summary:

1. Use the `software/scripts/summarize_courses.py` script if available.
2. If manually summarizing (e.g., for a new course not yet supported by script), follow the standard format:
   - **Title**: Course Name
   - **Overview**: 1 paragraph
   - **Key Topics**: Bullet points
   - **Target Audience**: Who is this for?
   - **Prerequisites**: What is needed?

*Minimize surprise. Maximize evidence.*
