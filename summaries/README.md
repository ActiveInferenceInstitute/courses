# Course Summaries

> **Active Inference Institute** | AI Generated Summaries

This directory contains high-level summaries of course content, generated by LLMs to provide quick overviews of the curriculum.

## Contents

- `*_summary.md`: One-page summaries of specific courses.

## Generation

These summaries are typically generated using the `software/scripts/summarize_courses.py` script.

```bash
uv run python software/scripts/summarize_courses.py --course ai-philosophy
```

## Usage

Use these summaries for:

- Quick review of course scope
- Marketing materials
- Syllabus planning
- Onboarding new contributors
