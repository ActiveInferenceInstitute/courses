## 学習目標

このモジュールを完了すると、以下のことができるようになるはずです。

1. 能動的推論における哲学的な観点から**コミュニケーション**を定義する。
2. FEP フレームワークにおける**相互主観**の役割を説明する。
3. コミュニケーションを、フリーエネルギー最小化のより広範な概念に結びつける。
4. 実際のコミュニケーションの例を分析するために、哲学的な推論を適用する。
