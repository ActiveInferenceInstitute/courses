## 学習目標

このモジュールを完了するまでに、あなたは以下のことができるようになるはずです。

1. 積極的推論の視点から**知覚**を定義する
2. FEP フレームワークにおける**直接知覚**の役割を説明する
3. 知覚をより広範な自由エネルギー最小化の概念と関連付ける
4. 実際の知覚の例を分析するために、哲学的な推論を適用する
