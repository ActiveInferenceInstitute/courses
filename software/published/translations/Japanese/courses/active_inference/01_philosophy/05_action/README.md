## 学習目標

このモジュールを完了するまでに、あなたは以下のことができるようになるはずです：

1. 積極的推論における哲学的な視点から **行動** を定義する。
2. FEP フレームワークにおける **主体性としての推論** の役割を説明する。
3. 行動とより広い概念であるフリーエネルギー最小化との関連付けを行う。
4. 現実世界の行動の例を分析するために哲学的な推論を適用する。
