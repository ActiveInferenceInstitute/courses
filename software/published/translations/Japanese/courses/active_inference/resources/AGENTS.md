## 概要

このディレクトリには、Active Inference の**公式リソース**が含まれています。このファイル (`notation_table.md`, `glossary.md`, `references.md`, `cross_course_map.md`) は、32 のモジュール全体の**唯一の情報源**として機能します。

## リソースに関する重要なルール

1.  **唯一の情報源**: モジュール内で記号や用語をローカルで定義しないでください。ここでは定義し、参照してください。
2.  **一貫性**: ここに変更を加えると、すべての 4 つのコースに影響します。`notation_table.md` または `glossary.md` を変更する前に影響を確認してください。
3.  **完全性**: モジュールで新しい用語または記号が使用された場合、**必ず**ここで追加してください。

## ファイルの責任

| ファイル | 責任 |
| ------ | ---------------- |
| `README.md` | リソースディレクトリの概要と使用方法のガイド |
| `notation_table.md` | すべての数学的記号 (`F`, `G`, `A`, `B`, など) を定義 |
| `glossary.md` | 記号ブラケット、知識的価値、など、すべての技術用語を定義 |
| `references.md` | 82+ の公式引用をリストアップ |
| `cross_course_map.md` | 4 つの分野にわたる 8 つのトピックをマッピング |
| `learning_pathways.md` | 学生を背景に基づいてカリキュラムをガイド |
| `faq.md` | Active Inference とこのカリキュラムに関する一般的な質問 |

一般的なコンテンツ生成ガイドラインについては、[ルート エージェント ガイドライン](../AGENTS.md) を参照してください。
