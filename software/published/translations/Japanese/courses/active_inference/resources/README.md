## これらのリソースの使用方法

### コンテンツ作成者向け

カリキュラムファイル（モジュール講義、質問、クイズ、ラボ、ダッシュボード）を作成または編集する場合：

1.  **記号**: [記号表](./notation_table.md)で定義されているとおりに記号を使用してください。 独自の記号を導入しないでください。
2.  **用語**: [用語集](./glossary.md)から推奨される用語を使用してください。ルートの[エージェントガイドライン](../AGENTS.md)で「避ける」列を確認し、非公式な同義語を使用する前に確認してください。
3.  **参考文献**: 可能であれば、[参考文献](./references.md)を使用してください。 新しいソースが必要な場合は、まず references.md に追加してから引用してください。
4.  **クロスリンク**: [コース間マップ](./cross_course_map.md)を使用して、コース間で並行するモジュールを見つけてリンクします。

### エージェント向け

エージェントは、コンテンツを生成または大幅に編集する前に、すべての4つのリソースファイルを**読み取る必要があります**。 これらのリソースは、32モジュール、4コースのカリキュラム全体で一貫性を保証します。

### 学生向け

これらのリソースは、学習中のクイックリファレンスツールとして使用できます：

-   **記号表**を、不明な記号に遭遇したときに使用してください
-   **用語集**を、新しい用語に遭遇したときに使用してください
-   **参考文献**を使用して、各概念の背後にある元の論文を見つけてください
-   **コース間マップ**を使用して、同じトピックが異なる学問分野の視点からどのように見えるかを確認してください

## メンテナンス

| 行動 | いつ | 方法 |
|---|---|---|
| 新しい用語を追加 | コンセプトを用語集に導入するとき | [用語集](./glossary.md)にアルファベット順に追加 |
| 新しい記号を追加 | モジュールでテーブルにない記号を使用するとき | 適切なセクションにある [記号表](./notation_table.md)に追加 |
| 新しい参考文献を追加 | references.mdにない論文を引用するとき | 適切なモジュールヘッダーの下にある [参考文献](./references.md)に追加 |
| コース間マップを更新 | モジュールタイトルまたは焦点の説明が変更されたとき | [コース間マップ](./cross_course_map.md)を更新 |
