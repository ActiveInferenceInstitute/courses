## アクティブインファーレンスについて

### アクティブインファーレンスとは？

アクティブインファーレンスは、生物が *期待されるフリーエネルギー* を最小化するように行動することで、知覚、行動、学習、計画を単一の動機の下で統合するフレームワークです。これは、フリーエネルギー原則 (FEP) の副産物であり、非平衡状態での自律組織化システムが、変分フリーエネルギーを最小化することで記述できるというものです。

**始めるには**: [哲学モジュール 1](../01_philosophy/01_systems/module.md) (概念的) または [数学モジュール 3](../03_math/03_perception/module.md) (形式的)。

### アクティブインファーレンスは、強化学習とどのように異なりますか？

| 側面 | アクティブインファーレンス | 強化学習 |
|---|---|---|
| 目的 | 期待されるフリーエネルギーを最小化する | 期待される報酬を最大化する |
| 探索 | 本質的なもの (EFE の知識的価値) | 外的なもの (ε-greedy、UCB など) |
| モデル | 生成モデル (必要) | モデルフリーまたはモデルベース |
| 知覚 | 知覚と行動を統合 | 行動とは分離 |

**詳細な扱い**: [CS モジュール 5](../04_computer_science/05_action/module.md)、参考文献 #74 (Sajid et al., 2021)。

### ダークルーム問題とは？

生物が驚きを最小化するように行動すると仮定した場合、予測可能な環境を求めるだろうという問題。アクティブインファーレンスは、*Cベクター* (嗜好) を通じてこれを解決します。生物は、占有するべき状態に関する事前期待を持ち、暗い部屋はそれらの期待に反します。

**詳細な議論**: [哲学モジュール 4](../01_philosophy/04_cognition/module.md)、[用語集：ダークルーム問題](./glossary.md)。

## 本コースについて

### 必要な数学は？

- **コース 1 (哲学)**: 数学は必要ありません - 概念は文章で提示されます
- **コース 2 (認知科学)**: 確率と統計に関する基本的な知識があると役立ちます
- **コース 3 (数学)**: 微分積分学、基本的な線形代数、確率論。モジュール 1-2 が前提条件をレビューします
- **コース 4 (コンピュータサイエンス)**: NumPy を使用した Python プログラミング、基本的なオブジェクト指向プログラミング

### コースをスキップできますか？

コースは、哲学 → 認知科学 → 数学 → CS の順に進めるように設計されていますが、あなたのバックグラウンドに基づいて、[学習パス](./learning_pathways.md) で提案されている代替ルートを確認してください。重要な依存関係:

- 数学コースは、コース 1-2 からの哲学と認知科学の文脈を必要とします
- CS コースは、コース 3 からの数学的導出を必要とします
- 各コースは、単独の学問分野の視点から独立して研究できますが、コース間のつながりは失われます

### コースの所要時間は？

各コースは 8 週間 (1 週間あたり 1 モジュール) で設計されています。完全な 4 コースのシリーズは約 32 週間かかります。強力なバックグラウンドを持つ学生は、馴染みのある素材をより速く完了できます。

4 つのコースはすべて、共通のリソースを参照しています。

## 概念的な質問

### マルコフブランケットとは？

内部状態を *条件付き独立* にする状態のセット。これはシステム境界の概念を形式化し、物理的な壁ではなく統計的な分離として捉えます。 [用語集](./glossary.md)、[哲学モジュール 1](../01_philosophy/01_systems/module.md)、[数学モジュール 1](../03_math/01_systems/module.md) を参照してください。

### 変分フリーエネルギーとは？

驚異の上限 (モデルの負の対数確率): `F = E_q[ln q(s) - ln p(o,s)]`。信念に関して VFE を最小化 = 知覚; パラメータに関して最小化 = 学習。 [記号表](./notation_table.md)、[数学モジュール 3](../03_math/03_perception/module.md) を参照してください。

### 期待されるフリーエネルギーとは？

将来のポリシーの下でのフリーエネルギーの期待値です。リスク (実用的な価値) と曖昧さ (知識的価値) に分解されます。これは行動選択を駆動します。 [数学モジュール 5](../03_math/05_action/module.md)、[CS モジュール 5](../04_computer_science/05_action/module.md) を参照してください。

### A, B, C, D, E 行列とは？

状態空間の生成モデルの構成要素:

| 行列 | 名前 | 役割 |
|---|---|---|
| **A** | 確率 | 隠れた状態を観測にマッピングします |
| **B** | 遷移 | 行動の下での状態遷移 |
| **C** | 嗜好 | 観測に関する事前嗜好の対数 |
| **D** | 事前 | 初期状態に関する事前信念 |
| **E** | 習慣 | ポリシーに関する事前 |

[記号表](./notation_table.md)、[CS モジュール 2](../04_computer_science/02_agents/module.md) を参照してください。
