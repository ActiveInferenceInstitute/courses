# 学習パス (Gakushū Pasu) - Learning Pathways

> **クイックナビゲーション**: [カリキュラムホームページ](../README.md) | [記法表](./notation_table.md) | [用語集](./glossary.md) | [参考文献](./references.md) | [コース間マップ](./cross_course_map.md)

背景と目標に基づいて、アクティブ・インフュージョン (Active Inference) のカリキュラムを通る推奨される経路。このカリキュラムは、4つのコース × 8つのモジュールで構成され、すべて同じ8つのトピックを異なる学問分野の視点からカバーしています。

---

## 前提条件の連鎖 (Zen'ite Genjō no Rensha)

```text
コース 1: 哲学 ──→ コース 2: 認知科学 ──→ コース 3: 数学 ──→ コース 4: コンピュータサイエンス
                                                              ↑                           ↑
                                                              │                           │
                                                       計算機を必要とする、          Python、
                                                       線形代数の基礎                     NumPy、基本的なOOP
```

コースは順番に進めるように設計されています。各コースは、前のコースで導入された概念に基づいて構築されています。

## モジュール依存グラフ (Mōjūru Iizō Gurafu)

各コース内で、モジュールは互いに依存しています:

```text
M1: システム ──→ M2: エージェント ──→ M3: 認識 ──→ M4: 認知
                                                        │
                                                        ↓
                M8: 計画 ←── M7: コミュニケーション ←── M6: 学習 ←── M5: 行動
```

- **M1-M2**: 基礎 — システムとは何か、エージェントとは何か
- **M3-M4**: 認識と認知 — エージェントが世界をモデル化する方法
- **M5-M6**: 行動と学習 — エージェントが行動し、適応する方法
- **M7-M8**: コミュニケーションと計画 — 多様なエージェントと時間的拡張

## コース間深掘 (Kōsu Kan Fuboreru)

単一のトピックについて深く理解するためには、4つのコースすべてで対応するモジュールを研究してください:

| トピック (Topyuku) | パスウェイ (Pasuwē) | キーとなる洞察 (Kii to naru Domutsū) |
|-------|---------|-------------|
| 認識 (Ninchaku) | Phil M3 → CogSci M3 → Math M3 → CS M3 | 「認識とは何か」から信念更新の実装まで |
| 行動 (Gōdō) | Phil M5 → CogSci M5 → Math M5 → CS M5 | 把握可能性から EFE 計算まで |
| 学習 (Gakushū) | Phil M6 → CogSci M6 → Math M6 → CS M6 | 認識的成長からディレクトリ更新まで |
| 計画 (Keikaku) | Phil M8 → CogSci M8 → Math M8 → CS M8 | 目的論から深層時間モデルまで |

[コース間マップ](./cross_course_map.md) で、すべての8つのコース間のパスの詳細を確認してください。
