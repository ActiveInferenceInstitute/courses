## 学習目標

このモジュールを完了するまでに、あなたは以下のことができるようになるはずです：

1. 積極的推論における認知行動学的な観点から「行動」を定義する
2. FEPフレームワークにおける「運動制御を積極的推論」、「習慣と目標」の役割を説明する
3. 行動を、より広い概念であるフリーエネルギー最小化に結び付ける
4. 現実世界の行動の例を分析するために、認知行動学的な推論を適用する
