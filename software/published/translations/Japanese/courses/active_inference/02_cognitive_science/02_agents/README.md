## 学習目標

このモジュールを完了するまでに、あなたは以下のことができるようになるはずです：

1. 能動的推論における認知行動科学的な視点から **エージェント** を定義する。
2. FEP フレームワークにおける **自己モデル** の役割を説明する。
3. エージェントを、自由エネルギー最小化のより広範な概念と関連付ける。
4. 実際の事例を分析するために、認知行動科学的な推論を適用する。
