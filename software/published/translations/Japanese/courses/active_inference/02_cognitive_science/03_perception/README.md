## 学習目標

このモジュールを完了するまでに、あなたは以下のことができるようになるはずです：

1. 能動的推論における認知行動学的な視点から**知覚**を定義する。
2. FEPフレームワークにおける**予測符号化**の役割を説明する。
3. 知覚を、フリーエネルギー最小化のより広範な概念と関連付ける。
4. 認知行動学的な推論を適用して、知覚の実際の事例を分析する。
