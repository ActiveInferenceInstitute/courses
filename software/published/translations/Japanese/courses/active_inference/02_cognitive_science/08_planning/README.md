## 学習目標

このモジュール終了までに、あなたは以下のことができるようになるはずです：

1.  アクティブ・インファーレンスにおける認知行動的観点から「計画」を定義する。
2.  FEPフレームワークにおける「実行機能と不確実性下での意思決定」の役割を説明する。
3.  計画をより広い概念であるフリーエネルギー最小化に結び付ける。
4.  現実世界の計画の例を分析するために認知行動的推論を適用する。
