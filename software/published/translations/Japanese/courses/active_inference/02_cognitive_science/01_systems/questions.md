# システムに関する学習問題

1.  皮質カラムとは何であり、アクティブ・インファーレンス（Active Inference）の枠組みの中で、局所的な推論エンジンとしてどのように理解できるか？
2.  海馬の階層的な組織について説明してください。この階層は、生成モデルの深さにどのように対応しているのでしょうか？
3.  脳のマルコフ・ブランケットとは何ですか？それは頭蓋骨ではなく、身体の感覚運動面でなぜ構成されているのでしょうか？
4.  脳-身体-環境のループを、アクティブ・インファーレンスの知覚-行動サイクルにおける物理的な実装として説明してください。
5.  フリーストン（2005年）が休息状態の脳活動について示したことは何ですか？それは生成モデルの概念とどのように関連していますか？
6.  このモジュールで議論されている3つの主要な休息状態ネットワークの名前を挙げてください。それぞれのネットワークは、脳の生成モデルにおいてどのような役割を果たす可能性がありますか？
7.  デフォルト・モード・ネットワーク（DMN）は、エージェントの自己モデルをどのようにエンコードするのでしょうか？この解釈を支持する証拠は何ですか？
8.  注意ネットワークの提案された役割は何か、そして精密重み付けにおける前頭葉島（anterior insula）の貢献は？
9.  予測誤差の概念は、神経レベルでどのように現れるのでしょうか？候補となる神経信号は何ですか？
10. 皮質階層において、「トップダウン」の予測誤差と「ボトムアップ」の予測を比較してください。それぞれの皮質層と関連付けられていますか？
11. アノソグノーシアとは何ですか、そしてアクティブ・インファーレンスは、生成モデルの更新の失敗としてそれをどのように説明するのでしょうか？
12. 自己モデルの予測における低精度として、脱個人化をどのように理解できるのでしょうか？
13. 休息状態の活動が、アクティブ・インファーレンスの予測に基づいているのか、単なる神経的ノイズなのかをテストするために使用できる実験パラダイムは？
14. 感覚皮質（V1, A1, S1）と、生成モデル階層における関連皮質との間で、どのような違いがありますか？
15. 立血皮質ループは、脳の階層的推論の実現においてどのような役割を果たしていますか？
16. エデルマンの神経ダーウィン主義の概念は、皮質集積体の自己組織化の性質とどのように関連していますか？
17. 神経振動周波数（アルファ波、ベータ波、ガンマ波）と生成モデルの時間スケール階層との間にはどのような関係がありますか？
18. 脳の代謝予算（身体エネルギーの約20％を消費し、身体質量のごくわずか2％で維持される）が、生成モデルを維持するための計算上の要求をどのように反映しているのでしょうか？
19. アクティブ・インファーレンスの休息状態活動の説明を、レイチレ（2001年）の「デフォルト・モード」解釈と比較してください。それらは互換性がありますか？
20. アクティブ・インファーレンスの特定の予測に関する神経的自己組織化をテストする仮説的なfMRI研究を設計してください。
