## 学習目標

このモジュールを修了することで、あなたは以下ができるようになるはずです。

1. 能動的推論における認知行動科学的な視点から「システム」を定義する。
2. FEPフレームワークにおける「神経集団と機能統合」の役割を説明する。
3. システムをより広い概念である「フリーエネルギー最小化」に結びつける。
4. 認知行動科学的な推論を用いて、実際のシステムの例を分析する。
