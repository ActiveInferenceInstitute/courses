## 学習目標

このモジュールを完了するまでに、あなたは以下のことができるようになるはずです：

1. 活性推論における計算的な視点から**行動**を定義する
2. FEP フレームワークにおける**ポリシー選択と期待自由エネルギー計算**の役割を説明する
3. 行動をより広い概念である自由エネルギー最小化に結び付ける
4. 現実世界の行動の例を分析するために計算的な推論を適用する
