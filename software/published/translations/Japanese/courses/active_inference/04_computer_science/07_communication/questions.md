# コミュニケーションに関する質問

1.  単一エージェントのActive Inferenceループをマルチエージェント環境に拡張する場合、どのように拡張しますか？ どのような変化があり、何が同じですか？

2.  シグナリングゲームにおいて、送信者のA行列と受信者のA行列とは何か、それらはなぜ異なりますか？

3.  相互情報量 $I(X; Y)$ をエントロピーの用語で定義してください。 $I = 0$ がコミュニケーションに何を意味しますか？ $I = H(\text{state})$ が何を意味しますか？

4.  `mutual_information()` を使用して、信号シーケンスと状態シーケンス間の相互情報量を計算するコードを記述してください。

5.  シグナリングゲームにおいて、送信者のCベクトルとは何か、受信者のCベクトルとは何か、なぜ同じ報酬構造を共有しますか？

6.  受信者がどの信号がどのワールド状態に対応するかをどのように学習しますか？ どのようなDirichlet更新が関与しますか？

7.  送信者がワールド状態に関係なく常に信号0を生成する場合、相互情報量はいくつになりますか？ なぜこれは非最適ですか？

8.  MI計算のために、観測された (信号、状態) ペアから共同分布行列を構築するにはどうすればよいですか？

9.  マルチエージェントシミュレーションにおけるB行列の役割は何ですか？ 各エージェントはそれぞれBを必要としますか、それとも共有できますか？

10. Active Inferenceにおける「ハードコーディングされたコミュニケーション」(事前プログラミングされた信号) と「出現的なコミュニケーション」の違いを説明してください。

11. シグナリングゲームに3番目のエージェント (盗聴者) を追加するにはどうすればよいですか？ そのA行列はどのようなものになりますか？

12. 学習なし (固定 pA, pB) でシグナリングゲームを実行した場合、相互情報量はどうなりますか？ なぜですか？

13. MI計算のために、3信号、3状態のシグナリングゲームを設計してください。送信者と受信者のA行列とCベクトルを定義してください。

14. 送信者の精度 γ がコミュニケーションの品質にどのように影響しますか？ γが非常に低い場合、どうなりますか？

15. 2エージェントが50ステップで交互に送信および受信するマルチエージェントループ用のコードを記述してください。

16. 計算機用語における「理論の心」とは何ですか？ エージェントは、その生成モデル内で他のエージェントの信念をモデル化できますか？

17. エージェントが異なるCベクトル (対立する好み) を持っている場合、コミュニケーションは出現しない可能性があります。EFEフレームワークを使用して説明してください。

18. `plot_learning_progress()` をマルチエージェントのコンテキストで使用して、両エージェントの学習曲線を示すにはどうすればよいですか？

19. 2状態システムにおける信号と状態間の最大相互情報量はいくつですか？ これはいつ達成されますか？

20. 明示的な信号ではなく、行動の観察を通じてコミュニケーションが生まれるシナリオを記述してください。エージェントは行動から意図を推論します。
