## 学習目標

このモジュールを完了するまでに、あなたは以下のことができるようになるはずです：

1.  活性推論における計算的な視点から「学習」を定義する
2.  FEPフレームワークにおける「パラメータ更新：経験からAとB行列を学習する」の役割を説明する
3.  フリーエネルギー最小化のより広範な概念と学習を結びつける
4.  実際の学習の例を分析するために計算的な推論を適用する
