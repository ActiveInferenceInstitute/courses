## 学習目標

このモジュールを完了すると、以下のことができるようになるはずです。

1. 活性推論における計算的な視点から **システム** を定義する
2. FEP フレームワークにおける **環境のセットアップ: 生成的プロセス vs 生成的モデル** の役割を説明する
3. システムをより広い概念であるフリーエネルギー最小化に結びつける
4. 実際のシステムに関する例を分析するために計算的な推論を適用する
