## 学習目標

このモジュールを完了するまでに、あなたは以下のことができるようになるはずです：

1.  活性推論における計算的な視点から**認識**を定義する
2.  FEPフレームワークにおける**A行列とB行列：尤度**の役割を説明する
3.  認識をより広い概念であるフリーエネルギー最小化と関連付ける
4.  現実世界の認識の例を分析するために計算的な推論を適用する
