# モジュール05：行動 — 積極的推論、期待される自由エネルギー、およびPOMDPフレームワーク

## 学習目標

1.  **行動方程式**を導出する：感覚状態の変化によって自由エネルギーを最小化する方法。
2.  **期待される自由エネルギー (EFE)** 関数G(π)を定義し、認識的および実践的成分に分解する。
3.  **POMDP** (部分観測マルコフ決定過程) フレームワークを、積極的推論におけるポリシー選択に適用する。

## 導入

積極的推論における行動は、報酬最大化のような別個の最適化原理に従うわけではない。代わりに、行動は感覚と同様の目的を果たし、自由エネルギーを最小化する。しかし、感覚は信念（内部状態）を更新するのに対し、行動は世界（ベール状態）を変化させる。このモジュールでは、行動選択の数学的基礎を導き出し、期待される自由エネルギー関数を導入する。

## 主要な概念

### 1. 行動方程式

自由エネルギーFは、感覚状態sに依存し、感覚状態は行動aに依存する：

**a* = argmin_a F(s(a), μ)**

連続系の場合、行動は勾配降下に従う：

**da/dt = -∂F/∂a = -∂F/∂s · ∂s/∂a**

最初の因子（∂F/∂s）は、感覚レベルでの予測誤差を表す。2番目の因子（∂s/∂a）は、センサーモータマッピングを表す。これら2つが組み合わさることで、感覚の予測を満たすように行動を駆動し、もし脳が腕が*ここに*あると予測すれば、行動は腕を動かしてその予測を現実のものにする。

### 2. 期待される自由エネルギー

離散時間におけるポリシーπ = (a₁, a₂, ..., aT)に対する期待される自由エネルギーG(π)は、次のように評価される：

**G(π) = ∑ₜ E_{q(oₜ,sₜ|π)}[ln q(sₜ|π) - ln p(oₜ, sₜ)]**

これは次のように分解される：

**G(π) = -∑ₜ E_q[ln p(oₜ)] + ∑ₜ E_q[H[p(oₜ|sₜ)]]**

ここで：

- **-E_q[ln p(oₜ)]** は**実践的価値**であり、期待される結果に対する好みの事前確率（結果の整合性がどの程度高いか）を表す。
- **E_q[H[p(oₜ|sₜ)]]** は**認識的価値**であり、隠れた状態に関する期待される曖昧さ（ポリシーが隠れた状態に関する情報量どれだけ提供するか）を表す。

あるいは：

**G(π) = ∑ₜ {-E_q[D_KL[q(sₜ|oₜ,π) ‖ q(sₜ|π)]] + E_q[-ln p(oₜ)]}**

ここで最初の項は**情報収益**（負の）であり、状態に関する不確実性を解消するポリシーが好まれる。

### 3. ソフトマックス関数によるポリシー選択

ポリシーは、期待される自由エネルギーの負のソフトマックス関数に基づいて選択される：

**P(π) = σ(-γ · G(π))**

ここでγは、ポリシー選択の精度を制御する**逆温度パラメータ**である。高いγ → 最適なポリシーを決定論的に選択する；低いγ → よりランダム（探索的）な選択をする。

### 4. POMDPフレームワーク

離散時間における積極的推論は、POMDP内で実装される：

- **A**行列：p(oₜ | sₜ) — 尤度マッピング
- **B**行列：p(sₜ | sₜ₋₁, aₜ₋₁) — 以前の行動に基づく状態遷移ダイナミクス
- **C**ベクトル：ln p(oₜ) — 結果に対する事前確率
- **D**ベクトル：p(s₁) — 初期状態の事前分布

エージェントは、このモデルを逆転用して隠れた状態を推論し、期待される自由エネルギーを最小化するポリシーを選択する。

## 導出演習

1.  線形センサーモータマッピングを持つ連続系の場合、da/dt = -∂F/∂a の行動方程式を導出する。
2.  G(π) = ∑ₜ E_q[ln q(sₜ|π) - ln p(oₜ, sₜ)] から、実践的-認識的分解を導出する。
3.  情報収益を最大化することは、期待される曖昧さを最小化することと同等であることを示す。

## 結論

行動と感覚は、どちらも（期待される）自由エネルギーを最小化するという点で、同じコインの2つの側面である。EFE分解は、知的行動が自然に、利用（実践的価値）と探索（認識的価値）のバランスを取ることを明らかにする。モジュール06では、この数学的基礎を学習の数学に拡張する。
