# Lab: Derivation Exercise — 期待されるフリーエネルギーとポリシー選択

## 目的

期待されるフリーエネルギー関数とその分解を導出し、それを具体的なPOMDPに適用してポリシー値を計算します。

## 第1部：連続アクション

**目標**: 連続システムにおけるアクション方程式を導出する。

**モデル**: 感覚状態 s はアクション a を通じて s = h(a) + ω によって依存する (例: h(a) = a は直接的なモーター制御の場合)。フリーエネルギー F = ½π(s - g(μ))²

**タスク**:

1. 鎖則を用いて ∂F/∂a を計算する: ∂F/∂a = ∂F/∂s · ∂s/∂a
2. da/dt = -∂F/∂a が s を g(μ) に向かわせることを示す - アクションは感覚予測を満たす
3. 意味を解釈する: アクションはセンサーモーターマッピングを通して「予測が実現される」ことを行う

## 第2部：EFE分解

**目標**: G の経験的-知識的分解を導出する。

以下の式から始める: **G(π) = E_{q(oₜ,sₜ|π)}[ln q(sₜ|π) - ln p(oₜ, sₜ)]**

**タスク**:

1. p(oₜ, sₜ) = p(oₜ|sₜ) · p(sₜ) を生成モデルを用いて展開する
2. E_q[ln q(sₜ|oₜ, π)] を加えて、引き算する
3. G が以下の分解になることを示す:
   - **情報利得**: -E_q[D_KL[q(sₜ|oₜ,π) ‖ q(sₜ|π)]] (知識的価値)
   - **実用的価値**: E_q[-ln p(oₜ)] (結果が好みにどれだけ乖離しているか)
4. 情報利得が常に負である理由を説明する (ポリシーは常に非負の知識的価値を持つ)

## 第3部：具体的なPOMDP計算

**目標**: EFEを簡単なPOMDPに対して計算する。

以下のT-maze POMDPを検討する：

- 4つの状態: {左-報酬、右-報酬、左-報酬なし、右-報酬なし}
- 4つの観測: {報酬、報酬なし、左のヒュー、右のヒュー}
- 2つのアクション: {左に進む、右に進む}
- 好み: C = [ln 2, ln(1/2), 0, 0] (報酬を好む、報酬なしを避ける、ヒューは中立)

以下のA行列（確率）：

```
A = [0.9  0.1  0.5  0.5;
     0.1  0.9  0.5  0.5;
     0.5  0.5  0.8  0.2;
     0.5  0.5  0.2  0.8]
```

**タスク**:

1. ポリシーπ₁ = 左に進む、状態信念q(s) = [0.5, 0.5, 0, 0] の場合、期待される観測 E_q[p(o|s)] を計算する
2. 好みベクトルCを用いて、実用的価値 E_q[-ln p(o)] を計算する
3. 期待される情報利得を計算する
4. どちらのポリシー (左に進む vs 右に進む) がより低いEFEを持つかを決定する
