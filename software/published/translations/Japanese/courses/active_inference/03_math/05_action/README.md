## 学習目標

このモジュールを完了する時点で、あなたは以下のことができるようになるはずです：

1.  第一原理から、期待される自由エネルギー `G(π) = リスク + 不確実性` の分解を導出する。
2.  ソフトマックスポリシー選択 `P(π) = σ(-γG(π))` を計算し、精度 `γ` が探索と利用のトレードオフに与える影響を分析する。
3.  実用的な価値（リスク：好ましい結果からの逸脱）と認識的な価値（不確実性：期待される観察エントロピー）を区別する。
4.  EFEフレームワークをTマズと2本腕バンディットに適用し、競合するポリシーに対して `G(π)` を計算する。
