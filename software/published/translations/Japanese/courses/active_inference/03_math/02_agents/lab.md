# Lab: Derivation Exercise — 生成モデルと変分推論

## 目的

具体的な生成モデルに対して、変分推論の更新方程式を導出し、抽象的な数学を明示的な計算に結びつける。

## 第1部: 隠れマルコフモデルの仕様

**目標**: 完全な生成モデルを記述する。

隠れマルコフモデルを考慮し、以下の要素を持つものとする：

- K = 3 の隠れ状態 (s ∈ {1, 2, 3})
- 観測モデル: p(oₜ | sₜ = k) = N(oₜ; μₖ, σₖ²)  （既知のパラメータを持つ）
- 遷移モデル: p(sₜ | sₜ₋₁) が 3×3 行列 **A** で与えられ、各行の和が 1
- 先験: p(s₁) = カテゴリ分布で、確率 [0.5, 0.3, 0.2]

**課題**: T = 3 の時間ステップに対する共役分布 p(o₁:T, s₁:T) を記述する。積の記号を完全に展開する。

## 第2部: HMM の変分自由エネルギー

**目標**: このモデルの自由エネルギーを導出する。

q(s₁:T) = ∏ₜ q(sₜ) は、各 q(sₜ) がパラメータ (確率) rₜ = [rₜ₁, rₜ₂, rₜ₃] で与えられるカテゴリ分布である、平均場認識密度であるとする。

**課題**: 次の変分自由エネルギーを記述する：

F = E_q[ln q(s₁:T)] - E_q[ln p(o₁:T, s₁:T)]

各項を展開する。最初の項は q の負のエントロピーである。2番目の項は、対尤度と対遷移確率を含む。

## 第3部: 最適な更新方程式

**目標**: 十分な統計量の固定点方程式を導出する。

∂F/∂rₜₖ = 0 (制約 ∑ₖ rₜₖ = 1) を用いて、最適な q*(sₜ) を導出する：

**ln q*(sₜ = k) ∝ ln p(oₜ | sₜ = k) + E_{q(sₜ₋₁)}[ln p(sₜ = k | sₜ₋₁)] + E_{q(sₜ₊₁)}[ln p(sₜ₊₁ | sₜ = k)]**

すべてのステップを示す。更新が過去 (sₜ₋₁) と未来 (sₜ₊₁) のメッセージに依存することを示す。

## 第4部: ガウス状態空間モデル

**目標**: 連続モデルに対して導出を繰り返す。

線形ガウス状態空間モデルを考慮する：

- p(sₜ | sₜ₋₁) = N(sₜ; A·sₜ₋₁, Q)  — 状態ダイナミクス
- p(oₜ | sₜ) = N(oₜ; C·sₜ, R)  — 観測モデル
- p(s₁) = N(s₁; μ₀, Σ₀)  — 先験

認識密度 q(sₜ) = N(sₜ; mₜ, Vₜ) で与えられるものとする。

**課題**: F を最小化することにより、十分な統計量 mₜ (平均) と Vₜ (共分散) の更新方程式を導出する。これらの式がカルマンフィルタ/スムーサーの式に対応することを示す。
