# モジュール 02: エージェント — 生成モデル、十分統計量、および自由エネルギー原理

## 学習目標

1. 生成モデルを、共役確率分布 p(o, s, θ) として形式的に定義し、認識密度 q(s, θ) と区別する。
2. 認識密度の十分統計量を導出し、それがエージェントの信念をパラメータ化する方法を説明する。
3. 自由エネルギー原理を正確に記述する：内部状態が、自由エネルギーを最小化する認識密度をパラメータ化する。

## 導入

アクティブインファレンス（Active Inference）の枠組みにおいて、エージェントとは、内部状態が隠れた状態に関する確率分布（信念をエンコードした）をパラメータ化することを解釈できるシステムである。このモジュールは、生成モデル、十分統計量、および自由エネルギー原理の数学的枠組みを通じて、システムが「エージェント」であるという概念を形式化する。

## 主要な概念

### 1. 生成モデル

生成モデルは、隠れた原因から観測が生成される方法を指定する：

**p(o₁:T, s₁:T, θ) = p(θ) ∏ₜ p(oₜ | sₜ, θ) · p(sₜ | sₜ₋₁, θ)**

ここで：

- **o₁:T** は時間経過とともに観測されるデータ
- **s₁:T** は隠れた状態（観測の原因）
- **θ** はパラメータ（環境の固定された特性）
- **p(oₜ | sₜ, θ)** は尤度（状態が観測を生成する方法）
- **p(sₜ | sₜ₋₁, θ)** は状態の遷移確率（状態の進化方法）
- **p(θ)** はパラメータの事前確率

行動を追加することで、これは部分的に観測されたマルコフ決定過程（POMDP）となる。

### 2. 認識密度と十分統計量

正確なベイズ推論 p(s, θ | o) は、ほとんどのモデルで intractable であるため、エージェントは近似事後分布である認識密度 q(s, θ) を維持する：

**q(s, θ) ≈ p(s, θ | o)**

平均場近似の下では、この因子化される：

**q(s, θ) = q(s) · q(θ)**

指数族分布の場合、q は十分統計量によって完全に指定される。例えば、q(s) = N(s; μ, Σ) のガウス分布は、平均 μ と共分散 Σ によってパラメータ化される。これらの十分統計量は、エージェントの内部状態であり、脳（または自己組織化システム）が追跡する必要がある量である。

### 3. 自由エネルギー原理（形式的な記述）

**自由エネルギー原理**: 非平衡定常状態にあるマルコフブランケットを持つ任意のシステムにおいて、内部状態 μ は、変分自由エネルギーを最小化する認識密度 q_μ(η) をパラメータ化することを記述できる：

**μ* = argmin_μ F(s, μ) = argmin_μ E_{qμ}[ln q_μ(η) - ln p(η, s)]**

これは、すべてのシステムが自由エネルギーを *計算* するという主張ではない。それは、マルコフブランケットを持つシステムのダイナミクスが、自由エネルギーを *最小化するように記述される* ということである—物理学と推論の間の形式的な二重性。

## 導出練習

1. K 個の離散状態と D 次元ガウス観測を持つ単純な隠れマルコフモデルの生成モデルを記述する。すべてのパラメータを特定する。
2. ガウスの認識密度 q(s) = N(μ, σ²) に対して、生成モデル p(s) = N(0, 1), p(o|s) = N(s, σ_o²) の場合、自由エネルギー F = E_q[ln q(s)] - E_q[ln p(o, s)] を計算する。
3. 十分統計量 μ と σ² の更新方程式を導出するために、∂F/∂μ = 0 および ∂F/∂σ² = 0 を設定する。

## 結論

エージェントは、生成モデルと認識密度によって定義される。自由エネルギー原理は、自己組織化システムは、自由エネルギーの最小化を通じて近似ベイズ推論を行っていると解釈できることを確立する。モジュール 03 は、これに認識を拡張する。
