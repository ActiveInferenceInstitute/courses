# Lab: Derivation Exercise — Policy Evaluation and Sophisticated Inference

## 目的

多段階ポリシーにおける期待自由エネルギーを導出し、再帰的信念更新と組み合わせた高度な推論を行う。

## 第1部：二段階ポリシー評価

**目標**: シンプルなPOMDPにおけるすべてのポリシーの期待自由エネルギー(EFE)を計算する。

**設定**: 2状態、2観察、2行動、計画期間T=2。

- A行列: [[0.9, 0.1], [0.1, 0.9]]
- B行列: B₁ = [[0.8, 0.2], [0.2, 0.8]] (行動1), B₂ = [[0.3, 0.7], [0.7, 0.3]] (行動2)
- Cベクトル: C = [ln 2, ln(1/2)] (観察1を好む)
- 初期信念: q(s₁) = [0.5, 0.5]

K^T = 2² = 4 のポリシーが存在する: π₁=(a₁,a₁), π₂=(a₁,a₂), π₃=(a₂,a₁), π₄=(a₂,a₂)。

**タスク**:

1. 各ポリシーに対して、q(s₂ | π) = B(π₁) · q(s₁) および q(s₃ | π) = B(π₂) · q(s₂ | π) を計算する。
2. 各タイムステップにおいて、予測された観察 q(o_τ | π) = A · q(s_τ | π) を計算する。
3. 各ポリシーに対して、EFE G(π) = ∑_τ [pragmatic_τ + epistemic_τ] を計算する。
4. 最良のポリシー (最も低いG) を選択する。

## 第2部：高度な推論

**目標**: 第1部を将来の信念更新で拡張する。

**タスク**:

1. 第1部の最良ポリシーに対して、タイムステップ2での出来事をシミュレートする：エージェントはo₂を観測し、ベイズの法則を用いて信念を更新する: q(s₂ | o₂, π) ∝ A(o₂, :) · q(s₂ | π)
2. 各可能な観察 o₂ に対して、更新された信念 q(s₂ | o₂, π) を計算する。
3. これらの更新された信念を用いて、2番目の行動のEFEを評価する。
4. 第1部の基本的なEFEと、高度なEFEを比較する。その違いは何か？

- レベル2 (低速): 2状態 (コンテキスト)、レベル1の初期状態分布と好みを決定

**タスク**:

1. 各レベルの生成モデルを記述する。
