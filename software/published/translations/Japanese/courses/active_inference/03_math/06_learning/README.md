## Learning Objectives

By the end of this module, you should be able to:

1. **Derive** Dirichlet-Categorical conjugacy and the concentration parameter update rule for A- and B-matrices
2. **Prove** that parameter learning is gradient descent on accumulated VFE with respect to model parameters
3. **Formulate** Bayesian Model Reduction (BMR) and compute the log Bayes factor for model comparison
4. **Analyze** how concentration parameters control learning rate and the natural annealing from exploration to exploitation
