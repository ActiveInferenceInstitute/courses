## 学習目標

このモジュールを完了するまでに、あなたは以下のことができるようになるはずです：

1.  **導出**：Dirichlet-Categorical の共役性と、A-およびB行列に対する集中パラメータの更新ルール
2.  **証明**：パラメータ学習が、モデルパラメータに対するVFEの累積における勾配降下であること
3.  **構築**：ベイズモデル削減 (BMR) を定義し、モデル比較のための対数ベイズ因子を計算する
4.  **分析**：集中パラメータが学習率をどのように制御し、探索から活用までの自然な焼きなましをどのように制御するかを分析する
