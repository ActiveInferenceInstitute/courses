# アクティブ推論の数学

> **クイックナビゲーション**: [カリキュラムホーム](../README.md) | [シラバス](./syllabus.md) | [エージェントガイドライン](./AGENTS.md) | [リソース](../resources/)

## 概要

アクティブ推論とフリーエネルギー原則の形式的な数学的基礎を提供します。状態空間の形質化、ランジェーヌダイナミクス、変分推論、KLダイバージェンス、フリーエネルギーの期待値分解、精密行列、ベイズモデル削減、そして高度な推論を扱います。すべての導出は段階的に提示されています。

## 必要な知識

哲学と認知科学のコース1-2。行列（行列、ベクトル）、確率理論（ベイズの定理、分布）、微分積分の知識が必要です。情報理論（エントロピー、KLダイバージェンス）の知識があると役立ちます。
