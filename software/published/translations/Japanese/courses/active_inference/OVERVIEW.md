# アクティブ推論カリキュラム概要

> **クイックナビゲーション**: [哲学](./01_philosophy/) | [認知科学](./02_cognitive_science/) | [数学](./03_math/) | [コンピュータサイエンス](./04_computer_science/) | [共有リソース](./resources/)

## コースミッション

この4コースのカリキュラムは、**アクティブ推論**と**フリーエネルギー原則 (FEP)** の包括的かつ多分野的な入門を提供します。学習者が概念的な理解から数学的推論と計算実装へと進むように設計されています。

カリキュラムは**螺旋学習**の教育方法を採用しています。各コースが4つのコアトピックを異なる分野の視点から見直し、繰り返し学習を通じて理解を深めます。

---

## 1. 構造

### 学際的トラック

1. **[哲学](./01_philosophy/README.md)**: 「なぜ」「何」を確立します。現象学、能動主義、概念的基盤に焦点を当てます。
    * *主な成果物*: 概念的明確さと議論。
2. **[認知科学](./02_cognitive_science/README.md)**: 生物システムにおける「どのように」を探求します。予測コーディング、神経基底、臨床応用に焦点を当てます。
    * *主な成果物*: 理論を脳構造と機能にマッピングします。
3. **[数学](./03_math/README.md)**: 「証明」を導出します。VFE、EFE、信念更新の形式的な定義に焦点を当てます。
    * *主な成果物*: 更新方程式の厳密な導出。
4. **[コンピュータサイエンス](./04_computer_science/README.md)**: 「メカニズム」を構築します。`pymdp`およびカスタムエージェントを使用したPythonの実装に焦点を当てます。
    * *主な成果物*: アクティブ推論エージェントの動作シミュレーション。

### 8つのコアトピック

すべてのコースで次の順序でフォローされます。

1. **システム**: マルコフの布地、境界、自己組織化 ([マップ](./resources/cross_course_map.md#module-1-systems))。
2. **エージェント**: 自律性、内受容、自己モデル ([マップ](./resources/cross_course_map.md#module-2-agents))。
3. **知覚**: 推論された状態、予測コーディング、VFE最小化 ([マップ](./resources/cross_course_map.md#module-3-perception))。
4. **認知**: 信念、精度重み付け、注意 ([マップ](./resources/cross_course_map.md#module-4-cognition))。
5. **行動**: ポリシー選択、機能、EFE最小化 ([マップ](./resources/cross_course_map.md#module-5-action))。
6. **学習**: パラメータ更新、構造学習、モデル削減 ([マップ](./resources/cross_course_map.md#module-6-learning))。
7. **コミュニケーション**: 精神理論、結合推論、言語 ([マップ](./resources/cross_course_map.md#module-7-communication))。
8. **計画**: 深層時間モデルと高度な推論 ([マップ](./resources/cross_course_map.md#module-8-planning))。

* **[コース間マップ](./resources/cross_course_map.md)**: すべての4コースのモジュールを網羅したグリッドビュー。
* **[学習パス](./resources/learning_pathways.md)**: あなたの背景に基づいて材料をたどるための提案されたルート。

## 4. 貢献方法

このリポジトリはAIエージェントのチームによって維持されています。人間とエージェントは厳格なガイドラインに従う必要があります。

1. **まず読む**: 根ディレクトリにある[AGENTS.md](./AGENTS.md)を確認してください。
2. **検証**: すべての新しいコンテンツが[記号表](./resources/notation_table.md)に準拠していることを確認してください。
3. **監査**: 変更を送信する前に`./audit_modules.sh`を実行してください。
