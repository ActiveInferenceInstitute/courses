## How These Resources Are Used

### For Content Authors

When creating or editing any curriculum file (module lectures, questions, quizzes, labs, dashboards):

1. **Notation** — Use symbols exactly as defined in [notation_table.md](./notation_table.md). Never introduce ad-hoc symbols.
2. **Terminology** — Use preferred terms from [glossary.md](./glossary.md). Check the "Avoid" column in the root [AGENTS.md](../AGENTS.md) before using informal synonyms.
3. **References** — Cite from [references.md](./references.md) when possible. If a new source is needed, add it to references.md first, then cite it.
4. **Cross-linking** — Use [cross_course_map.md](./cross_course_map.md) to find and link parallel modules across courses.

### For Agents

Agents **must** read all 4 resource files before generating or substantially editing content. These resources ensure consistency across the 32-module, 4-course curriculum.

### For Students

These resources serve as quick reference tools during study:

- Use the **notation table** when you encounter an unfamiliar symbol
- Use the **glossary** when you encounter a new term
- Use the **references** to find the original papers behind each concept
- Use the **cross-course map** to see how the same topic looks from different disciplinary angles

## Maintenance

| Action | When | How |
|--------|------|-----|
| Add a new term | When introducing a concept not in the glossary | Add to [glossary.md](./glossary.md) in alphabetical order |
| Add a new symbol | When a module uses notation not in the table | Add to [notation_table.md](./notation_table.md) in the appropriate section |
| Add a new reference | When citing a paper not in references.md | Add to [references.md](./references.md) under the appropriate module heading |
| Update cross-course map | When module titles or focus descriptions change | Update [cross_course_map.md](./cross_course_map.md) |
