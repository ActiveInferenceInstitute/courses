Key Concepts

Practice as Network Training +

Each practice session is a training epoch. Each corrected mistake is a gradient step. The crocheter's motor system trains like a neural network — weights converge toward optimal values over thousands of stitches.

A beginning crocheter's hands are an untrained network with poorly calibrated "weights" — grip pressure, hook insertion depth, yarn tension. Each stitch attempted is a training sample. Each row is an epoch. The learning rate starts high (dramatic improvement in the first hour) and slows as skill develops, eventually producing muscle memory — converged motor weights that execute stitch policies automatically.

Centrality: Core structural parallel

Overfitting vs Generalization +

Crocheters who only make granny squares overfit — mastering one pattern but struggling with new ones. Diverse practice builds generalized skill that transfers across stitch types and project forms.

Just as a neural network trained exclusively on one data type memorizes rather than learns, a crocheter who never leaves their comfort zone develops narrow skill. The antidote is the same in both domains: varied training data (diverse projects, yarn weights, stitch types) and regularization techniques (deliberately practicing unfamiliar techniques, trying new materials).

Centrality: Key learning principle

Loss Landscape of Projects +

Simple projects have smooth, forgiving loss landscapes; complex lace has rugged, unforgiving landscapes with narrow paths to success. Experience teaches the crocheter to read these landscapes intuitively.

A dishcloth in single crochet is a smooth valley — hard to go seriously wrong. A lace shawl with a 24-row repeat is a rugged landscape with local minima and narrow saddle points. A single missed yarn-over can cascade through subsequent rows. The crocheter's experience level determines how well they can sense difficulty before beginning.
