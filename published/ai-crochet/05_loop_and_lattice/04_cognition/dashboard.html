Key Concepts

Crochet Rows as Hidden Layers +

Each row of crochet functions as a hidden layer — transforming input from the row below into new representations. Foundation chains are input layers; the finished edge is the output layer.

Just as neural network hidden layers transform raw data through successive computations, each row of crochet transforms the structural state of the fabric. The depth of the project (number of rows) determines the richness and complexity of the emergent structure, paralleling how deep networks learn richer representations than shallow ones.

Centrality: Core structural parallel

Emergent Hidden Representations +

Complex stitch patterns (shells, cables, granny squares) are hidden representations — emergent features that cannot be reduced to individual component stitches.

A shell stitch (five double crochets fanned from one base) creates an emergent feature no single stitch produces. Similarly, cables emerge across multiple rows. These mirror how features in trained neural networks (edges, textures, objects) emerge from the interaction of many individual neurons across layers, not from any single unit.

Centrality: Key analogy bridge

Deep Generative Model of Projects +

The crocheter holds a deep generative model spanning from finished-object vision down to current-stitch mechanics — predictions flow top-down through multiple hierarchical levels.

The crocheter simultaneously maintains representations at stitch level, row level, section level, project level, and design level. Top-down predictions ("this should be a hat") constrain lower-level operations, while bottom-up evidence (the feel of each stitch) updates the model. Beginners have shallow models; experts have deep ones that enable improvisation.

Centrality: Active Inference integration
