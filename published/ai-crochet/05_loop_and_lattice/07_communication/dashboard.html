Key Concepts

Mesh vs Solid Communication +

Mesh fabric (chain spaces, open patterns) transmits signals loosely like a sparse network. Solid fabric transmits directly like a dense, fully-connected network.

A lace pattern with chain-3 spaces creates long-range connections between distant nodes, while solid single crochet creates tight, local connectivity. The crocheter's choice between open and closed fabric is a choice between communication topologies — sparse vs dense network architectures with fundamentally different information-flow properties.

Centrality: Core structural concept

Pattern as Communication Protocol +

Written crochet patterns are communication protocols — compressed descriptions encoding complex network structures for transmission between crocheters across time and space.

"Ch 3, 5 dc in ring, sl st" compresses a detailed graph specification into a few symbols. Like TCP/IP or HTTP, crochet notation is a standardized protocol enabling reliable transmission of complex structural information. Different notation systems (US/UK terms, charts, video) are different protocols for the same underlying network data.

Centrality: Information theory bridge

Stitch Markers as External Memory +

Stitch markers are external memory nodes — physical tokens carrying information between sessions, extending the crocheter's cognitive system beyond the brain.

A stitch marker placed at a pattern repeat boundary is externalized working memory. It frees cognitive resources by physically encoding positional information. This is extended cognition: the crocheter's mind extends beyond the skull to include the markers, the pattern, and the emerging fabric itself as components of a distributed cognitive system.

Centrality: Extended cognition bridge
