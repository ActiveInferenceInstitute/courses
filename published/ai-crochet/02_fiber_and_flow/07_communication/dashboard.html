Key Concepts

Color Theory as Shared Language +

Color wheels, complementary pairs, and value scales give crocheters a shared vocabulary for design.

Color theory provides a common generative model that two crocheters can use to communicate about yarn choices. Terms like 'warm neutral' or 'high contrast' are compressed predictions.
Relevance to Active Inference

Yarn Weight Classification +

The standard weight system (lace through jumbo) is a shared coding scheme for tactile properties.

Weight categories compress complex tactile information into a shared label. When someone says 'worsted weight,' both parties activate similar predictions about diameter, gauge, and drape.
Relevance to Active Inference

Fiber Content Labeling +

Fiber labels communicate internal states of the yarn system to anyone who can read them.

A label reading '80% merino, 20% nylon' transmits the yarn's generative model in compressed form. The reader can predict felting behavior, durability, warmth, and care requirements.
Relevance to Active Inference

Pattern Writing as Model Transmission +

A crochet pattern is a written generative model that transmits the designer's vision to the maker.

The pattern encodes stitch sequences, material choices, and construction logic. Reading and following a pattern is receiving and executing someone else's generative model.
Relevance to Active Inference
