Study Questions: Communication (Fiber & Flow)

  1. How does color theory function as a shared generative model in the crochet community? What predictions does the color wheel enable?

  2. Explain the yarn weight classification system as a communication protocol. What information is compressed into a single weight category label?

  3. Why can a fiber content label like "100% Superwash Merino" transmit so much predictive information in so few words? What shared model must sender and receiver possess?

  4. How does texture communicate meaning in crochet? Give three examples of textures and the meanings they convey.

  5. Describe a crochet pattern as a generative model transmission. What makes a good pattern versus a bad one in terms of model fidelity?

  6. How do standardized gauge specifications function as a communication bridge between pattern designers and crocheters?

  7. Why do color names vary between yarn brands, and what communication problems does this create? How could the system be improved?

  8. How does the visual language of a finished crochet piece communicate the crocheter's skill level to other crafters?

  9. Describe how abbreviations in crochet patterns (sc, dc, ch, etc.) function as a compressed communication code. What happens when the code is ambiguous?

  10. How do online crochet communities extend the communicative range of the fiber arts? What can be communicated online that cannot be communicated through a pattern alone?

  11. Why is it difficult to communicate yarn hand feel through text or images? What information is lost when yarn cannot be touched?

  12. How does the concept of a yarn review function as communicated experience? What makes a yarn review useful versus unhelpful?

  13. Describe the communication challenges of international crochet — different terminology (US vs. UK stitch names), different weight systems, different hook sizing.

  14. How does a yarn color card or shade card function as a visual communication tool? What does it predict for the crocheter?

  15. Explain how a crocheter's Ravelry project page communicates their experience to future crafters. What information has the highest predictive value?

  16. How do care symbols on yarn labels communicate a compressed set of instructions? What happens when a crocheter ignores these communications?

  17. Why is it important that the crochet community maintains shared standards for weight, gauge, and fiber labeling? What would happen if these standards diverged?

  18. How does a color palette inspiration image (e.g., a photo of a sunset used to select yarn colors) function as a communicative bridge between nature and craft?

  19. Describe the communication that happens when a crocheter teaches a beginner. What generative model elements are hardest to transmit verbally?

  20. If you were designing a new yarn labeling system, what information would you include beyond current standards? What would help crocheters make better predictions?
