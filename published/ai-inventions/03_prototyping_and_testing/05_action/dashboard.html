Core Concepts

1. The Action-Perception Loop

Build (action) -> test (perception) -> update beliefs -> select next change (action). Each turn reduces free energy. Toyota's kaizen implements this at industrial scale. The loop's value comes from frequency, not amplitude: many small fast iterations outperform few large slow ones because each turn corrects errors in the generative model.

2. Minimum Viable Prototype

The simplest prototype that generates enough prediction error to meaningfully update the generative model. Include only what tests the highest-priority hypothesis; exclude everything else. Houston's Dropbox video tested demand without building the technology. The MVP maximizes the ratio of information gain to construction cost.

3. A/B Testing

Controlled comparison between two design alternatives. Vary one factor, keep everything else constant, randomly assign conditions, compare outcomes. Google runs 10,000+ A/B tests annually. For physical prototypes, build both options and test each with different user groups. The key discipline: change only one variable at a time.

4. Pivot or Persevere

Persevere signals: each iteration improves performance, errors are shrinking, remaining problems are calibration issues. Pivot signals: diminishing returns, prediction errors not decreasing, fundamental approach feels wrong. Slack pivoted from a failing game (Glitch) to a communication tool when game engagement showed persistent large prediction errors.

5. Iteration Roadmapping

A planned sequence of prototype iterations with three components: the sequence (hypothesis priority ordering), decision gates (criteria for proceed/iterate/pivot), and resource allocation (time and budget per iteration). Without a roadmap, iteration becomes circular rather than convergent. The Stage-Gate process formalizes this with evidence-based checkpoints.
