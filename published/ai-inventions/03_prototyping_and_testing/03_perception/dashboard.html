Core Concepts

1. Observation vs. Inference

Raw test observations (a part broke at 45N, a user hesitated for 3 seconds) are not the same as inferences (the material is too weak, the interface is confusing). Perception in testing is always model-dependent: your priors shape what you see. Record raw data before interpreting it, because interpretations change as your model evolves.

2. Signal Taxonomy

Four types of test signals: Quantitative measurements (force, voltage, time) for parameter estimation. Qualitative feedback (user comments) for model structure evaluation. Behavioral observations (what users actually do) for revealing implicit user models. Failure events (breakage, malfunction) for identifying model boundaries. Each type provides unique information.

3. Failure as Highest-Value Signal

Failures produce the largest prediction errors, forcing the most significant model updates. Fleming discovered penicillin from a contaminated culture. Spencer invented the microwave from a melted candy bar. These inventors had models flexible enough to recognize failures as informative signals rather than noise. Build "failure listening" into every test protocol.

4. Extending Perception Through Instrumentation

Instruments transduce hidden states into observable signals: strain gauges convert stress to resistance, thermal cameras convert temperature to images, eye trackers convert attention to coordinates. Each instrument adds a sensory channel to the inventor's Markov blanket. The design challenge is choosing which hidden states are most relevant to current hypotheses.

5. Quantitative vs. Qualitative Trade-offs

Quantitative data provides precision for parameter updates within an existing model. Qualitative data provides richness for structure evaluation, revealing missing variables. A user saying "this feels unsafe" signals a perceived-safety variable absent from the inventor's model. The best strategies combine both: quantitative for calibration, qualitative for model expansion.

6. Behavioral Observation

Watching what users do (not just what they say) captures their implicit generative model. IDEO's shopping cart redesign was driven by behavioral observations: shoppers hung bags on handles, children stood on rails, carts were abandoned in narrow aisles. None of these needs were verbally articulated. Behavioral signals are the highest-bandwidth perceptual channel available.
