Post-Launch Model Updating

Every launch generates prediction errors. Parameter updating adjusts model weights (Spotify tuning recommendations). Model restructuring replaces the model's architecture (Instagram pivoting from check-ins to photos). The critical skill is distinguishing between the two in real time.

Example: Amazon continuously adjusts logistics routing parameters but restructured its entire model when it launched AWS — a completely new business.

Feedback Loop Precision

Not all feedback is equal. Behavioral data (what customers do) is high-precision evidence of actual free energy minimization. Stated data (what customers say) reflects self-models that may diverge from behavior. Design feedback loops that prioritize behavioral evidence and treat stated evidence with appropriate skepticism.

Example: Amazon's A/B testing infrastructure generates millions of high-precision behavioral experiments per year, far more reliable than any survey.

Pivoting as Model Comparison

A pivot is justified when accumulated evidence supports an alternative generative model more strongly than the current model. This is Bayesian model comparison — weighing the evidence for each model against switching costs. The key discipline is ensuring pivots are evidence-driven, not frustration-driven.

Example: Slack pivoted from a game (Glitch) to a communication tool when usage data showed the internal chat system attracted more engagement than the game itself.

Knowledge Management as Memory

Organizational learning only persists through knowledge management — the organizational equivalent of long-term memory. The SECI model describes how tacit knowledge becomes explicit and vice versa. Post-mortems, documentation, and training programs preserve learned model parameters across time and team changes.

Example: Amazon's 6-page memo practice creates a paper trail of predictions and outcomes that serves as institutional memory.

Building Learning Organizations

A learning organization institutionalizes Active Inference — it continuously generates predictions, tests them, processes errors, and updates models. Senge's five disciplines (personal mastery, mental models, shared vision, team learning, systems thinking) each contribute to this organizational inference capacity.

Example: Spotify's squad model creates multiple autonomous inference agents that test hypotheses in parallel, accelerating organizational learning.
