# Syllabus: Code & Create

> **Active Inference for Middle School** | **Audience**: Grades 6-8

## Course Description

Code & Create explores Active Inference through block coding & simple python. Over 8 modules, students will build a comprehensive understanding of how living systems perceive, think, act, and learn.

## Schedule

| Week | Module | Topic | Activity |
| --- | --- | --- | --- |
| Week 1 | [Systems](./01_systems/module.md) | Systems Everywhere: Phones, Schools, and You | Guided Coding Lab |
| Week 2 | [Agents](./02_agents/module.md) | What Makes an Agent Tick? | Guided Coding Lab |
| Week 3 | [Perception](./03_perception/module.md) | Seeing is Believing... Or Is It? | Guided Coding Lab |
| Week 4 | [Cognition](./04_cognition/module.md) | Thinking Fast and Slow | Guided Coding Lab |
| Week 5 | [Action](./05_action/module.md) | Actions Speak Louder | Guided Coding Lab |
| Week 6 | [Learning](./06_learning/module.md) | Level Up: How We Learn | Guided Coding Lab |
| Week 7 | [Communication](./07_communication/module.md) | Connected: Social Brains | Guided Coding Lab |
| Week 8 | [Planning](./08_planning/module.md) | Game Plan: Thinking Ahead | Guided Coding Lab |
