# Unit 04: Code & Create — Building Minds with Technology

## Learning Objectives

1. Understand how **programming and digital creation** are ways of building prediction machines, just like the ones in your brain.
2. Explore how **active inference principles** show up in game design, AI, robotics, and creative coding projects.
3. Create your own digital projects that use **feedback loops, learning, and prediction** to do something cool.

## Introduction

Every time you play a video game, something wild is happening behind the scenes. The enemy NPCs are "deciding" where to move. The difficulty is adjusting to how well you're playing. The game world is predicting what you'll do next and preparing for it. Sound familiar? It should — that's active inference, built into code.

When you learn to program, you're not just learning a technical skill. You're learning to build systems that predict, sense, act, and learn — the same things your brain does. A chatbot predicts what you might say. A recommendation algorithm learns your preferences. A robot adjusts its movements based on feedback. These are all digital versions of the same active inference loop.

In this unit, you'll go from playing with technology to building with it. You'll design games, create simple AI, and build projects that use the principles of active inference. By the end, you'll see code not just as instructions for a computer, but as a way of building minds.

## What You'll Explore in This Unit

### Module 1: Systems — How Code Creates Worlds
Every program is a system with inputs, processes, and outputs. You'll learn to see the architecture behind apps, games, and websites — and start building your own.

### Module 2: Agents — Giving Code a Mind
From game NPCs to chatbots, digital agents make decisions based on their "understanding" of the world. You'll learn what makes something an agent versus just a script.

### Module 3: Perception — Sensors and Inputs
How does a program "see" the world? Through sensors, user input, and data feeds. You'll explore how digital systems gather and process information.

### Module 4: Cognition — Algorithms That Think
Algorithms are like recipes for thinking. You'll learn how programs use logic, conditionals, and models to make decisions — and how this mirrors your own thought process.

### Module 5: Action — Output and Interaction
A program that only thinks but never acts is useless. You'll build projects that respond, move, display, and interact based on their internal models.

### Module 6: Learning — Code That Gets Smarter
The coolest programs adapt over time. You'll explore how machine learning works at a basic level and build simple programs that improve with experience.

### Module 7: Communication — APIs and Protocols
How do programs talk to each other? Through APIs, protocols, and data formats. You'll learn how digital communication mirrors the way brains share information.

### Module 8: Planning — Smart Algorithms for Complex Problems
From pathfinding in games to scheduling apps, you'll learn how programs plan ahead by simulating possible futures — just like your brain does.

## Summary

Code is more than syntax and semicolons — it's a way of building systems that predict, perceive, act, and learn. In this unit, you'll use programming as a creative tool to explore active inference from the inside out. Whether you're designing a game, training a simple AI, or building a creative project, you'll see that the same principles that run your brain can run your code. Let's build something.
