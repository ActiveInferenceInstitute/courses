# Body Science

> Part of **Active Inference for Middle School** | [Curriculum Home](../README.md)

## Overview

**Body Science** explores Active Inference through the lens of anatomy & health. This course is designed for Grades 6-8.

**Tone**: Curious, meme-aware, relatable. Light math (fractions, percentages). Scratch/block coding.
