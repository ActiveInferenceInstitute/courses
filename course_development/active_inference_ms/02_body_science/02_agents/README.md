# Module 02: Agents

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Your Brain as Agent

Part of **Body Science**.

## Learning Objectives

By the end of this module, you will be able to:

1. **Describe** the brain as an agent with sensors, an internal model, and action outputs
2. **Measure** reaction time and explain how prediction makes reactions faster
3. **Distinguish** between reflexes (automatic) and decisions (deliberate)
4. **Explain** how the brain compensates when one sensory input is removed
5. **Map** the brain's agent features: sensors, goals, predictions, actions
6. **Connect** the brain-as-agent concept to Active Inference

## Key Vocabulary

| Term | Simple Definition |
|------|------------------|
| **Brain** | The organ that acts as your body's central agent |
| **Reflex** | An automatic, fast response that does not require conscious thought |
| **Decision** | A deliberate choice that requires conscious thinking |
| **Sensory input** | Information from your senses arriving at the brain |
| **Motor command** | A signal from the brain telling muscles to move |
| **Reaction time** | How fast you respond to an unexpected event |
| **Compensation** | When the brain shifts resources to other senses when one is reduced |

## Why This Matters

Your brain is running thousands of processes right now -- keeping your heart beating, processing what you are reading, maintaining your balance, and preparing for whatever comes next. It is the ultimate agent, constantly predicting and adjusting. Understanding how the brain works as an agent helps you:
- Appreciate why reactions improve with practice
- Understand the difference between instinct and deliberate thought
- See how prediction makes you faster and more efficient
- Recognize your brain as an Active Inference machine
