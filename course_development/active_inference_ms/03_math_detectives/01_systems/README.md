## Counting, Measuring, and Categorizing Data

Part of **Math Detectives**.

## Learning Objectives

By the end of this module, you will be able to:

1. **Define** number systems in the context of data investigation and probability
2. **Collect** data systematically using appropriate measurement and recording techniques
3. **Analyze** data to find patterns, trends, and outliers
4. **Calculate** simple statistics (averages, ranges, frequencies) to summarize findings
5. **Predict** future outcomes based on observed data patterns
6. **Connect** data analysis to Active Inference's prediction-and-update framework

## Key Vocabulary

| Term | Simple Definition |
|------|------------------|
| **Data** | Numbers or observations collected to answer a question |
| **Pattern** | A repeating or predictable arrangement in data |
| **Prediction** | A guess about what will happen, based on evidence |
| **Probability** | How likely something is to happen (from 0% to 100%) |
| **Evidence** | Data that supports or contradicts a prediction |
| **Outlier** | A data point that is very different from the rest |
| **Trend** | The general direction data is moving (up, down, steady) |

## Prerequisites

- Basic arithmetic (addition, subtraction, multiplication, division)
- Ability to read and create simple graphs
- Completion of earlier Math Detectives modules recommended

## Estimated Time

## Why This Matters

Math is not just about getting the right answer on a test -- it is about making sense of the world using numbers, patterns, and logic. Math detectives use data the way regular detectives use clues: to figure out what is going on and predict what will happen next. This is exactly what Active Inference says your brain does all the time -- it collects evidence, finds patterns, and updates its predictions. Learning these skills helps you think more clearly about everything from sports statistics to social media trends to science experiments.
