# Station: Action (Math Detectives)

> **Quick Navigation**: [Module README](./README.md) | [Course AGENTS](../AGENTS.md)

## Conventions

- **Perspective**: Probability as mystery-solving
- **Topics**: Testing Hypotheses -- hypothesis testing, experiments, control groups, fair tests
- **Lab Style**: Guided Worksheet
- **Audience**: Grades 6-8
- **Tone**: Curious, meme-aware, relatable

## Content Guidelines

### Audience Awareness
Middle schoolers are developing mathematical reasoning skills and enjoy mystery/detective scenarios. Frame data investigation as solving a case -- the data is the evidence, the patterns are the clues, and the prediction is the solution. Use accessible math (fractions, percentages, simple graphs) rather than advanced statistics. Students should feel like clever detectives, not intimidated math students.

### Active Inference Integration
- **Data as Evidence**: In Active Inference, perception provides evidence that updates the agent's model. In Math Detectives, collected data serves the same role -- it updates our predictions about the world.
- **Prediction and Testing**: The core loop of Active Inference (predict, observe, update) maps directly to the scientific method (hypothesize, experiment, revise). Make this connection explicit.
- **Uncertainty and Probability**: Use simple probability language (likely, unlikely, 50-50) to describe uncertainty. Help students see that Active Inference is fundamentally about managing uncertainty with math.

### Lab Design Principles
- Guided worksheet format with structured data tables
- Data collection that students can complete in the classroom
- Pattern analysis that builds toward prediction
- Prediction testing for immediate feedback
- All activities completable in 30-40 minutes with basic materials

### Key Vocabulary for This Module
Hypothesis Testing, Experiments, Control Groups, Fair Tests
