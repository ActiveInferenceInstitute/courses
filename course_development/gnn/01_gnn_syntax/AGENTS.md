## Content Conventions

- **Perspective**: notation and specification — what a model declares, not how
  a particular framework implements it
- **Audience**: middle school (guided reading) through advanced 401; the module
  is written for the reader who will supervise the level mapping
- **Tone**: precise and example-driven; every claim about the exemplar must be
  checkable against the file itself
- **Notation**: match the exemplar files; the A–E matrix conventions follow the
  Core curriculum's [notation table](../../active_inference/resources/notation_table.md)
- **Terminology**: prefer "generative model", "hidden state", "observation",
  "likelihood matrix", "transition matrix", "prior", "precision" (see
  [glossary](../../active_inference/resources/glossary.md))

## Rules for Agents

1. **Do not edit the files in `models/`.** They are verbatim copies from the GNN
   repository at the pinned commit recorded in
   [`models/README.md`](./models/README.md). To update them, re-copy from the
   new pinned commit and update the provenance table and hashes.
2. **Keep counts accurate.** The module ships five exemplars; do not describe
   the set as "the full corpus" or imply coverage of families that are not
   shipped (continuous, hierarchical, multi-agent, precision, scaling).
3. **Verify commands before writing them.** Pipeline commands must match the
   GNN repository's documented interface for the pinned release
   (`python src/gnn/main.py --target-dir <dir> --only-steps "3,5,11,12"`).
4. **Keep the level mapping honest.** Elementary and Family levels do not
   introduce GNN; the middle-school entry is explicitly a guided reading.
5. **No placeholders.** Every worksheet field, table, and exercise must be
   completable with the shipped materials.
