# Module 02: Agents -- Estimator-Controller Agent Design

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Overview

This module covers **agents** in the context of **Control & Estimation**. It applies Active Inference principles to mathematical control and estimation theory, examining how agents operates within robotic systems from the perspective of kalman filters, pid, mpc, active inference.

## Learning Objectives

1. **Derive** the mathematical formulation of agents for robotic systems in state-space form.
2. **Implement** classical agents algorithms and their Active Inference equivalents in pseudocode.
3. **Prove** conditions under which classical and Active Inference approaches to agents yield equivalent results.
4. **Apply** agents algorithms to specific robotic platforms with realistic parameters.
5. **Compare** classical and Active Inference agents in terms of robustness, adaptability, and computational cost.
6. **Evaluate** the practical trade-offs of adopting Active Inference agents in real-time robotic systems.

## Key Concepts

- State-space formulation of agents
- Classical vs. Active Inference approaches to agents
- Mathematical equivalences and divergences
- Computational complexity and real-time feasibility
- Precision weighting in agents

## Prerequisites

- Familiarity with Active Inference fundamentals (generative models, free energy, prediction errors)
- Completion of prior modules in this course sequence
- Basic robotics background (kalman filters, pid, mpc, active inference)
