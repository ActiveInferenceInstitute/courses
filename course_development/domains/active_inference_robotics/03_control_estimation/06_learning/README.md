# Module 06: Learning -- Adaptive Control and Parameter Estimation

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Overview

This module covers **learning** in the context of **Control & Estimation**. It applies Active Inference principles to mathematical control and estimation theory, examining how learning operates within robotic systems from the perspective of kalman filters, pid, mpc, active inference.

## Learning Objectives

1. **Derive** the mathematical formulation of learning for robotic systems in state-space form.
2. **Implement** classical learning algorithms and their Active Inference equivalents in pseudocode.
3. **Prove** conditions under which classical and Active Inference approaches to learning yield equivalent results.
4. **Apply** learning algorithms to specific robotic platforms with realistic parameters.
5. **Compare** classical and Active Inference learning in terms of robustness, adaptability, and computational cost.
6. **Evaluate** the practical trade-offs of adopting Active Inference learning in real-time robotic systems.

## Key Concepts

- State-space formulation of learning
- Classical vs. Active Inference approaches to learning
- Mathematical equivalences and divergences
- Computational complexity and real-time feasibility
- Precision weighting in learning

## Prerequisites

- Familiarity with Active Inference fundamentals (generative models, free energy, prediction errors)
- Completion of prior modules in this course sequence
- Basic robotics background (kalman filters, pid, mpc, active inference)
