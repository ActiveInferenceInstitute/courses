# Learning Pathways: Active Inference for Robotics

> Suggested routes through the curriculum for robotics engineers and researchers.

## Pathway 1: Sequential (Recommended for Beginners)

Complete one course fully before starting the next. This builds knowledge progressively from hardware foundations to full autonomy.

1. **Robotic Systems** -- Learn how Active Inference maps to sensors, actuators, and embedded systems.
2. **Bio-Inspired Design** -- Understand biological inspiration for robotic design through biomimicry and neural architectures.
3. **Control & Estimation** -- Master the mathematical foundations: Kalman filtering, optimal control, and their Active Inference equivalences.
4. **Autonomous Agents** -- Integrate everything into fully autonomous robotic systems with SLAM, navigation, and multi-robot coordination.

**Duration**: ~16 weeks at 2 modules per week.

## Pathway 2: Parallel by Module (Recommended for Experienced Roboticists)

Study the same module topic across all four courses before moving to the next module. This provides deep comparative understanding.

For each module number (1-8):
1. Read the Robotic Systems version (hardware perspective)
2. Read the Bio-Inspired Design version (biological perspective)
3. Read the Control & Estimation version (mathematical perspective)
4. Read the Autonomous Agents version (deployment perspective)

**Duration**: ~16 weeks at 4 lectures per week.

## Pathway 3: Control Engineer Track

For roboticists with a control theory background who want to understand Active Inference quickly:

1. Course 3, Module 01: Control System Architectures
2. Course 3, Module 03: State Estimation and Kalman Filtering
3. Course 3, Module 05: Optimal Control and Active Inference
4. Course 3, Module 06: Adaptive Control and Parameter Estimation
5. Course 1, Module 05: Active Inference Control (hardware perspective)
6. Course 3, Module 08: Model Predictive Control and Planning
7. Course 4, Module 05: Autonomous Manipulation and Locomotion

**Duration**: ~7 weeks at 1 module per week.

## Pathway 4: Bio-Inspired Robotics Track

For researchers interested in the intersection of biology and robotics:

1. Course 2, Module 01: Biological System Architectures
2. Course 2, Module 02: Biological Agents and Embodied Cognition
3. Course 2, Module 03: Bio-Inspired Sensing and Predictive Processing
4. Course 2, Module 05: Biological Motor Control and CPGs
5. Course 2, Module 06: Biological Learning Mechanisms
6. Course 2, Module 07: Biological Communication and Swarm Intelligence
7. Course 1, Module 03: Sensor Fusion and State Estimation

**Duration**: ~7 weeks at 1 module per week.

## Pathway 5: Autonomous Systems Track

For engineers building autonomous robots who want practical deployment skills:

1. Course 4, Module 01: Autonomous System Architectures
2. Course 4, Module 03: Autonomous Perception Pipelines
3. Course 4, Module 04: Autonomous World Modeling
4. Course 4, Module 05: Autonomous Manipulation and Locomotion
5. Course 4, Module 08: Autonomous Mission Planning
6. Course 4, Module 07: Human-Robot Interaction
7. Course 4, Module 06: Autonomous Skill Learning

**Duration**: ~7 weeks at 1 module per week.

## Pathway 6: Research Deep Dive

For PhD students exploring Active Inference as a research framework:

1. Course 1, Modules 01-08 (complete foundation)
2. Course 3, Modules 03 and 05 (mathematical depth)
3. Course 2, Modules 03-05 (bio-inspiration for novel approaches)
4. Course 4, Modules 04, 06, 08 (advanced topics)

**Duration**: ~12 weeks.
