# Shared Resources: Active Inference for Robotics

> Centralized reference materials for the entire curriculum.

## Overview

This directory contains shared resources used across all four courses in the Active Inference for Robotics curriculum. These materials ensure consistency in terminology, notation, and references, and provide students with navigation aids for the multi-course program.

## Contents

| File | Description |

## How to Use These Resources

- **Before starting a course**: Review the glossary and notation table to familiarize yourself with the terminology.
- **During study**: Use the cross-course map to find related content in other courses.
- **For deeper understanding**: Consult the references for primary sources and foundational texts.
- **For curriculum navigation**: Follow one of the learning pathways based on your background and interests.

## Courses in This Curriculum

1. **Robotic Systems** -- Sensors, actuators, embedded systems (Hardware Lab)
2. **Bio-Inspired Design** -- Biomimicry and neural architectures (Design Challenge)
3. **Control & Estimation** -- Kalman filters, PID, MPC, Active Inference (Simulation Lab)
4. **Autonomous Agents** -- SLAM, navigation, multi-robot coordination (ROS2 Project)
