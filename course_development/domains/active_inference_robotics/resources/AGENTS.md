# AGENTS: Shared Resources

> **Quick Navigation**: [Resources README](./README.md) | [Curriculum AGENTS](../AGENTS.md)

## Purpose

These shared resources serve as the single source of truth for terminology, notation, references, and learning pathways across all four courses in Active Inference for Robotics. They ensure consistency and enable cross-referencing between the Robotic Systems, Bio-Inspired Design, Control & Estimation, and Autonomous Agents courses.

## Maintenance Rules

1. Update the glossary when new terms are introduced in any module across any course.
2. Keep the notation table synchronized with all four courses, adding symbols as they appear.
3. Verify cross-course map links after any structural changes to course or module organization.
4. All tables must use proper MD060-compliant formatting (spaces around pipes).
5. References must include robotics-specific Active Inference literature (Lanillos et al., Pio-Lopez et al., Oliver et al.) alongside foundational texts.
6. Learning pathways must remain valid after any curriculum restructuring.

## Quality Standards

- All definitions must be precise and consistent across courses.
- Notation must follow standard robotics conventions (q for joints, u for inputs, z for observations) extended with Active Inference notation (mu for beliefs, F for free energy, G for expected free energy).
- References must include DOIs or stable URLs where available.
- Cross-course map must be bidirectional: if Course 1 Module 3 references Course 3 Module 3, the reverse link must also exist.
