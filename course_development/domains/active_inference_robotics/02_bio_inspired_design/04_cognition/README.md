# Module 04: Cognition -- Neural Architectures for Robotic Cognition

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Overview

This module covers **cognition** in the context of **Bio-Inspired Design**. It applies Active Inference principles to biological inspiration for robotic design, examining how cognition operates within robotic systems from the perspective of biomimicry & neural architectures.

## Learning Objectives

1. **Map** hippocampal spatial representations (place cells, grid cells) to robotic localization and mapping systems.
2. **Design** hierarchical cognitive architectures inspired by cortical processing streams for object recognition.
3. **Implement** biologically-inspired memory systems (working, episodic, semantic, procedural) for robotic cognition.
4. **Analyze** how the brain builds and updates world models through predictive coding and synaptic plasticity.
5. **Compare** neural-inspired cognitive architectures with classical AI approaches (SLAM, planning, classification).
6. **Evaluate** the computational trade-offs of implementing brain-like cognitive architectures on robotic hardware.

## Key Concepts

- Hippocampal navigation and place/grid cells
- Cortical hierarchies and predictive coding
- Biological memory systems and their robotic equivalents
- Neural-inspired cognitive architectures
- Embodied cognition and situated world models

## Prerequisites

- Familiarity with Active Inference fundamentals (generative models, free energy, prediction errors)
- Completion of prior modules in this course sequence
- Basic robotics background (biomimicry & neural architectures)
