# Module 06: Learning -- Biological Learning Mechanisms for Adaptive Robots

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Overview

This module covers **learning** in the context of **Bio-Inspired Design**. It applies Active Inference principles to biological inspiration for robotic design, examining how learning operates within robotic systems from the perspective of biomimicry & neural architectures.

## Learning Objectives

1. **Analyze** Hebbian learning rules as biologically plausible mechanisms for robotic sensor calibration and model learning.
2. **Design** developmental learning curricula for robots inspired by infant motor development stages.
3. **Connect** dopaminergic reward prediction error to expected free energy minimization in Active Inference.
4. **Implement** curiosity-driven exploration systems that maximize epistemic value (information gain).
5. **Compare** biological (Hebbian, STDP) and artificial (backpropagation) learning mechanisms for robotics applications.
6. **Evaluate** the trade-offs between biological plausibility, computational efficiency, and learning performance.

## Key Concepts

- Hebbian learning and synaptic plasticity
- Developmental learning and staged skill acquisition
- Curiosity, intrinsic motivation, and epistemic value
- Reward prediction error and dopaminergic systems
- Biologically plausible learning rules for robots

## Prerequisites

- Familiarity with Active Inference fundamentals (generative models, free energy, prediction errors)
- Completion of prior modules in this course sequence
- Basic robotics background (biomimicry & neural architectures)
