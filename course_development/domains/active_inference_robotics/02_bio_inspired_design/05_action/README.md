# Module 05: Action -- Biological Motor Control and Central Pattern Generators

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Overview

This module covers **action** in the context of **Bio-Inspired Design**. It applies Active Inference principles to biological inspiration for robotic design, examining how action operates within robotic systems from the perspective of biomimicry & neural architectures.

## Learning Objectives

1. **Analyze** the biological spinal reflex arc as an Active Inference control mechanism with proprioceptive predictions.
2. **Design** CPG-based locomotion controllers for legged robots with sensory feedback modulation.
3. **Explain** the cerebellum's forward model as a biological implementation of generative model predictions.
4. **Compare** biological locomotion strategies with robotic approaches across efficiency, adaptability, and robustness.
5. **Implement** bio-inspired reaching controllers using forward models and prediction error signals.
6. **Evaluate** how efference copy mechanisms improve robotic motor control by predicting self-generated sensory changes.

## Key Concepts

- Spinal reflex arc as Active Inference control
- Central pattern generators for rhythmic movement
- Cerebellar forward models and motor prediction
- Efference copy and corollary discharge
- Bio-inspired locomotion control

## Prerequisites

- Familiarity with Active Inference fundamentals (generative models, free energy, prediction errors)
- Completion of prior modules in this course sequence
- Basic robotics background (biomimicry & neural architectures)
