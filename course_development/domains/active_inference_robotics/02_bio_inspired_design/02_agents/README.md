# Module 02: Agents -- Biological Agents and Embodied Cognition

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Overview

This module covers **agents** in the context of **Bio-Inspired Design**. It applies Active Inference principles to biological inspiration for robotic design, examining how agents operates within robotic systems from the perspective of biomimicry & neural architectures.

## Learning Objectives

1. **Analyze** animal behavior as Active Inference, identifying generative models and prior preferences.
2. **Explain** morphological computation and how body-environment coupling reduces cognitive requirements.
3. **Apply** the umwelt concept to robotic sensor design, creating task-appropriate sensory worlds.
4. **Design** bio-inspired robotic agents that exploit embodied cognition and material compliance.
5. **Compare** biological and artificial agency across dimensions of autonomy, adaptation, and self-repair.
6. **Evaluate** soft robotics as an implementation of Active Inference principles in hardware.

## Key Concepts

- Biological agency as Active Inference
- Morphological computation and embodied cognition
- Umwelt and subjective sensory worlds
- Soft robotics and compliant mechanisms
- Biological autonomy and self-maintenance

## Prerequisites

- Familiarity with Active Inference fundamentals (generative models, free energy, prediction errors)
- Completion of prior modules in this course sequence
- Basic robotics background (biomimicry & neural architectures)
