# Active Inference for Robotics — Pedagogical Overview

## Vision

This curriculum makes Active Inference accessible to Robotics engineers and researchers through four complementary lenses. Each course covers the same 8 foundational topics but from a different disciplinary perspective.

## Tone & Style

Engineering-focused. Hardware + software. ROS2, sensor fusion, control theory.
