# Module 02: Agents -- Autonomous Agent Design Patterns

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Overview

This module covers **agents** in the context of **Autonomous Agents**. It applies Active Inference principles to fully autonomous robotic systems, examining how agents operates within robotic systems from the perspective of slam, navigation, multi-robot coordination.

## Learning Objectives

1. **Design** a complete autonomous agents system with ROS2 architecture and Active Inference components.
2. **Implement** core algorithms for autonomous agents in pseudocode with defined data structures and timing constraints.
3. **Evaluate** system autonomy across dimensions: human intervention, failure recovery, novelty handling, and continuous operation.
4. **Compare** classical autonomous agents approaches with Active Inference formulations.
5. **Analyze** real-world deployment challenges for autonomous agents systems including safety and edge cases.
6. **Integrate** agents with other autonomous subsystems (perception, planning, control) in a unified Active Inference architecture.

## Key Concepts

- Autonomous agents system architecture
- ROS2 implementation patterns for autonomy
- Failure recovery and graceful degradation
- Active Inference for autonomous agents
- Real-world deployment challenges and solutions

## Prerequisites

- Familiarity with Active Inference fundamentals (generative models, free energy, prediction errors)
- Completion of prior modules in this course sequence
- Basic robotics background (slam, navigation, multi-robot coordination)
