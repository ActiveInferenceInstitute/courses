# Lab: Autonomous Agents Integration Project

## Objective

Design a comprehensive robotic system that integrates all eight Active Inference modules from the Autonomous Agents course. You will apply slam, navigation, multi-robot coordination to create a unified system specification that demonstrates how systems, agents, perception, cognition, action, learning, communication, and planning work together under the Active Inference framework.

## Prerequisites

- Completion of Modules 01-08 in the Autonomous Agents course
- Familiarity with slam, navigation, multi-robot coordination
- Understanding of Active Inference fundamentals
