## Identity

- **Course**: Robotic Systems
- **Number**: 1
- **Perspective**: Sensors, actuators, embedded systems
- **Lab Type**: Hardware Lab
- **Audience**: Robotics engineers and researchers
- **Tone**: Engineering-focused. Hardware + software. ROS2, sensor fusion, control theory.

## Course Theme

This course establishes the foundational mapping between Active Inference concepts and robotic hardware/software systems. Every module grounds abstract concepts (Markov blankets, generative models, free energy) in concrete robotic components (sensors, actuators, processors, communication buses). The goal is for robotics engineers to see Active Inference not as an abstract theory but as a practical design framework for building better robots.

## Conventions

All modules in this course must:

1. Use language appropriate for robotics engineers and researchers with backgrounds in control theory, signal processing, and embedded systems.
2. Frame all concepts through the lens of sensors, actuators, and embedded systems, using real hardware examples (LIDAR, IMUs, DC motors, stepper motors, servo drives).
3. Include hardware lab activities that involve system design, sensor analysis, controller comparison, and architecture evaluation.
4. Adhere to notation standards in [../resources/notation_table.md](../resources/notation_table.md).
5. Cross-reference the shared [../resources/glossary.md](../resources/glossary.md).
6. Connect each module to standard robotics tools and frameworks (ROS2, Gazebo, MuJoCo) where applicable.
7. Maintain the Active Inference integration pattern: sensorimotor loops, proprioceptive inference, and motor commands as predictions.
