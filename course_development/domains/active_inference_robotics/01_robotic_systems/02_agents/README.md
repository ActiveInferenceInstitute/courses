# Module 02: Agents -- Embodied Agents and Morphological Computation

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Overview

This module examines what makes a robotic system an **agent** in the Active Inference framework. An agent is not simply a system with sensors and actuators, but one that actively minimizes free energy through goal-directed behavior, self-modeling, and adaptive interaction with its environment. We explore how agency emerges from the coupling between a generative model and physical embodiment, and how morphological computation reduces the cognitive burden on the generative model.

## Learning Objectives

1. **Define** a robotic agent as a self-evidencing system that minimizes variational free energy through sensorimotor coupling.
2. **Distinguish** between reactive systems, deliberative agents, and adaptive agents using generative model depth and temporal horizon.
3. **Explain** morphological computation and how the robot's physical body shape contributes to cognitive processing.
4. **Specify** the components of an Active Inference agent: generative model, belief states, prior preferences, and policy space.
5. **Analyze** hierarchical agency in robots, from low-level servo loops to high-level task planners.
6. **Evaluate** real robotic platforms along an autonomy spectrum based on their generative model complexity and adaptive capacity.

## Key Concepts

- Agency as self-evidencing and free energy minimization
- Morphological computation and body-brain coupling
- Prior preferences as implicit goal specifications
- Hierarchical generative models for multi-level control
- The autonomy spectrum: from thermostats to fully autonomous robots

## Prerequisites

- Module 01: Systems (Markov blanket formalism, system boundaries)
- Basic understanding of control loops (feedback, feedforward)
- Familiarity with goal-directed behavior concepts
