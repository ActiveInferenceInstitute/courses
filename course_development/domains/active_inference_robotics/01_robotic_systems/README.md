# Robotic Systems

> Part of **Active Inference for Robotics** | [Curriculum Home](../README.md)

## Overview

**Robotic Systems** explores Active Inference through the lens of sensors, actuators, embedded systems. This course is designed for Robotics engineers and researchers.

**Tone**: Engineering-focused. Hardware + software. ROS2, sensor fusion, control theory.
