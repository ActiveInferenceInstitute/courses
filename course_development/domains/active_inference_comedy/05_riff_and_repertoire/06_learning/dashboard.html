Key Concepts

Career-Scale Learning +

Building a repertoire is learning over career timescales — from first open mic to headlining. Each stage involves different learning challenges and different model complexity.

A core Active Inference concept applied to creative improvisation and repertoire development.

Centrality

Failure as Learning Signal +

Bombing is the most powerful learning signal in comedy — it generates massive prediction errors that force model updating. Every great comedian has a history of failures.

This concept bridges improvisational comedy practice with prediction-error frameworks.

Centrality

Style Development +

Developing a personal comedy style is deep model specialization — narrowing the generative model to excel in a specific niche rather than attempting universal comedy.

An advanced application connecting comedy repertoire building to formal Active Inference theory.
