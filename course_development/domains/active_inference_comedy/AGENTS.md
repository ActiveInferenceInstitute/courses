## Overview

This directory contains a 5-course Active Inference curriculum for comedians, performers, comedy scholars, cognitive scientists, and the curious. Agents working in this repository must maintain a smart, antic, deeply technical tone — like a theoretical physicist who also does improv. Real comedy craft knowledge and real Active Inference formalism, woven together through the structure and practice of comedy. The primary case study throughout is Abbott & Costello's "Who's on First?"

### 2. Never Use Placeholders

All content must use **real content** — no mocks, stubs, placeholder brackets, or `[TODO]` markers. Every module must contain substantive, comedy-grounded content.

### 3. Maintain Course-Specific Perspectives

| Course | Perspective | Lab Type | Example Content |
|--------|------------|----------|----------------|
| Bit & Boundary | Routine mechanics | Routine Analysis Lab | "Read the first 10 lines of 'Who's on First.' Where does the system's boundary form? The moment Abbott says 'Who's on first,' a Markov blanket snaps into existence between two incompatible models." |
| Straight & Setup | Performer strategies | Performance Workshop | "Stand up and deliver the straight man's line. Your job is to maintain high precision — to say 'Who is on first' as if it is the most obvious statement in the world. Feel how the certainty in your voice is a precision parameter." |
| Timing & Tension | Perceptual mechanisms | Timing Experiment | "Play the recording. Pause it at 'Third base!' Measure the silence before the laugh. That pause is precision weighting — the audience accumulating evidence before the prediction error resolves." |
| Crowd & Callback | Social dynamics | Audience Dynamics Lab | "Watch the routine with a group. Who laughs first? Who laughs last? The first laugher has high epistemic confidence — they 'got it' early. The last laugher is still updating." |
| Riff & Repertoire | Evolutionary comedy | Improvisation Studio | "Perform 'Who's on First' but replace baseball with a tech startup. 'The CEO is Who.' 'The CEO is who?' Notice which parts of the routine survive translation and which break. The survivors are the deep structure — the generative model's skeleton." |

### 4. Write for People Who Love Comedy

- Use second-person voice where appropriate ("Stand up. Deliver this line..." "Listen to the recording..." "Try this...")
- **Use real comedy terminology** — setup, punchline, tag, callback, blow, straight man, comic, timing, beat, topper, bit, routine, act-out
- Write with energy and precision — comedy language has its own rigor
- Ground every Active Inference concept in a concrete comedic experience
- Respect the intelligence of comedy craft — timing is sophisticated temporal inference, not just "pausing before the joke"
- Reference comedy traditions (vaudeville, improv, stand-up, sketch) alongside FEP literature
- Be genuinely funny where the material allows — do not force jokes

## Notation Standards

This curriculum uses comedy notation alongside Active Inference translations:

| Comedy Term | Active Inference Mapping | Example |
|------------|------------------------|---------|
| Setup | Prediction-generating utterance | "Abbott says 'Who's on first' — he plants a prediction in Costello's generative model" |
| Punchline | Prediction error delivery | "The punchline lands when the predicted meaning collapses — the model can't accommodate the observation" |
| Straight man | High-precision prior agent | "Abbott holds his model with iron certainty — his priors have very high precision" |
| Comic / Funny man | Low-precision / flexible agent | "Costello's model is perpetually destabilized — his precision on word meaning keeps dropping" |
| Timing / Beat | Precision accumulation window | "The pause before the punchline lets the audience's precision build, making the prediction error larger" |
| Callback | Posterior reactivation | "A callback retrieves a previously updated posterior and generates new prediction error from it" |
| Tag / Topper | Incremental prediction error | "Each tag after the punchline is a secondary prediction error riding the first" |
| Blow / Blow line | Terminal high-amplitude prediction error | "The blow is the routine's maximum prediction error — the point where the model catastrophically fails" |
| Frogging (bombing) | Failed prediction error (audience model validates) | "When a joke bombs, the audience's model successfully predicted the punchline — no surprise, no laughter" |
| Callback | Prior reactivation | "A callback is a previously resolved prediction error being re-instantiated" |
| Rule of three | Prior establishment + violation | "Two instances establish the prior; the third violates it — minimum viable prediction error" |
| Act-out | Embodied generative model | "The comedian's physical performance is an embodied generative model the audience reads" |

## Terminology Standards

| Preferred Term | Avoid | Reason |
|----------------|-------|--------|
| Setup | Prediction-generating utterance (in isolation) | Use the comedian's own word; connect to AI concept explicitly when teaching |
| Punchline | Prediction error (in isolation) | The craft term comes first; the formalism illuminates it |
| Timing | Temporal precision dynamics (in isolation) | "Timing" is richer — it encodes the whole embodied temporal inference |
| Bombing / dying | Failed surprise delivery | The performer's experience grounds the concept |
| Killing / crushing | High-amplitude collective surprise | Same — respect the performer's vocabulary |
| Reading the room | Audience state estimation | Comedians "read the room" — this is active perceptual inference |
| Bit | Bounded inference episode | A "bit" is a self-contained comedic system |
| Tight five | Precision-optimized action sequence | A comedian's most refined, lowest-free-energy set |
| Riffing | Epistemic foraging | Improvised exploration of the comedic state space |
| Hack | Degenerate prior / cliché model | A "hack" joke activates no prediction error — the audience already has it |

## Topic Order Convention

All 5 courses follow this exact topic order:

1. **Systems** → 2. **Agents** → 3. **Perception** → 4. **Cognition** → 5. **Action** → 6. **Learning** → 7. **Communication** → 8. **Planning**

Comedy version of the dependency chain:

- What holds together as a comedic system (Systems) → Who are the performers and what do they bring (Agents) → What is sensed through ears, eyes, and social antennae (Perception) → What the performer and audience think, model, and predict (Cognition) → Every joke, gesture, and pause as an action (Action) → How comedic skill deepens across performances (Learning) → How comedy is shared, quoted, and transmitted (Communication) → How sets, routines, and careers are planned (Planning)
