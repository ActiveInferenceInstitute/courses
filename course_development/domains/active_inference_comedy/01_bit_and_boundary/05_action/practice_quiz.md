# Practice Quiz: Action

## Part A: Multiple Choice

1. Costello's question "Who's on first?" is best classified as:
A) A pragmatic action that achieves its goal
B) An epistemic action trapped in a fixed point — it cannot generate disambiguating information
C) A random behavior with no inferential content
D) An external state rather than an action

2. Abbott's action policy in the routine is characterized by:
A) Random responses unrelated to Costello's questions
B) Strategic selection of utterances that maximize Costello's expected free energy while maintaining truth
C) Deliberate lying to confuse Costello
D) No planning or intention

3. A comedian's pause before a punchline functions as:
A) A mistake in delivery
B) A deliberate action that creates a precision accumulation window, amplifying subsequent prediction error
C) Dead air that kills the joke
D) An absence of action with no communicative value

4. The concept of a "tight five" in comedy corresponds to:
A) An unplanned, spontaneous five minutes
B) A precision-optimized action policy: maximum prediction error per unit time, minimum wasted effort
C) Any five-minute set regardless of quality
D) A set that avoids all prediction error

5. When Costello throws up his hands in frustration, this is:
A) Not an action because it is non-verbal
B) An action at the Markov blanket that communicates his internal state (frustration) to the audience
C) An internal state invisible to others
D) An external state of the venue

6. If Costello asked Abbott "Can you spell the first baseman's name?" the likely result would be:
A) The routine would become funnier
B) The action would break the epistemic loop by generating a disambiguating observation
C) Nothing would change
D) Abbott would leave

7. Laughter from the audience is:
A) An involuntary reflex with no agentive function
B) An action that provides feedback to the performers and signals social prediction error acknowledgment
C) An external state unrelated to the routine
D) Always identical across audiences

## Part B: Short Answer

1. Explain the difference between an **epistemic action** and a **pragmatic action** using examples from "Who's on First?" Why are Costello's actions primarily epistemic while Abbott's are primarily pragmatic?

2. Describe how a comedian's action repertoire (words, pauses, gestures, facial expressions, movement) constitutes a multi-channel communication system. Which channels does Abbott primarily use?

3. A comedian walks on stage, says "Good evening," and pauses. The audience laughs. Analyze this sequence: what actions were taken, what prediction errors were generated, and why did laughter occur before any joke was told?
