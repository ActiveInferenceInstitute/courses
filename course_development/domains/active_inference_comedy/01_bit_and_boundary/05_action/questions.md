# Study Questions: Action

1. Costello's question "Who's on first?" is an **epistemic action** — an action taken to gather information. Explain why this epistemic action fails to reduce uncertainty in the routine.

2. Compare a successful epistemic action (e.g., asking "What time is it?" and getting a clear answer) to Costello's failed epistemic action. What structural difference causes the failure?

3. Abbott's responses to Costello are described as strategically selected to maximize confusion. In Active Inference terms, Abbott is selecting actions that maximize **expected free energy** for the other agent. Explain this concept.

4. The **pause** in comedy is described as "a zero-word utterance that is never zero information." What information does a comedian's pause communicate?

5. When Costello throws up his hands in frustration, is this an action in the Active Inference sense? What is its function at the Markov blanket?

6. In "Who's on First?", Costello's action policy is a fixed point: ask → hear "Who" → ask again. Describe what would happen if Costello tried a different action (e.g., "Spell the name for me").

7. Abbott's refusal to rephrase or clarify is a deliberate action. What would be the Active Inference consequences if Abbott chose to clarify?

8. Comedians describe the difference between a "hard punchline" (delivered with force) and a "soft punchline" (delivered casually). How does the intensity of the action modulate the prediction error?

9. In improv, the "Yes, And" principle requires accepting the other performer's contribution and building on it. Is Abbott doing "Yes, And" throughout the routine? Is Costello?

10. A comedian doing crowd work asks the audience "Where are you from?" This is an epistemic action. How does it differ from Costello's epistemic actions in its ability to reduce uncertainty?

11. The concept of a **tight five** — a comedian's most polished five minutes — is described as a precision-optimized action sequence. What makes an action sequence "precision-optimized"?

12. When Costello says "Third base!" he is performing an action that suggests understanding. Is this a genuine pragmatic action (he has achieved a goal) or a pseudo-action (the appearance of progress without actual model update)?

13. Compare the action repertoire of a stand-up comedian (words, pauses, gestures, movement) to the action repertoire in "Who's on First?" (primarily verbal). Does a richer action repertoire enable better comedy?

14. In Active Inference, actions change sensory observations. When Abbott says "Who," the observation it produces in Costello is identical to the previous observation. What happens to an agent when its actions cannot change its observations?

15. A heckler's shout is an unexpected action that disrupts the planned routine. How do skilled performers incorporate heckler actions into their action policy?

16. Consider the entire "Who's on First?" routine as a single action policy. Describe the policy's temporal structure: what actions come first, how do they build, and what is the terminal action?

17. The **blow line** — the routine's final, highest-impact punchline — is the terminal action. What makes it the highest-impact action? How does it depend on all preceding actions?

18. In what sense is laughter an audience action? What function does it serve in the overall system?

19. If Costello stopped asking questions entirely (ceased all action), what would happen to the routine? Can the system survive the absence of one agent's actions?

20. Compare Costello's tragic epistemic actions to a scientist running the same experiment and getting the same result every time. When is it rational to keep trying the same action?
