# Practice Quiz: Agents

## Part A: Multiple Choice

1. In "Who's on First?", Abbott is best characterized as:
A) An agent with a volatile, rapidly updating generative model
B) An agent with high-precision priors that resist revision
C) An agent with no generative model at all
D) An external state rather than an agent

2. Costello's inability to interpret "Who" as a name demonstrates:
A) Low intelligence
B) A generative model where "Who" has a strong prior as a question word, making the name interpretation improbable
C) Deliberate refusal to understand
D) A broken Markov blanket

3. The audience of "Who's on First?" functions as:
A) A passive observer with no generative model
B) A meta-inference agent that tracks both performers' models simultaneously
C) An internal state of the routine
D) An agent identical to Costello

4. The comedy of the routine arises primarily from:
A) Abbott being wrong and Costello being right
B) The mismatch between two agents' generative models operating on the same observations
C) The audience's inability to understand the joke
D) Random surprise unrelated to agent models

5. If Abbott broke character and told Costello "It's a name, not a question," this would:
A) Increase the comedy by adding more prediction error
B) Resolve the model mismatch and collapse the comedic system
C) Have no effect on the routine
D) Make Costello's precision increase permanently

6. The straight man's role in comedy is analogous to:
A) A low-precision, flexible agent exploring hypothesis space
B) A fixed reference point with high precision against which the comic's volatility is measured
C) An agent that minimizes its own free energy at the audience's expense
D) A Markov blanket rather than an agent

7. A heckler during a live performance of "Who's on First?" is best modeled as:
A) An internal state of the routine
B) A blanket state that mediates between performers
C) An adversarial inference agent injecting unexpected observations into the system
D) A non-agent phenomenon

## Part B: Short Answer

1. Compare and contrast Abbott's and Costello's precision profiles. Use the concept of precision (inverse variance) to explain why their different profiles are both necessary for the routine to work.

2. The audience maintains theory-of-mind models of both performers. Describe what happens in the audience's generative model when Costello says "That's what I want to find out!" — what inference does the audience make about Costello's model, and why is this inference funny?

3. Imagine a version of "Who's on First?" with three performers: a straight man, a comic, and a "mediator" who understands both models. How would this third agent change the dynamics? Would the routine be funnier or less funny?
