## Conventions

- **Perspective**: Abbott and Costello as competing inference engines — two generative models in productive collision
- **Topics**: Agents, generative models, precision profiles, model competition, the audience as meta-agent
- **Lab Style**: Routine Analysis Lab — diagramming the competing models and their interactions
- **Audience**: Comedians, performers, comedy scholars, cognitive scientists, and the curious
- **Tone**: Smart, antic, deeply technical, never condescending

## Active Inference Focus

This module treats performers as **inference agents** — entities that maintain generative models and act on those models. The comedy of "Who's on First?" arises because Abbott and Costello maintain incompatible models of the same observations. Agents working on this module must ensure that:

- The **straight man** is characterized by high-precision priors — certainty that resists updating even under contradictory evidence
- The **comic** is characterized by a volatile, perpetually destabilized model — genuine prediction error that never resolves
- The **audience** is modeled as a third agent with a superior generative model (they see what both performers miss)
- Humor is formalized as the audience detecting a model mismatch through the Markov blanket of dialogue
- The concept of **competing generative models** is always grounded in specific exchanges from the routine

## Key Mappings for This Module

| Comedy Role | Agent Property | Formal Description |
|------------|---------------|-------------------|
| Straight man (Abbott) | High-precision agent | Priors resist revision; model is rigid by functional necessity |
| Comic (Costello) | Volatile agent | Model constantly destabilized; prediction errors accumulate without resolution |
| Audience | Meta-inference agent | Maintains a model that encompasses both performers' hidden states |
