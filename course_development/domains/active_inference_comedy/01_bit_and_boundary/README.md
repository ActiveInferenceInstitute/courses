# Bit & Boundary

> Part of **Active Inference & Comedy** | [Curriculum Home](../OVERVIEW.md)

## Overview

**Bit & Boundary** explores Active Inference through the lens of the routine as a system — the mechanics of the comedic exchange. This course is designed for comedians, performers, comedy scholars, cognitive scientists, and the curious.

**Tone**: Smart, antic, deeply technical, never condescending.
