# Agent Guidelines: Systems (Bit & Boundary)

## Conventions

- **Perspective**: The routine as a dynamical system — the mechanics of how a comedy exchange holds together as a bounded, self-sustaining entity
- **Topics**: Systems, Markov blankets, internal/external states, system boundaries
- **Lab Style**: Routine Analysis Lab — mapping the boundary structure of "Who's on First?"
- **Audience**: Comedians, performers, comedy scholars, cognitive scientists, and the curious
- **Tone**: Smart, antic, deeply technical, never condescending

## Active Inference Focus

This module introduces the foundational concept: comedy as a **bounded dynamical system**. The Markov blanket concept maps directly onto the dialogue boundary of a routine. Agents working on this module must ensure that:

- The **system** (not the performers or audience) is the primary object of analysis
- **Dialogue** is consistently treated as the Markov blanket separating internal from external states
- **Internal states** include both performers' generative models and accumulated exchange history
- **External states** include audience, cultural context, and venue
- Every formal concept is grounded in a specific moment from "Who's on First?"

## Key Mappings for This Module

| Comedy Element | System Concept | Example |
|---------------|---------------|---------|
| The routine | Bounded dynamical system | "Who's on First?" persists as a coherent entity across decades |
| Spoken dialogue | Markov blanket | Abbott's "Who's on first" crosses from internal belief to public behavior |
| Abbott's model | Internal state (high precision) | He knows the names with certainty |
| Costello's model | Internal state (misspecified) | He parses "Who" as a question word |
| The audience | External state | They infer the mismatch through the blanket |
