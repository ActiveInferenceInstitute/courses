## Learning Objectives

1. **Analyze** how the phoneme "Who" is parsed differently by agents with different generative models — the core likelihood degeneracy of the routine
2. **Understand** perceptual inference as the process by which observations are mapped to hidden states through a model
3. **Identify** how comedic timing exploits the temporal dynamics of perception — the speed at which prediction error registers
4. **Distinguish** between what is acoustically present (the sound) and what is perceptually inferred (the meaning)
5. **Connect** perceptual ambiguity in comedy to broader phenomena of model-dependent perception in everyday life

## Key Terms

- **Perceptual inference**: The process of inferring hidden states from sensory observations using a generative model
- **Likelihood degeneracy**: When a single observation is equally consistent with multiple hidden causes
- **Auditory parsing**: How the brain segments and interprets continuous speech into meaningful units
- **Prior-dependent perception**: The phenomenon where what you expect to hear shapes what you actually hear
- **Prediction error**: The signal generated when perceived input diverges from the model's prediction
