Key Concepts

Punchline Velocity +

The speed at which a punchline arrives carries meaning: fast delivery creates surprise through acceleration; slow delivery through delayed resolution.

Velocity is a deliberate action parameter the performer controls for desired comedic effect.

Centrality

The Pause as Action +

A pause is not inaction — it builds prediction precision. Long pauses create enormous expectation; subsequent delivery must match that energy.

Mastering the pause is mastering the physics of comedic tension.

Centrality

Rhythmic Delivery +

Setup-punchline rhythms (da-da-DA) create entrainment. When the audience expects DA, the performer can delay, accelerate, or substitute.

Rhythmic patterns are the temporal scaffold comedy actions deviate from.
