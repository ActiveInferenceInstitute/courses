## Learning Objectives

1. **Explain** cognitive rhythm as the brain's temporal prediction model — detecting and extrapolating regular patterns in dialogue
2. **Connect** beat detection in comedy dialogue to musical beat detection — the same neural architecture processes both
3. **Analyze** anticipatory processing at multiple time horizons: next syllable, next exchange, routine arc
4. **Apply** temporal prediction hierarchies to joke structure — setups establish rhythms, punchlines violate them
5. **Evaluate** how comedians intuitively exploit cognitive beat structures even without formal knowledge of temporal cognition

## Key Terms

- **Cognitive rhythm**: The brain's automatic detection and extrapolation of temporal patterns in speech and dialogue
- **Beat detection**: The neural process of identifying regular temporal intervals in a stream of events
- **Anticipatory processing**: Cognitive preparation for predicted future events at multiple time scales
- **Temporal prediction hierarchy**: Nested predictions at different time scales (milliseconds, seconds, minutes) running simultaneously
- **Rhythm violation**: Breaking an established temporal pattern to generate temporal prediction error

## Prerequisites

- Modules 01-03 in Timing & Tension — temporal systems, agent roles, and precision windows
- Musical experience (even casual listening) helps ground the concept of beat and rhythm in comedy
