## Learning Objectives

1. **Understand** comedy as a temporal dynamical system where the state variables include the precise temporal arrangement of exchanges
2. **Analyze** the acceleration pattern in "Who's on First?" — exchanges speed up as confusion mounts, building audience arousal
3. **Connect** rhythmic structure in comedy to precision accumulation — regular rhythms set temporal expectations that violations exploit
4. **Measure** concrete temporal features: pause durations between exchanges, exchange rates per minute, laugh onset latencies
5. **Evaluate** why timing is not decoration on the comedy system but the system itself — change the timing, change the comedy

## Key Terms

- **Temporal dynamical system**: A system whose state variables include the precise timing of events, not just their content
- **Precision weighting on temporal predictions**: The confidence assigned to expectations about WHEN events will occur
- **Rhythmic precision accumulation**: Regular temporal patterns build high precision, making violations (timing breaks) more surprising
- **Exchange rate acceleration**: The increase in dialogue speed as confusion and energy build in a routine
- **Temporal prediction error**: Surprise generated when an event occurs earlier or later than the model predicted
