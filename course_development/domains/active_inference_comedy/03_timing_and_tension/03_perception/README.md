## Learning Objectives

1. **Explain** precision windows as temporal intervals during which the audience accumulates confidence about what comes next
2. **Analyze** the pause-punchline relationship as precision accumulation followed by prediction error delivery
3. **Identify** anticipation as a measurable perceptual state — held breath, leaned-forward posture, focused attention
4. **Distinguish** between too-early delivery (low precision, weak error) and too-late delivery (precision decays, attention drifts)
5. **Connect** temporal precision windows to the comedian's intuitive sense of "waiting for the right moment"

## Key Terms

- **Precision window**: A temporal interval during which the audience builds confidence about upcoming events
- **Temporal precision accumulation**: The process by which regular patterns build increasingly confident temporal predictions
- **Anticipation**: The perceptual state of high temporal precision before an expected event — the audience is primed for surprise
- **Optimal pause length**: The duration that maximizes precision accumulation without crossing into precision decay
- **Precision decay**: The loss of temporal confidence when a pause extends too long — attention drifts and the moment is lost
