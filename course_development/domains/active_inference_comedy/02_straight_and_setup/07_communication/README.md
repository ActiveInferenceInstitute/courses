## Learning Objectives

1. **Catalog** the performer's parallel communication channels: verbal, prosodic, gestural, postural, facial, and temporal
2. **Analyze** cross-channel contradiction as an additional source of prediction error (deadpan delivery, ironic tone)
3. **Understand** silence as deliberate communication — its meaning shifts with context (processing, anticipation, frustration, comic timing)
4. **Compare** Abbott's vocal communication profile (authority, patience, certainty) with Costello's (uncertainty, overload, questioning)
5. **Evaluate** how reduced-channel formats (podcast, text) force comedians to compensate for lost communication dimensions

## Key Terms

- **Multi-channel communication**: Simultaneous information transmission through voice, body, face, and timing
- **Cross-channel contradiction**: When different channels carry conflicting signals (e.g., serious face with absurd words), generating additional prediction error
- **Silence as communication**: The deliberate use of pauses to communicate processing, anticipation, or comic timing
- **Channel reduction**: The loss of communication dimensions in non-live formats (podcast loses visual; text loses everything but words)
- **Prosodic communication**: Information carried by pitch, stress, rhythm, and intonation patterns
