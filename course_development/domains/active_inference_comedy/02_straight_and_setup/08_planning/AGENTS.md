## Conventions

- **Perspective**: Building a set — the practical, embodied process of designing an action policy for a specific performance context
- **Topics**: Set construction as policy architecture, contingency planning, script vs. spontaneity, career planning
- **Lab Style**: Performance Workshop — set-building exercises where you design and critique comedy action policies
- **Audience**: Comedians, performers, comedy scholars, cognitive scientists, and the curious
- **Tone**: Smart, antic, deeply technical, never condescending

## Active Inference Focus

Planning in comedy operates at multiple scales: the individual joke (microseconds), the set (minutes), and the career (years). Each level involves the same core computation: anticipating the audience's model and selecting actions to maximize the gap between expectation and experience. Agents working on this module must ensure that:

- **Set construction** is treated as action policy architecture — selecting, ordering, and transitioning between material
- **Contingency planning** is formalized as policy branching — pre-computing alternative sequences deployed based on observations
- The **tension between script and spontaneity** is modeled as the relationship between planned trajectory and real-time model predictive control
- **Career planning** is treated as long-horizon policy optimization in an uncertain, evolving environment
