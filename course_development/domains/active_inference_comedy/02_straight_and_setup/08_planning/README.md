## Learning Objectives

1. **Construct** a comedy set as an action policy: selecting material, ordering it, planning transitions, and designing the energy arc
2. **Apply** contingency planning as policy branching — pre-computing alternative sequences for different audience responses
3. **Analyze** the tension between script and spontaneity as the relationship between planned trajectory and real-time adaptation
4. **Evaluate** the Netflix comedy special as a meticulously planned artifact that still feels spontaneous
5. **Connect** career planning to long-horizon policy optimization — how "finding your voice" is the convergence of a career-scale policy

## Key Terms

- **Set construction**: Building a comedy set as a planned sequence of material with deliberate ordering and energy arc
- **Contingency planning**: Pre-computing alternative action sequences to deploy based on real-time audience observations
- **Model predictive control**: Using a model to plan a trajectory, then adjusting moment-to-moment based on actual observations
- **Energy arc**: The planned emotional trajectory of a set — how it builds, peaks, and resolves across its duration
- **Tight five**: A comedian's most refined five-minute set — a precision-optimized, lowest-free-energy action sequence
