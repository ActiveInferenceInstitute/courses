## Learning Objectives

1. **Understand** reading the room as active perceptual inference — estimating hidden audience states from sparse, noisy signals
2. **Identify** the performer's multi-modal sensory channels: auditory, visual, haptic, and temporal
3. **Analyze** different laughter patterns (early, delayed, partial, absent) as evidence about the audience's generative model
4. **Explain** Abbott's perceptual strategy as deliberate precision weighting — setting incoming signals from Costello to near-zero precision
5. **Connect** crowd work to epistemic action — actions performed specifically to gather perceptual data about the room

## Key Terms

- **Reading the room**: Real-time estimation of the audience's model state through multi-modal sensory evidence
- **Multi-modal fusion**: Integrating auditory, visual, and haptic information into a unified percept of the audience
- **Precision-weighted perception**: Attending to signals that inform the model while attenuating noise
- **Audience state estimation**: Inferring the audience's mood, expectations, and readiness to laugh from observable cues
- **Epistemic action in crowd work**: Asking the audience questions to gather data about their generative model

## Prerequisites
