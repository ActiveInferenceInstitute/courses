## Learning Objectives

1. **Understand** rehearsal as progressive model refinement — increasing precision on lower-level performance features until they automatize
2. **Analyze** audience feedback as the comedian's primary training signal — continuous evaluation that shapes the action policy
3. **Map** the comedian's career onto the exploration-exploitation trade-off: broad early sampling, mid-career voice-finding, late-career mastery
4. **Evaluate** mentorship as compressed model transfer — how experienced comedians transmit decades of learning efficiently
5. **Connect** deliberate practice in comedy to broader principles of skill acquisition through structured learning episodes

## Key Terms

- **Rehearsal as model refinement**: Progressively increasing precision on performance features through repetition
- **Audience feedback**: The continuous evaluation signal (laughter, silence, groans) that trains the performer's action policy
- **Exploration-exploitation trade-off**: The balance between trying new material (exploration) and refining proven material (exploitation)
- **Automatization**: The process by which rehearsed behaviors become procedural, freeing cognitive resources for adaptation
- **Compressed model transfer**: Mentorship as the efficient transmission of a refined generative model from expert to novice

## Prerequisites
