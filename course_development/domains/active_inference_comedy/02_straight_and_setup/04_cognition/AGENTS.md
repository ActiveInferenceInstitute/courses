# Agent Guidelines: Cognition (Straight & Setup)

> **Quick Navigation**: [Module README](./README.md) | [Course AGENTS](../AGENTS.md) | [Domain AGENTS](../../AGENTS.md)

## Conventions

- **Perspective**: The straight man's cognitive discipline — dual-track cognition, cognitive load management, theory of mind
- **Topics**: Dual-track cognition (character model + meta-model), cognitive load, theory of mind, corpsing
- **Lab Style**: Performance Workshop — exercises that reveal the cognitive demands of comedy performance
- **Audience**: Comedians, performers, comedy scholars, cognitive scientists, and the curious
- **Tone**: Smart, antic, deeply technical, never condescending

## Active Inference Focus

Every performer runs two simultaneous cognitive tracks: the character's model and the performer's meta-model. This module reveals the cognitive demands hidden behind the Markov blanket of character. Agents working on this module must ensure that:

- **Dual-track cognition** is vividly described — the character's simple model running alongside the performer's complex meta-model
- **Cognitive load management** is explained through rehearsal and automatization — how practice frees resources for adaptation
- **Theory of mind** is presented as the comedian's core cognitive skill — modeling what the audience expects and when their predictions will fail
- **Corpsing** (breaking character) is analyzed as a meta-model breach — the performer's amusement leaking through the character's blanket
