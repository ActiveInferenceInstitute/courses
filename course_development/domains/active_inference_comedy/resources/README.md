## How to Use These Resources

- **Before writing content**: Consult the glossary and notation table to ensure terminological consistency
- **Before citing sources**: Check references.md for existing citations and formatting conventions
- **Before adding cross-references**: Consult cross_course_map.md for the correct link targets
- **When encountering unfamiliar terms**: The glossary maps every comedy term to its Active Inference equivalent

## Core Mappings (Quick Reference)

| Comedy Term | Active Inference Concept |
|------------|------------------------|
| Setup | Prediction-generating utterance |
| Punchline | Prediction error delivery |
| Timing / Beat | Precision weighting on temporal predictions |
| Callback | Prior reactivation -- previously resolved prediction error re-instantiated |
| Bombing | Failed prediction error -- the audience's model successfully predicted the punchline |
| Reading the room | Active perceptual inference about the audience's generative model |

## Prerequisites

These resources assume no prior knowledge of either comedy theory or Active Inference. They are designed to be accessible entry points for:

- **Comedians and performers** seeking a formal framework for what they already do intuitively
- **Cognitive scientists** seeking a rich applied domain for Active Inference
- **The curious** seeking to understand why things are funny
