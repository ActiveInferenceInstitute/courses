# Agent Guidelines: Resources

> **Quick Navigation**: [Curriculum Home](../OVERVIEW.md) | [Domain AGENTS](../AGENTS.md)

## Conventions

- **Purpose**: Shared reference materials for all 5 courses in the Active Inference & Comedy curriculum
- **Authority**: These files are canonical -- module content must not contradict them
- **Maintenance**: Update glossary, notation, and references as courses expand
- **Tone**: Reference material -- clear, precise, and navigable

## Resource Files

| File | Purpose | Update Policy |
|------|---------|--------------|
| `glossary.md` | Comedy-Active Inference term definitions | Update when any module introduces a new term |
| `notation_table.md` | Canonical notation mapping comedy terms to AI concepts | Update when a new mapping is established |
| `references.md` | Foundational references in comedy theory and Active Inference | Update when a new source is cited |
| `cross_course_map.md` | How modules connect across all 5 courses | Update when cross-references are added |
| `faq.md` | Frequently asked questions | Update based on learner feedback |
| `learning_pathways.md` | Entry points for different backgrounds | Update as new pathways are identified |

## Content Standards

1. **Glossary entries** must include both the comedy term and its Active Inference mapping
2. **Notation** must be consistent across all 5 courses -- if "setup" maps to "prediction-generating utterance," this holds everywhere
3. **References** must include both comedy theory sources (comedy craft books, performance studies) and Active Inference sources (FEP literature, computational neuroscience)
4. **Cross-course links** must use correct relative paths and be bidirectional

## Key Principles

- Comedy terminology comes first; Active Inference formalism illuminates it
- Surprise equals prediction error -- this is the foundational mapping
- Callbacks equal generative model updating -- prior reactivation generating fresh prediction error
- Timing equals precision weighting on temporal predictions -- the audience's confidence about WHEN things will happen
- The glossary and notation table are the single source of truth for all terminology decisions
