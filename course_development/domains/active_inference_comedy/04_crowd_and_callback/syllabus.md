# Syllabus: Crowd & Callback

## Course Description

Expands from individual agents to collective dynamics. Examines the audience as a social organism, crowd work as interaction, and comedy as cultural communication.

## Weekly Schedule

| Week | Topic | Focus |
| --- | --- | --- |
| 1 | Systems | The Comedy Ecosystem |
| 2 | Agents | The Audience as a Collective Agent |
| 3 | Perception | Social Perception in Live Comedy |
| 4 | Cognition | Shared Cognition and Collective Laughter |
| 5 | Action | Crowd Work as Social Action |
| 6 | Learning | Cultural Learning Through Comedy |
| 7 | Communication | Comedy as Social Communication |
| 8 | Planning | Planning for Groups: Set Design for Diverse Audiences |

## Assessment

- **Study Questions**: 20 per module (160 total)
- **Practice Quizzes**: 1 per module (8 total)
- **Labs**: 1 per module (8 total)
