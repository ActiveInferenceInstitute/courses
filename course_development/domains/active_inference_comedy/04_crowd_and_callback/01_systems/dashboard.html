Key Concepts

Crowd as Coupled System +

An audience is not a collection of individuals but a coupled dynamical system. Once laughter cascades, individual prediction patterns synchronize into collective behavior.

The coupled system exhibits emergent properties — crowd energy, collective mood, shared expectations — that no individual audience member generates alone.

Centrality

Callback as System Memory +

Callbacks are references to earlier material that create temporal links within the system. They function as shared memory — the audience re-activates previous prediction patterns, generating compounded surprise.

Callbacks work because the audience has internalized earlier material into their generative model.

Centrality

Contagion Dynamics +

Laughter spreads through the crowd like a contagion — one person's laughter lowers the threshold for neighbors. This creates non-linear amplification that the performer can trigger and ride.

Understanding contagion dynamics lets performers strategically trigger cascade effects.
