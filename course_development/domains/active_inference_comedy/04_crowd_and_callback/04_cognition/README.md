## Learning Objectives

1. **Understand** shared cognition through the lens of Active Inference and social dynamics and collective inference
2. **Analyze** how cognition manifests in "Who's on First?" from the Crowd & Callback perspective
3. **Apply** callback to practical comedy craft and performance
4. **Connect** collective model updating to broader patterns in comedy as cultural practice
5. **Evaluate** how the Crowd & Callback perspective on cognition reveals dynamics invisible from other vantage points

## Key Terms

- **Shared cognition**: Cognitive processing distributed across multiple agents who build a collective model
- **Callback**: A reference to a prior joke that reactivates a previously resolved prediction error -- requires collective memory
- **Collective model updating**: The process by which an audience collectively revises its model based on new comedy input
- **Group theory of mind**: The comedian's model of the COLLECTIVE audience mind, not just individual minds
- **Shared memory**: The collective retention of prior jokes that enables callbacks and running gags to function

## Prerequisites
