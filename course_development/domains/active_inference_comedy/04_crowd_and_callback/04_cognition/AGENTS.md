## Conventions

- **Perspective**: Social comedy -- audience, ensemble, cultural transmission
- **Topics**: Shared cognition, collective model updating, the callback as shared memory, group theory of mind
- **Lab Style**: Audience Dynamics Lab
- **Audience**: Comedians, performers, comedy scholars, cognitive scientists, and the curious
- **Tone**: Smart, antic, deeply technical, never condescending

## Active Inference Focus

The audience engages in shared cognition -- they build a collective generative model of the performance that no individual constructed alone. The CALLBACK is the supreme demonstration: it works only because the audience collectively remembers a prior joke. Agents working on this module must ensure that:

- Every Active Inference concept is grounded in a concrete comedic experience from the Crowd & Callback perspective
- The social dynamics and collective inference lens reveals dynamics invisible from other vantage points
- "Who's on First?" is referenced substantively through the Crowd & Callback perspective
- Comedy terminology is used correctly alongside Active Inference formalism

## Key Mappings for This Module

| Comedy Concept | Active Inference Mapping |
|---------------|------------------------|
| Shared cognition | Cognitive processing distributed across multiple agents who build a collective model |
| Callback | A reference to a prior joke that reactivates a previously resolved prediction error -- requires collective memory |
| Collective model updating | The process by which an audience collectively revises its model based on new comedy input |
