# Thermodynamic Inference

> Part of **Active Inference for Metallurgy** | [Curriculum Home](../README.md)

## Overview

**Thermodynamic Inference** explores Active Inference through the lens of phase equilibria, transformation kinetics, and calphad. This course is designed for Thermodynamics specialists and computational materials scientists.
