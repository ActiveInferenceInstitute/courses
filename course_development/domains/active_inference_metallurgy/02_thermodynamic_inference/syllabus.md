# Syllabus: Thermodynamic Inference

> Part of **Active Inference for Metallurgy**

## Course Overview

This unit covers Active Inference through the lens of phase equilibria, transformation kinetics, and calphad. It is designed for Thermodynamics specialists and computational materials scientists.

## Schedule

| Week | Module | Topic |
| --- | --- | --- |
| 1 | Systems | Phase Diagrams as Generative Models |
| 2 | Agents | Chemical Species as Inference Agents |
| 3 | Perception | Thermal Analysis and Calorimetric Sensing |
| 4 | Cognition | Phase Stability Computation and CALPHAD Cognition |
| 5 | Action | Phase Transformation Kinetics as Thermodynamic Action |
| 6 | Learning | CALPHAD Assessment and Machine Learning |
| 7 | Communication | Interface Energy and Thermodynamic Signaling |
| 8 | Planning | TTT and CCT Diagram Planning |

## Assessment

- Weekly practice quizzes (self-assessment)
- Laboratory exercises (hands-on application)
- Discussion questions (analytical and applied)

## Prerequisites

- Undergraduate-level materials science or physical metallurgy
- Basic thermodynamics (Gibbs free energy, phase diagrams)
- Familiarity with Python for computational exercises
