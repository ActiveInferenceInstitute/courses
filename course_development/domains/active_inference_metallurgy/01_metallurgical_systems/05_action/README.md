## Learning Objectives

1. **Define** action in the Active Inference framework and map it onto plastic deformation and alloying processes
2. **Apply** Schmid's law as a policy selection mechanism — predicting which slip system activates to reduce applied stress
3. **Analyze** work hardening as increasing action cost due to dislocation density accumulation
4. **Explain** solid solution strengthening as raising the action threshold (CRSS) through solute-dislocation interactions
5. **Distinguish** between the material's spontaneous action (deformation under stress) and the metallurgist's intentional action (processing interventions)
6. **Calculate** resolved shear stress and predict slip system activation for a given crystal orientation and loading direction

## Key Concepts

- **Slip as action policy**: The crystal selects the slip system that most efficiently reduces the prediction error (applied stress)
- **Work hardening as action cost**: Dislocation forest hardening increases the driving force required for further deformation
- **Twinning as alternative action**: When slip is insufficient, the crystal selects mechanical twinning as an alternative deformation mode
- **Alloying as compositional action**: Intentional modification of chemistry to achieve target properties
