# Metallurgical Systems

> Part of **Active Inference for Metallurgy** | [Curriculum Home](../README.md)

## Overview

**Metallurgical Systems** explores Active Inference through the lens of crystal structures, defects, and fundamental thermodynamics. This course is designed for Materials science graduate students and metallurgical engineers.
