## Learning Objectives

1. **Trace** the historical arc of alloy development from Bronze Age empiricism to computational materials design as a progressive model-learning process
2. **Identify** Hume-Rothery rules as informative priors that constrain the search for solid solution alloys
3. **Explain** how the discovery of high-entropy alloys challenged existing generative models and forced paradigm revision
4. **Connect** modern materials informatics (ML for alloy prediction) to automated Active Inference learning
5. **Evaluate** the role of surprise-driven discovery in metallurgical history (metallic glasses, quasicrystals, shape memory alloys)
6. **Describe** the CALPHAD database refinement cycle as iterative Bayesian model learning

## Key Concepts

- **Historical learning**: Each era of metallurgy represents a deeper generative model with greater predictive power
- **Hume-Rothery rules as priors**: Atomic size, electronegativity, and valence rules constrain alloy solubility predictions
- **High-entropy alloys as surprise**: Multi-principal-element alloys forced revision of the assumption that dilute solutions dominate
- **Materials informatics**: Machine learning automates the learning cycle across large composition-property datasets

## Prerequisites

- Modules 01-05 (prior modules in Metallurgical Systems)
- Basic history of metallurgy (Bronze Age, Iron Age, steel age, modern alloy development)
