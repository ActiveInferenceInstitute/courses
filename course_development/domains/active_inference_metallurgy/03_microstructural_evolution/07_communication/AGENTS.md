## Active Inference Integration

The grain boundary network is the communication infrastructure of a polycrystalline material. Triple junctions are network nodes where three grain boundaries meet, forming the vertices of the communication graph. Percolation theory applies: if high-diffusivity (random high-angle) boundaries form a connected path through the microstructure, they create a high-bandwidth communication channel for intergranular corrosion, crack propagation, or impurity transport. Grain boundary engineering disrupts these percolation paths by increasing the fraction of low-energy CSL boundaries (especially Sigma-3 twins), effectively reconfiguring the communication network to limit damage propagation.

| FEP Concept | Grain Boundary Network Translation |
|-------------|-------------------------------------|
| Communication Network | Grain boundary network topology (nodes = triple junctions, edges = boundary segments) |
| Communication Channel | Individual grain boundary segment with characteristic diffusivity and energy |
| Network Percolation | Connected path of high-angle boundaries enabling corrosion or crack propagation |
| Channel Engineering | Grain boundary engineering — increasing twin fraction to break percolation paths |
| Signal Propagation | Intergranular diffusion, stress transmission, or corrosion front advancement |
| Network Topology | Grain boundary character distribution (GBCD) as the network's statistical signature |

## Content Guidelines

- Frame the grain boundary network as a graph with measurable topological properties (connectivity, clustering coefficient, percolation threshold)
- Treat grain boundary engineering as communication network optimization — disrupting harmful percolation paths while maintaining material integrity
- Connect triple junction character (types I, II, III based on constituent boundary types) to network node properties
- Emphasize that EBSD-derived grain boundary maps provide a direct experimental measurement of the communication network, enabling quantitative network analysis
