## Active Inference Integration

Grain boundaries are the Markov blankets of polycrystalline materials at the mesoscale. Each grain is an autonomous system with its own crystallographic orientation (internal state), separated from neighboring grains by boundaries that mediate all communication. The misorientation angle and boundary plane define the character of this Markov blanket — high-angle boundaries are thick, opaque blankets while low-angle boundaries are thin, translucent ones. Coincidence site lattice (CSL) boundaries represent special cases where the two grains share partial structural information across the boundary, creating privileged communication channels.

## Key Mappings

| FEP Concept | Grain Boundary Translation |
|-------------|---------------------------|
| Markov Blanket | Grain boundary (high-angle, low-angle, twin, CSL) |
| Internal States | Crystallographic orientation, intragranular composition, dislocation substructure |
| External States | Neighboring grain orientations, applied stress, temperature field |
| System Identity | Grain as a coherent crystallographic domain with unique orientation |
| Boundary Permeability | Grain boundary diffusivity; segregation tendency; boundary mobility |
| Nested Systems | Subgrains within grains within colonies within the component |

## Content Guidelines

- Frame the grain boundary character distribution (GBCD) as a statistical description of the Markov blanket population in a polycrystalline system
- Treat twin boundaries (Sigma-3) as low-energy Markov blankets that the system preferentially forms to minimize total boundary energy
- Connect grain boundary engineering to the deliberate design of Markov blanket properties — modifying the GBCD to improve macroscopic properties
- Emphasize that the polycrystalline microstructure is a multi-agent system where each grain's behavior depends on its neighbors through the grain boundary network
