# Microstructural Evolution

> Part of **Active Inference for Metallurgy** | [Curriculum Home](../README.md)

## Overview

**Microstructural Evolution** explores Active Inference through the lens of nucleation, grain growth, precipitation, and characterization. This course is designed for Microscopists, characterization engineers, and microstructure scientists.
