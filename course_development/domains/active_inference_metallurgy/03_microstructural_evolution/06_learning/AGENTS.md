## Active Inference Integration

Adaptive characterization embodies Active Inference in the laboratory. The microscopist begins with a prior model of the expected microstructure, collects initial data (low-magnification overview), identifies regions of high uncertainty or surprise, and then targets high-resolution imaging to those specific regions. 4D imaging (3D volume + time via serial sectioning, synchrotron X-ray computed tomography, or in-situ TEM) provides the temporal dimension that transforms static perception into dynamic learning — the microscopist watches the microstructure evolve and updates their generative model of the transformation kinetics in real time.

## Key Mappings

| FEP Concept | Adaptive Characterization Translation |
|-------------|--------------------------------------|
| Learning | Updating the microstructural model with new characterization data |
| Active Sensing | Adaptive sampling — targeting high-uncertainty regions for high-resolution imaging |
| Prior Model | Expected microstructure based on processing conditions and previous experience |
| Temporal Learning | 4D imaging tracking microstructural evolution through time |
| Surprise | Unexpected feature discovered during characterization (anomalous grain, unknown phase) |
| Model Refinement | Revising grain growth kinetics or phase fraction predictions based on in-situ observations |

## Content Guidelines

- Frame serial sectioning as building a 3D generative model of the microstructure slice by slice, with each new slice providing evidence that refines the volumetric model
- Treat synchrotron 4D-XCT as the ultimate active perception tool — non-destructive, time-resolved, and capable of resolving internal microstructural dynamics
- Connect in-situ TEM heating/straining experiments to real-time model learning — the microscopist observes transformation dynamics and updates kinetic parameters on the fly
- Emphasize that autonomous microscopy (AI-driven adaptive scanning) implements Active Inference algorithmically, selecting the next scan location to maximize information gain
