## How to Use These Resources

1. **Before writing module content**: Consult the notation table and glossary to ensure consistent terminology.
2. **When introducing a new term**: Add it to the glossary with both its Active Inference and metallurgical definitions.
3. **When citing literature**: Use the references file to ensure APA format and avoid duplicate entries.
4. **When linking across modules**: Use the cross-course map to identify relevant parallel treatments.

## Key Conceptual Bridge

The central insight of this curriculum is the structural isomorphism between thermodynamic free energy and variational free energy. Both are functionals that systems minimize. The notation table explicitly marks where the same symbol (e.g., F for free energy) carries dual meaning, and the glossary provides disambiguation for each context.
