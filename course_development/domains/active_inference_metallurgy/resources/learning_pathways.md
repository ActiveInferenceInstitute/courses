# Learning Pathways: Active Inference for Metallurgy

> Suggested routes through the curriculum based on your background and goals.

---

## Pathway 1: Materials Science Graduate Student

**Goal**: Build a deep, multi-scale understanding from atoms to factory.

1. Start with **C1: Metallurgical Systems** (all 8 modules) — build atomic-scale foundations
2. Continue to **C2: Thermodynamic Inference** — understand phase diagrams as generative models
3. Move to **C3: Microstructural Evolution** — connect thermodynamics to observable microstructure
4. Finish with **C4: Process Optimization** — apply everything to real manufacturing

---

## Pathway 2: Process Engineer

**Goal**: Apply Active Inference thinking to manufacturing and quality.

1. Start with **C4: Process Optimization** Module 01 (Systems) — frame your process as an inference system
2. Read **C2: Thermodynamic Inference** Module 01 (Systems) — understand why phase diagrams matter
3. Work through **C4** Modules 02–08 — sensors, digital twins, control, optimization
4. Supplement with **C3** Module 03 (Perception) and Module 05 (Action) for characterization and kinetics

---

## Pathway 3: Computational Materials Scientist

**Goal**: Master the computational tools through an inference lens.

1. Start with **C2: Thermodynamic Inference** (all 8) — CALPHAD, phase stability, ML
2. Move to **C3: Microstructural Evolution** Module 04 (Cognition) — phase-field and Monte Carlo
3. Study **C4** Module 04 (Cognition) and Module 06 (Learning) — digital twins and closed-loop control
4. Review **C1** for physical foundations as needed

---

## Pathway 4: Theory-First (Active Inference Researcher)

**Goal**: Understand how FEP applies to physical materials systems.

1. Read **C1: Metallurgical Systems** Module 01 (Systems) — the crystal lattice as Markov blanket
2. Read the same Module 01 across all 4 courses using the [Cross-Course Map](./cross_course_map.md)
3. Study Module 05 (Action) across all 4 courses — physical inference in action
4. Study Module 07 (Communication) across all 4 courses — diffusion as message passing

---

## Pathway 5: Quick Overview (1 day)

**Goal**: Get the main ideas fast.

1. Read **C1 Module 01** (Systems) — 30 min
2. Read **C2 Module 01** (Systems) — 30 min
3. Read **C2 Module 05** (Action) — 30 min
4. Read **C4 Module 01** (Systems) — 30 min
5. Review the [Glossary](./glossary.md) and [Cross-Course Map](./cross_course_map.md) — 30 min
