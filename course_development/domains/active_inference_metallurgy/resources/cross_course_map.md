# Cross-Course Map: Active Inference for Metallurgy

> How the same 8 Active Inference topics manifest across all 4 courses.
> Use this map to study the same concept from multiple metallurgical perspectives.

---

## Module 01: Systems

| Course | Title | Focus |
|--------|-------|-------|
| C1: Metallurgical Systems | Crystal Lattices as Markov Blankets | Unit cells, crystal boundaries, atomic-scale systems |
| C2: Thermodynamic Inference | Phase Diagrams as Generative Models | Equilibrium maps, stability fields, compositional systems |
| C3: Microstructural Evolution | Grain Boundaries as System Boundaries | Polycrystalline architecture, grain boundary character |
| C4: Process Optimization | Manufacturing Process as Inference System | Furnace, rolling mill, or printer as bounded system |

**Cross-cutting theme**: Every metallurgical system — from an atom in a lattice to a factory floor — is defined by its boundary. The Markov blanket framework reveals what flows in (heat, stress, chemistry) and what flows out (phase transformations, deformation, products).

---

## Module 02: Agents

| Course | Title | Focus |
|--------|-------|-------|
| C1: Metallurgical Systems | Atoms and Defects as Agents | Vacancies, dislocations, solute atoms as active entities |
| C2: Thermodynamic Inference | Chemical Species as Inference Agents | Diffusing elements seeking equilibrium partitioning |
| C3: Microstructural Evolution | Nuclei as Autonomous Agents | Critical nuclei as emergent agents with agency |
| C4: Process Optimization | Sensors and Controllers as Agents | Thermocouples, pyrometers, PLC controllers |

**Cross-cutting theme**: Agents are entities that act to minimize free energy. At the atomic scale, this is literal thermodynamics. At the process scale, sensor-controller pairs enact the same logic algorithmically.

---

## Module 03: Perception

| Course | Title | Focus |
|--------|-------|-------|
| C1: Metallurgical Systems | X-Ray Diffraction and Spectroscopy | Crystallographic structure determination |
| C2: Thermodynamic Inference | Thermal Analysis and Calorimetry | DSC, DTA — sensing phase transitions |
| C3: Microstructural Evolution | Microscopy and EBSD | Imaging grain structure and orientation |
| C4: Process Optimization | In-Situ Monitoring and NDT | Real-time process sensing, ultrasonic testing |

**Cross-cutting theme**: All metallurgical knowledge depends on observation. Each characterization technique is a "sensory organ" with its own precision, resolution, and blind spots.

---

## Module 04: Cognition

| Course | Title | Focus |
|--------|-------|-------|
| C1: Metallurgical Systems | Lattice Energy Calculations | First-principles DFT, interatomic potentials |
| C2: Thermodynamic Inference | Phase Stability Computation | CALPHAD, Thermo-Calc, computational equilibria |
| C3: Microstructural Evolution | Microstructure Prediction Models | Phase-field, Monte Carlo, cellular automata |
| C4: Process Optimization | Digital Twin Cognition | Process simulation, surrogate models, ML |

**Cross-cutting theme**: Cognition is the model's internal processing — computing beliefs about hidden states from observed data. Metallurgical cognition ranges from ab initio quantum mechanics to factory-floor digital twins.

---

## Module 05: Action

| Course | Title | Focus |
|--------|-------|-------|
| C1: Metallurgical Systems | Deformation and Alloying | Slip, twinning, solid solution strengthening |
| C2: Thermodynamic Inference | Phase Transformation Kinetics | Nucleation, growth, TTT/CCT curves |
| C3: Microstructural Evolution | Grain Growth and Coarsening | Normal/abnormal grain growth, Ostwald ripening |
| C4: Process Optimization | Heat Treatment and Quenching | Austenitizing, quenching, tempering, aging |

**Cross-cutting theme**: Action is how systems change the world to match their predictions. Metals "act" through phase transformations and deformation; engineers act through processing decisions.

---

## Module 06: Learning

| Course | Title | Focus |
|--------|-------|-------|
| C1: Metallurgical Systems | Alloy Development History | Historical progression from bronze to superalloys |
| C2: Thermodynamic Inference | CALPHAD and Machine Learning | Database assessment, ML-accelerated discovery |
| C3: Microstructural Evolution | Adaptive Characterization | Serial sectioning, 4D synchrotron, in-situ TEM |
| C4: Process Optimization | Closed-Loop Process Control | Adaptive control, reinforcement learning for manufacturing |

**Cross-cutting theme**: Learning is updating the generative model based on prediction error. Materials science has learned over millennia; CALPHAD databases and ML models accelerate this learning.

---

## Module 07: Communication

| Course | Title | Focus |
|--------|-------|-------|
| C1: Metallurgical Systems | Diffusion and Mass Transport | Fick's laws, atomic migration, interdiffusion |
| C2: Thermodynamic Inference | Interface Energy Signaling | Interfacial free energy, wetting, segregation |
| C3: Microstructural Evolution | Grain Boundary Networks | Triple junctions, percolation, GB engineering |
| C4: Process Optimization | SCADA and Data Pipelines | Industrial IoT, process data communication |

**Cross-cutting theme**: Communication is how subsystems exchange information. Atoms communicate via diffusion; grains communicate via boundary networks; factories communicate via SCADA systems.

---

## Module 08: Planning

| Course | Title | Focus |
|--------|-------|-------|
| C1: Metallurgical Systems | Alloy Design Strategies | Compositional design, property targets |
| C2: Thermodynamic Inference | TTT/CCT Diagram Planning | Transformation scheduling, cooling path design |
| C3: Microstructural Evolution | Microstructure Engineering | Grain size control, texture design, precipitation |
| C4: Process Optimization | Process Route Optimization | Multi-step schedule optimization, digital thread |

**Cross-cutting theme**: Planning is selecting policies (processing routes) that minimize expected free energy — achieving target properties while accounting for uncertainty.
