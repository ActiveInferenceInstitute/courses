# AGENTS.md -- Section 2: Creative Engineering

## Section Identity

This section covers the creative process of inventing through the Active Inference framework. It is the second of four sections in the Active Inference for Inventions course.

## Content Guidelines

### Tone and Voice
- Authoritative but accessible: explain technical concepts clearly without oversimplifying
- Theory-grounded but practice-oriented: every concept should connect to real inventive work
- Inclusive: content must work for inventors from any background or domain
- Evidence-based: use real case studies, not hypothetical examples

### Active Inference Integration
- Every module maps one pillar of Active Inference (systems, agents, perception, cognition, action, learning, communication, planning) to creative practice
- Use precise Active Inference terminology (generative model, prediction error, free energy, Markov blanket, precision weighting, expected free energy) with clear definitions
- Always bridge from theory to practice: "In Active Inference terms, this means..." followed by "For inventors, this means..."

### Case Study Standards
- Use real inventions with verifiable histories
- Include both classic examples (Edison, Wright brothers) and contemporary ones (SpaceX, Samsung)
- Analyze each case study through the Active Inference lens, not just as narrative
- Each module.md should contain at least two detailed case studies

### Lab Design Principles
- "Bring your own invention" approach: every exercise should work for any domain
- Use {fill:textarea} placeholders for student responses
- Include structured tables for analysis
- Target approximately 60 minutes total
- Include discussion/debrief questions

### Question Design
- Questions 1-10: Analytical (test understanding of framework and theory)
- Questions 11-20: Applied (self-reflection, project-based, experiential)
- All questions should be unique and specific to the module's theme
- Avoid generic questions that could apply to any topic

### Dashboard Standards
- Accent color: #10b981 (emerald green)
- Dark theme with consistent CSS variables
- 5+ concept cards with centrality meters
- 7 quiz questions with explanations
- 5 learning objective checkboxes with localStorage persistence
- Module grid showing all 8 modules with current module highlighted
- localStorage keys: cl-s2m[1-8]
