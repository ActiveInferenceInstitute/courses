Communication as Model Alignment

Invention communication is an Active Inference process: the inventor generates actions (words, images, demos) that serve as sensory evidence for the audience, systematically updating the audience's generative model toward the inventor's understanding. The key challenge is bridging the prior model mismatch — the inventor's rich, internalized model versus the audience's sparse or differently-structured model.

The Invention Narrative

Six-part story structure maps to prediction error management: Setup (establish shared prior), Tension (reveal prediction error), Insight (offer model update), Solution (describe new predictions), Evidence (confirm predictions), Vision (extend model forward). Steve Jobs's iPhone launch followed this structure precisely, updating the audience's model of smartphones in real time.

Visual Communication

Diagrams, sketches, and storyboards make abstract model components directly perceivable. System diagrams show structure, flowcharts show dynamics, storyboards show user experience, before/after comparisons show value. Leonardo da Vinci's annotated drawings remain effective centuries later because they function as shared generative model artifacts.

Patent Claims as Model Descriptions

Independent patent claims describe the Markov blanket of an invention — the minimal essential structure. Dependent claims specify parameters within that structure. Prior art is the existing generative model; the patent's novelty is the specific model update. Understanding this correspondence helps write clearer claims and read competitors' patents more effectively.

Audience-Adaptive Communication

Different audiences have different prior models. Technical peers share domain knowledge (focus on what is new). Investors model financial returns (translate to market terms). Users model their own needs (show value before mechanism). Patent examiners require legal precision (no ambiguity). Effective communication adapts to the audience's model rather than delivering a fixed message.

The Elevator Pitch

A 30-second to 2-minute compressed model-alignment action. Must convey: the problem (shared prior), the insight (model update), the solution (new predictions), and the ask/vision (forward projection). Airbnb learned to manage prediction errors sequentially in their pitch rather than presenting the full counterintuitive concept at once.
