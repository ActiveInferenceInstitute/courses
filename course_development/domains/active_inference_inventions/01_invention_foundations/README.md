# Section 1: Invention Foundations

**Understanding inventions as adaptive systems -- problem spaces, boundaries, and the inventor-environment relationship.**

## Overview

This section establishes the foundational framework for understanding invention through the lens of Active Inference. Before building, before testing, before scaling, the inventor must understand what an invention is, who they are as an inventive agent, and how the fundamental processes of perception, cognition, action, learning, communication, and planning operate in the inventive context.

Each module applies one of the eight Active Inference spine topics to the practice of invention, building a vocabulary and toolkit that will be used throughout the course. By the end of this section, students will have a systems-level understanding of the inventive process, a profile of their own inventive agency, and a concrete roadmap for their invention project.

## Learning Arc

The eight modules build on each other in a deliberate sequence:

1. **Systems** establishes the ontology: what is an invention as a system?
2. **Agents** positions the inventor within this ontology: who is doing the inventing?
3. **Perception** develops the first cognitive skill: how do inventors detect problems?
4. **Cognition** develops the second: how do inventors reason about causes and solutions?
5. **Action** bridges thinking and doing: how do prototypes test cognitive models?
6. **Learning** closes the perception-action loop: how does evidence update the model?
7. **Communication** extends the loop to other agents: how are models shared?
8. **Planning** projects the loop into the future: how do inventors navigate uncertainty?

## Files Per Module

Each module directory contains:

- `module.md` -- Rich lecture content with case studies and Active Inference integration (2500+ words)
- `lab.md` -- Hands-on exercises using the "bring your own invention" approach
- `questions.md` -- 20 study questions (10 analytical, 10 applied)
- `practice_quiz.md` -- 7 multiple choice + 3 short answer questions
- `dashboard.html` -- Interactive web dashboard with concepts, quiz, checklist, and navigation

## Design Principles

- **Inclusive**: All exercises work for any background. If you are a baker, you invent a baking tool. If an engineer, an engineering device. If an artist, an artistic tool.
- **Evidence-based**: Every concept connects to real invention case studies, from Edison's light bulb to SpaceX's rocket program.
- **Active**: Labs are hands-on -- students build, test, observe, and iterate, not just read and reflect.
- **Cumulative**: Each module builds on the previous, and the lab outputs accumulate into a project portfolio.
