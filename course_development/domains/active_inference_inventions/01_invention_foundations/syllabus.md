# Syllabus: Section 1 -- Invention Foundations

**Course**: Active Inference for Inventions
**Section**: 01 -- Invention Foundations
**Theme**: Understanding inventions as adaptive systems -- problem spaces, boundaries, and the inventor-environment relationship

## Section Description

This section introduces the Active Inference framework as a principled methodology for invention. Students will learn to see inventions as adaptive systems with Markov blankets, to understand themselves as agents with generative models and preferred states, and to apply the full perception-cognition-action-learning cycle to their own inventive projects. The section culminates in a personal invention roadmap grounded in expected free energy minimization.

## Prerequisites

- No technical background required
- Students should bring an invention idea or be prepared to develop one during Module 01
- Openness to hands-on building and iterative revision

## Learning Outcomes

Upon completion of this section, students will be able to:

1. Analyze any invention as a system with identifiable Markov blanket, sensory states, active states, and nested subsystems
2. Profile their own inventive agency -- identifying generative models, prior preferences, identity priors, and blind spots
3. Detect unmet needs through systematic prediction error identification and evidence gathering
4. Reason causally about invention problems using mental models, reframing techniques, and counterfactual reasoning
5. Design and execute minimum viable prototypes as hypothesis tests
6. Document learning systematically through iteration logs that distinguish parameter from structure learning
7. Communicate inventive ideas effectively to diverse audiences through pitching, documentation, and demonstration
8. Plan invention projects under uncertainty using expected free energy, staged development, and adaptive roadmaps

## Module Schedule

### Module 01: The Invention as a Living System
- **Reading**: module.md (Markov blankets, nested systems, free energy and persistence)
- **Lab**: Mapping the Markov Blanket of Your Invention (~60 min)
- **Key Concepts**: System, Markov blanket, sensory/active states, nested systems, accuracy-complexity trade-off
- **Case Studies**: Edison's electric lighting system, the smartphone as nested system

### Module 02: The Inventor as an Adaptive Agent
- **Reading**: module.md (generative models, prior preferences, identity, multi-agent invention)
- **Lab**: Profiling Your Inventive Agent (~60 min)
- **Key Concepts**: Agent, generative model, prior preferences, identity prior, multi-agent collaboration
- **Case Studies**: The Wright Brothers, the Post-it Note (Silver and Fry)

### Module 03: Seeing What Others Miss
- **Reading**: module.md (active perception, chronic prediction errors, active sensing, precision weighting)
- **Lab**: The Prediction Error Hunt (~60 min)
- **Key Concepts**: Active perception, prediction error, fresh eyes, active sensing, precision, signal vs. noise
- **Case Studies**: The pulse oximeter (Aoyagi), IDEO shopping cart redesign

### Module 04: Thinking Like an Inventor
- **Reading**: module.md (inference over hidden causes, mental models, reframing, cognitive flexibility)
- **Lab**: Causal Reasoning and Problem Reframing Workshop (~60 min)
- **Key Concepts**: Hidden cause inference, mental model, problem reframing, functional fixedness, counterfactual reasoning
- **Case Studies**: Automotive crumple zones (Barenyi), penicillin development (Fleming/Florey/Chain)

### Module 05: From Idea to Intervention
- **Reading**: module.md (active inference as world-changing, prototypes as hypotheses, the perception-action loop)
- **Lab**: Building Your First Minimum Viable Prototype (~60 min)
- **Key Concepts**: Active inference, prototype as hypothesis, MVP, epistemic vs. pragmatic value, informative failure
- **Case Studies**: Wright Brothers' systematic prototyping, Chuck Hull and 3D printing

### Module 06: Learning from Every Attempt
- **Reading**: module.md (prediction error as learning engine, parameter vs. structure learning, learning protocols)
- **Lab**: The Iteration Log (~60 min)
- **Key Concepts**: Prediction error, parameter learning, structure learning, learning trajectory, local optima
- **Case Studies**: WD-40 (40 formulations), Netflix's structural pivots

### Module 07: Sharing the Vision
- **Reading**: module.md (model alignment, pitching, documentation, demonstration, user instruction)
- **Lab**: Communicating Your Invention Across Audiences (~60 min)
- **Key Concepts**: Model alignment, precision weighting for audience, externalized model, demonstration, affordance
- **Case Studies**: Salk's polio vaccine communication, IKEA's wordless instructions

### Module 08: The Invention Roadmap
- **Reading**: module.md (expected free energy, staged development, decision trees, adaptive roadmaps)
- **Lab**: Building Your Invention Roadmap (~60 min)
- **Key Concepts**: Expected free energy, pragmatic/epistemic value, staged development, option value, planning horizon
- **Case Studies**: SpaceX's staged rocket development, the microwave oven's 20-year journey

## Assessment

### Ongoing Assessment
- Lab completion and quality of responses (each module)
- Study questions (selected questions assigned per module)
- Practice quizzes (self-assessment, not graded)

### Section Project
By the end of Section 1, each student should have:
1. A system map of their invention (from Module 01 lab)
2. An inventor agent profile (from Module 02 lab)
3. A documented prediction error hunt (from Module 03 lab)
4. A causal model with reframing analysis (from Module 04 lab)
5. A minimum viable prototype plan or result (from Module 05 lab)
6. An iteration log with at least one documented cycle (from Module 06 lab)
7. A pitch, technical description, and user instruction set (from Module 07 lab)
8. An adaptive roadmap for their invention project (from Module 08 lab)

These eight outputs compose the **Invention Foundations Portfolio**, which serves as the basis for Section 2 (Creative Engineering).
