Communication as Model Alignment

Communication means updating the listener's generative model to include the same causal relationships and predictions as the inventor's. The inventor must infer the listener's current model, predict how messages will land, and select the message that most efficiently bridges the gap. This is itself an inference problem.

Pitching: Compressing the Model

An effective pitch creates a prediction error (the problem), presents a model update (the solution), aligns preferences (the value), and establishes precision (credibility). Leading with the problem is essential because without the prediction error, the listener has no context for the technical details.

Documentation: Externalizing the Model

Patents, specifications, and design files capture different slices of the generative model for different audiences. A patent describes mechanism and prior art for an examiner. Specifications provide parameter values for manufacturers. Each document type externalizes the right level of detail for its intended reader.

Demonstration: Shared Sensory Evidence

Showing rather than telling provides direct perceptual evidence that forces model updating. Jobs's iPhone demo created prediction errors through the audience's own senses. Demonstration is especially effective for experiential inventions — those whose value must be felt rather than described.

User Instruction and Affordances

User instruction builds the correct generative model incrementally — one manageable step at a time, like IKEA's wordless assembly guides. Affordances go further: design features that communicate function through form eliminate the need for instructions entirely. A pressable-looking button is an affordance.
