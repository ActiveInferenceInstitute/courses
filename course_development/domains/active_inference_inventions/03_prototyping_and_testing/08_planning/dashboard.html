Core Concepts

1. Expected Free Energy for Test Priority

The highest-priority test resolves the largest uncertainty about the most consequential variable. Epistemic value (how much you learn) + pragmatic value (how much it matters) = expected free energy reduction. Test sensor accuracy before color preference. Test safety before aesthetics. And test cheap hypotheses before expensive ones, unless the expensive one is existential.

2. Test Protocol Design

Pre-specified document defining hypothesis, procedure, measurements, sample size, controls, success criteria, and failure criteria. Writing the protocol forces clarity about what is being tested. It prevents scope creep and creates a pre-registration record. Pharmaceutical clinical trial protocols are the gold standard, but the principle applies at any scale.

3. Resource Allocation

Greedy algorithm: allocate each resource unit to the test with the highest EFE reduction per unit cost. Plan parallel vs. sequential testing based on dependencies. Identify the critical path (longest sequential chain) to find bottlenecks. Avoid testing debt: deferred high-consequence tests accumulate interest as design decisions build on untested assumptions.

4. Regulatory Testing Integration

Non-negotiable tests with high pragmatic value. Plan early: identify requirements during design, not after prototyping. Design for compliance: if the standard requires X, design for 1.5X. Integrate regulatory tests with development tests where possible. Schedule regulatory tests strategically: too early wastes resources on immature designs; too late risks costly redesigns.

5. Comprehensive Test Planning

A unified living document integrating test inventory, priority ranking, protocols, resource budget, schedule, decision gates, and risk register. Updated as each test resolves uncertainties. NASA's Test Readiness Reviews ensure readiness before major tests. The plan provides structure without rigidity — a framework for adaptive test planning, not a fixed script.
