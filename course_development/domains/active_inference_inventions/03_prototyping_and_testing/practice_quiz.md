# Practice Quiz: Prototyping and Testing

## Part A: Multiple Choice

1. A prototype's Markov blanket determines:
A) How attractive the prototype looks
B) Which variables are included in the test and which are assumed or excluded
C) The cost of manufacturing the prototype
D) How many users will test it

2. An inventor tests their prototype and finds that all 10 users complete the task, but 7 of them use the device differently than intended. This result is best interpreted as:
A) A success -- all users completed the task
B) A prediction error -- the inventor's model of user behavior was wrong for 70% of users, revealing critical design assumptions
C) Noise -- user behavior varies naturally
D) A failure -- the prototype should be discarded

3. Which of the following best describes the difference between parameter learning and structure learning during iteration?
A) Parameter learning changes the numbers; structure learning changes the materials
B) Parameter learning adjusts variables within the current model; structure learning changes the fundamental model architecture
C) Parameter learning is for early prototypes; structure learning is for late prototypes
D) Parameter learning is cheap; structure learning is expensive

4. The sunk cost fallacy leads inventors to:
A) Test too many hypotheses at once
B) Continue investing in a failing approach because of past investment rather than future expected value
C) Prototype at too high a fidelity level
D) Skip documentation

5. A test result has high precision when:
A) The result confirms the inventor's hypothesis
B) The measurement method produces consistent, reliable readings with low noise
C) The test was conducted quickly
D) Multiple users agree that the prototype is attractive

6. An inventor must choose between testing user ergonomics (critical to adoption) and testing material durability (important for production). According to expected free energy, the inventor should first test:
A) Whichever is cheaper
B) Material durability, because production comes later
C) User ergonomics, because if users reject the device no other test matters -- this hypothesis has higher expected free energy
D) Both simultaneously, regardless of cost

7. James Dyson's 5,127 prototypes primarily demonstrate:
A) Inefficiency caused by lack of planning
B) Disciplined parameter learning with occasional structure learning, systematically reducing free energy through cumulative evidence
C) Proof that Active Inference does not apply to physical invention
D) The importance of hiring more engineers

## Part B: Short Answer

1. Explain why a cardboard mockup (low fidelity) is sometimes a better prototype than a 3D-printed functional model (high fidelity). Use the concept of matching the prototype's Markov blanket to the hypothesis being tested.

2. Describe a scenario where an inventor should pivot (abandon the current approach) rather than persevere (continue iterating). What specific evidence would trigger this decision, and how does Bayesian model comparison formalize it?

3. Toyota's A3 protocol requires engineers to fit their entire problem-solving process on a single sheet of paper. Explain how this constraint serves as a form of model compression, and why compressed models are often more useful for communication than detailed ones.
