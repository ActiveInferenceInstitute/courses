Practice Quiz: Documenting the Build

Part A: Multiple Choice

Documentation functions as an external generative model because:
A) It satisfies legal requirements
B) It enables another agent to reconstruct the inventor's understanding and continue the work
C) It makes prototypes look more professional
D) It is required for manufacturing

A lab notebook entry should include:
A) Only successful results
B) Date, hypothesis, raw observations, interpretations (separated), decisions, and open questions
C) Only final conclusions
D) Only quantitative measurements

The most common documentation gap in invention projects is:
A) Missing photographs
B) Absence of decision rationale — what was chosen is recorded but not why
C) Incorrect dates
D) Too much detail

Version control for physical prototypes includes:
A) Using Git for all physical objects
B) Photography, change logs, labeling, and preservation of previous versions
C) Destroying previous versions to save space
D) Relying on memory

Uncertainty communication in documentation means:
A) Expressing doubt about everything to avoid liability
B) Reporting both beliefs and their confidence levels so readers understand what is tested vs. assumed
C) Hiding uncertainty from stakeholders
D) Using vague language

The "reconstruction test" for documentation quality asks:
A) Can the inventor remember what they built?
B) Could another competent agent read the documentation and continue the work?
C) Is the documentation aesthetically pleasing?
D) Does the documentation fit in one page?

Architecture Decision Records (ADRs) capture:
A) Only the final decision
B) The decision, alternatives considered, evidence, uncertainties, and consequences
C) Only technical specifications
D) Only cost estimates
