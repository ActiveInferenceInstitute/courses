Practice Quiz: Documenting the Build

Part A: Multiple Choice

  1. Documentation functions as an external generative model because: A) It satisfies legal requirements B) It enables another agent to reconstruct the inventor's understanding and continue the work C) It makes prototypes look more professional D) It is required for manufacturing

  2. A lab notebook entry should include: A) Only successful results B) Date, hypothesis, raw observations, interpretations (separated), decisions, and open questions C) Only final conclusions D) Only quantitative measurements

  3. The most common documentation gap in invention projects is: A) Missing photographs B) Absence of decision rationale — what was chosen is recorded but not why C) Incorrect dates D) Too much detail

  4. Version control for physical prototypes includes: A) Using Git for all physical objects B) Photography, change logs, labeling, and preservation of previous versions C) Destroying previous versions to save space D) Relying on memory

  5. Uncertainty communication in documentation means: A) Expressing doubt about everything to avoid liability B) Reporting both beliefs and their confidence levels so readers understand what is tested vs. assumed C) Hiding uncertainty from stakeholders D) Using vague language

  6. The "reconstruction test" for documentation quality asks: A) Can the inventor remember what they built? B) Could another competent agent read the documentation and continue the work? C) Is the documentation aesthetically pleasing? D) Does the documentation fit in one page?

  7. Architecture Decision Records (ADRs) capture: A) Only the final decision B) The decision, alternatives considered, evidence, uncertainties, and consequences C) Only technical specifications D) Only cost estimates

Part B: Short Answer

  1. An inventor's lab notebook contains the entry: "Changed the gear ratio. Works better now." Rewrite this entry to meet the documentation standards described in this module. Include all elements that should be present in a proper inference log entry.

  2. You are handing your invention project to a collaborator who will work on it while you are away for three months. Using the reconstruction test framework, list the five most critical documents you would prepare to ensure they can continue your work effectively.

  3. Explain why Leonardo da Vinci's notebooks remain scientifically and technically valuable 500 years after they were written, while many modern engineering documents become obsolete within years. What documentation practices account for this difference? How does the concept of "documenting the generative model, not just the design" apply?
