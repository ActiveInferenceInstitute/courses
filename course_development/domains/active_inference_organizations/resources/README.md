# Shared Resources: Active Inference for Organizations

> Centralized reference materials for the entire curriculum.

## Purpose

This resource directory provides the shared foundation for the Active Inference for Organizations curriculum. All four course sections (Organizational Systems, Collective Intelligence, Strategic Modeling, Digital Transformation) draw on these common resources to maintain consistency in terminology, notation, and theoretical grounding.
