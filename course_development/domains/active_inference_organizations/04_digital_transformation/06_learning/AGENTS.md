## Conventions

- **Perspective**: Machine learning systems as organizational learning mechanisms — with distinct learning dynamics and failure modes
- **Topics**: ML model lifecycle, continuous learning, data flywheel, model drift, human-AI co-learning
- **Lab Style**: Implementation plan — technology assessment, architecture design, migration planning
- **Audience**: Business leaders, CTOs, digital transformation leaders, organizational scientists
- **Tone**: Professional technology/business — connecting Active Inference to digital strategy and implementation

## Domain Integration Guidelines

This module covers Machine Learning and Organizational Adaptation. All content should:

1. Frame ML model lifecycle as organizational learning: training, deployment, monitoring, and retraining as a continuous learning loop
2. Introduce the data flywheel: more users generate more data, which improves models, which attracts more users
3. Address model drift: ML models degrading over time as the environment changes and training data becomes stale
4. Design human-AI co-learning: systems where human and machine learning complement each other
5. Connect to organizational knowledge management: where does ML-learned knowledge reside, and who has access to it?

## Active Inference Concepts for This Module

- **ML lifecycle**: Training, deployment, monitoring, and retraining as organizational learning loops
- **Data flywheel**: Self-reinforcing cycle of usage, data, model improvement, and value creation
- **Model drift**: ML models degrading as the environment changes — prediction error accumulation
- **Human-AI co-learning**: Complementary learning where each improves the other
- **Knowledge governance**: Where ML knowledge resides, who accesses it, and how it is maintained
