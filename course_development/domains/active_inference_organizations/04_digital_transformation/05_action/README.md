## Learning Objectives

1. Frame automation as algorithmic action — technology executing organizational policies at scale
2. Distinguish levels of automation from manual to fully autonomous
3. Design human-machine handoff protocols for safety-critical and judgment-requiring situations
4. Diagnose automation failure modes: brittleness, complacency, and skill atrophy
5. Understand how automation reshapes organizational roles, processes, and structure

## Key Organizational Concepts

- **Algorithmic action**: Automation executing policies at machine speed
- **Automation levels**: The spectrum from manual to fully autonomous
- **Handoff protocols**: Transitioning between automated and human-driven action
- **Automation failure modes**: When technology breaks, and the human consequences
- **Organizational redesign**: How automation changes roles and processes

## Prerequisites

- Completion of Sections 1-3 (Organizational Systems, Collective Intelligence, Strategic Modeling)
- Basic familiarity with digital technology concepts (APIs, databases, cloud computing, machine learning)

## Recommended Case Studies

- **Tesla Autopilot** — automation levels and handoff failures in autonomous driving
- **UiPath and RPA** — robotic process automation in back-office operations
- **High-frequency trading** — fully autonomous action at millisecond timescales
