## Learning Objectives

1. Frame strategy as a set of testable hypotheses about competitive success
2. Apply structured assumption testing to critical strategic beliefs
3. Identify cognitive biases that distort strategic reasoning
4. Design red teaming and pre-mortem exercises for strategic challenge
5. Know when accumulated prediction error demands a strategic pivot

## Key Organizational Concepts

- **Strategy as hypothesis**: Testable beliefs about competitive value creation
- **Assumption testing**: Validating or falsifying strategic beliefs systematically
- **Strategic biases**: Confirmation bias, anchoring, overconfidence in strategy
- **Red teaming**: Adversarial challenge of strategic assumptions
- **Strategic pivot**: Revising the fundamental competitive model

## Prerequisites

- Completion of Sections 1-2 (Organizational Systems and Collective Intelligence)
- Familiarity with basic strategy concepts (competitive advantage, market analysis)

## Recommended Case Studies

- **Netflix's strategic pivots** — DVD-to-streaming as hypothesis-driven model revision
- **BlackBerry's strategic rigidity** — confirmation bias about keyboard phones
- **Intel's 'Only the Paranoid Survive'** — Grove's institutionalized strategic challenge
