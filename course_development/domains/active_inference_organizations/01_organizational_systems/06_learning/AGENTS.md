## Conventions

- **Perspective**: Organizations as adaptive entities that update their generative models based on prediction errors
- **Topics**: Single-loop vs. double-loop learning, learning loops, learning failures, designing learning systems
- **Lab Style**: Case study — learning system audit and failure diagnosis
- **Audience**: Business leaders, managers, organizational scientists
- **Tone**: Professional business/management — strategic and evidence-based

## Domain Integration Guidelines

This module examines how organizations learn — updating their generative models when prediction errors accumulate. All content should:

1. **Frame learning as model updating**: When forecasts are wrong and strategies fail, the organization should update its generative model. Distinguish parameter learning (refining existing models) from structure learning (changing the model itself)
2. **Apply Argyris's framework**: Single-loop learning (correcting errors within the current framework) versus double-loop learning (questioning the framework itself) as parameter updates versus model revision
3. **Map learning loops and cadence**: Operational (daily/weekly), tactical (monthly/quarterly), strategic (annual), and transformative (crisis-driven) learning cycles
4. **Diagnose learning failures**: Superstitious learning, competency traps, defensive routines, and learning myopia as specific patterns
5. **Design learning infrastructure**: Shorter feedback loops, signal-noise separation, rewarding informative failure, knowledge management, and safe-to-fail environments

## Active Inference Concepts for This Module

- **Model updating**: Reducing prediction error by improving the generative model
- **Parameter learning**: Refining model weights within existing structure (single-loop)
- **Structure learning**: Changing the model architecture itself (double-loop)
- **Learning loops**: Structured cadences for model updating across time horizons
- **Learning failures**: Superstitious learning, competency traps, defensive routines
