## Organizational Learning and Adaptation

Part of **Section 1: Organizational Systems**.

Organizations that learn, survive. This module examines organizational learning as the process of updating the generative model based on prediction errors. You will distinguish between single-loop learning (parameter updates within the existing model) and double-loop learning (revising the model structure itself), map your organization's learning loops, and diagnose why some organizations systematically fail to learn from experience.

## Learning Objectives

1. **Explain** organizational learning as model updating — reducing prediction error by improving the generative model
2. **Distinguish** single-loop learning (parameter updates) from double-loop learning (structure changes)
3. **Identify** learning loops and their cadence (operational, tactical, strategic, transformative)
4. **Diagnose** learning failures: superstitious learning, competency traps, defensive routines, learning myopia
5. **Design** organizational systems that accelerate and deepen learning

## Key Organizational Concepts

- **Model updating**: Learning as reducing the gap between predictions and observations
- **Single-loop vs. double-loop**: Argyris's framework mapped to Active Inference parameter vs. structure learning
- **Learning loops**: Daily standups to annual strategy reviews as structured model-updating cadences
- **Learning failures**: Why organizations fail to learn even when evidence demands change
- **Learning infrastructure**: Feedback loops, knowledge management, safe-to-fail environments
