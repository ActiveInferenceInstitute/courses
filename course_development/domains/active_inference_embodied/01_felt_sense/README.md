# Felt Sense

> Part of **Active Inference: Embodied Experience** | [Curriculum Home](../README.md)

## Overview

**Felt Sense** explores Active Inference through the lens of body awareness & interoception. This course is designed for Anyone seeking qualitative, felt understanding.

**Tone**: Somatic, poetic, experiential. First-person felt sense. Meditative. Zero equations, zero code.
