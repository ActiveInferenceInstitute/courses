# Module 05: Action

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Moving from the Inside Out

Part of **Felt Sense**.

## Learning Objectives

1. **Experience** action as the body's ongoing conversation with the environment, not a command from the brain
2. **Feel** the pre-movement impulse: the subtle bodily intention that precedes overt movement
3. **Explore** affordances: how the environment offers action possibilities to the body (Gibson)
4. **Distinguish** effortful from flowing action and connect this to prediction error in Active Inference
5. **Investigate** morphological computation: how the body's physical structure shapes action without explicit planning
6. **Discover** how movement can change inner states -- action as interoceptive regulation

## Key Concepts

- **Sensorimotor loop**: Action and perception as inseparable aspects of the same process
- **Motor intention**: The felt readiness to move before movement begins (Sheets-Johnstone)
- **Affordances**: Action possibilities offered by the environment to a specific body (Gibson)
- **Morphological computation**: Physical body structure performing computational work
- **Effort and flow**: High vs. low prediction error in motor execution
- **Action as regulation**: Movement changing the body's internal state by changing sensory input

## Prerequisites

- Completion of Modules 01-04 recommended
- A space for movement
