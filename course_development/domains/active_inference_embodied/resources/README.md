# Shared Resources: Active Inference for Embodied Experience

> Centralized reference materials for the entire curriculum, bridging Active Inference theory with embodied cognition.

## Overview

This resource collection supports all four courses in the Embodied Experience curriculum. Materials are designed for anyone seeking qualitative, felt understanding of how the body shapes cognition, perception, and action. Each resource bridges formal Active Inference concepts with experiential, phenomenological language drawn from the 4E cognition tradition (embodied, embedded, enacted, extended).

## How to Use These Resources

- **Before starting a course**: Review the glossary and notation table so that key terms are familiar.
- **During a module**: Consult the notation table for symbol definitions and the references for deeper reading.
- **Between courses**: Use the cross-course map and learning pathways to plan your next steps.
- **For research or writing**: Use the references as a starting bibliography for embodied cognition and Active Inference.
