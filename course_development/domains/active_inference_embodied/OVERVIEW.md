# Active Inference: Embodied Experience — Pedagogical Overview

## Vision

This curriculum makes Active Inference accessible to Anyone seeking qualitative, felt understanding through four complementary lenses. Each course covers the same 8 foundational topics but from a different disciplinary perspective.

## Tone & Style

Somatic, poetic, experiential. First-person felt sense. Meditative. Zero equations, zero code.
