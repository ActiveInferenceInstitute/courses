# Practice Quiz: Communication

## Part A: Multiple Choice

1. A crochet pattern's abbreviation system (sc, dc, ch, etc.) functions in Active Inference as:
A) An external state unrelated to communication
B) A shared prior — a set of conventions both writer and reader must agree on for successful model transmission
C) A purely decorative feature of the pattern
D) The Markov blanket of the communication system

2. The difference between US "single crochet" and UK "double crochet" (same abbreviation "sc"/"dc" for different stitches) illustrates:
A) That communication always succeeds
B) A potential communication failure when priors are mismatched between sender and receiver
C) That patterns do not need conventions
D) The irrelevance of shared language

3. A symbol chart transmits crochet pattern information primarily through:
A) Sequential textual instructions
B) Visual-spatial layout that mirrors the fabric structure
C) Audio signals
D) Proprioceptive feedback

4. In-person demonstrations in a crochet circle are rich communication channels because they transmit:
A) Only textual information
B) Multi-modal information: visual hand positions, verbal explanations, and real-time feedback
C) No useful information
D) Only sequential action orders

5. When a crochet circle member notices a neighbor's tension error and offers a correction, this is:
A) Unwanted interference
B) An external prediction error signal that accelerates the neighbor's model refinement
C) A communication failure
D) Unrelated to Active Inference

6. A pattern that includes both written instructions and a symbol chart uses redundant communication channels. This redundancy:
A) Adds confusion without benefit
B) Improves accuracy by allowing the reader to cross-check two different representations of the same model
C) Is wasteful and should be eliminated
D) Only helps experienced crocheters

7. When a crocheter writes pattern notes sharing modifications they made, they are:
A) Destroying the original pattern
B) Communicating generative model updates to the community
C) Ignoring the pattern entirely
D) Performing active inference on the yarn

## Part B: Short Answer

1. Describe how teaching a beginner to make a double crochet requires externalizing an automatic motor model into explicit communicable steps. What information is hardest to convey?

2. Compare the precision characteristics of three communication channels: a written pattern, a symbol chart, and a video tutorial. For each, identify what aspect of the generative model it conveys best and what it leaves implicit.

3. A crocheter discovers an error in a published pattern (the stitch count given does not match the instructions). Describe how they use their own generative model to detect and resolve this communication error.
