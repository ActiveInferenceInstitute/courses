## Content Guidelines

This module examines how crocheters **communicate** craft knowledge: pattern notation as a shared generative model, symbol charts vs. written instructions as different communication channels, and the crochet circle as a knowledge-sharing network.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Written pattern notation (ch 3, dc in next st) | Shared generative model encoded in symbols |
| Symbol charts vs. written patterns | Different communication channels with different precision |
| Verbal demonstration ("watch me do this stitch") | High-bandwidth, multi-modal model transmission |
| Crochet circle sharing techniques | Knowledge network propagating generative models |
| Standard abbreviations (sc, dc, tr) | Compressed encoding of action sequences |
| Errata and pattern corrections | Updating a shared model to fix prediction errors |

### Craft Integrity

- Respect pattern notation as a genuine language with its own grammar, conventions, and regional dialects (US vs. UK terminology).
- Acknowledge that communication in crochet is multi-modal: written, visual (charts), verbal, and hands-on demonstration each carry different information.
- The crochet circle is a real-world example of distributed knowledge sharing — treat it with the seriousness this social structure deserves.
- When discussing communication, always ground it in real pattern notation and real teaching scenarios.
