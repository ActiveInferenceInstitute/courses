## Learning Goals

1. **Interpret** crochet pattern notation as a shared generative model — a common language that encodes action sequences and predicted outcomes
2. **Compare** written patterns, symbol charts, and verbal demonstrations as different communication channels with different precision
3. **Appreciate** how the crochet circle functions as a knowledge-sharing network that propagates and refines generative models
