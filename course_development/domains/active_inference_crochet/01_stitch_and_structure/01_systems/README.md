## Learning Goals

1. **Identify** the boundary between your crochet work and its environment
2. **Recognize** how hook, yarn, and hands form an interacting system
3. **Map** the Markov blanket concept onto the edge of your fabric
4. **Distinguish** internal states (completed fabric) from external states (unworked yarn, environment)
5. **Explain** how gauge swatching calibrates the system before committing to a project

## Key Crochet Terminology

- **Working edge**: The live row currently being stitched — the active boundary of the project
- **Live loop**: The loop sitting on the hook; if it slips off, the fabric can unravel
- **Gauge swatch**: A test piece crocheted to check stitch dimensions before starting a project
- **Frogging**: Ripping out stitches (from "rip it, rip it") — dissolving internal states back into yarn
- **Foundation chain**: The starting chain that establishes the initial width of the fabric

## Prerequisites

- Ability to hold a crochet hook and yarn
- Basic familiarity with chain stitch (ch) — or willingness to learn during the module

## Materials Needed

- Crochet hook (size H/8 or 5.0mm recommended for beginners)
- Medium-weight (worsted) yarn in a light color
- Scissors
- Stitch markers (optional)
