## Content Guidelines

This module focuses on the **motor dimension** of crochet: each stitch as a policy execution, hook insertion as action selection, and frogging as corrective action. Every pull of yarn through a loop is an act that transforms the state of the world.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Single stitch (insert, YO, pull through) | Policy execution — a specific motor sequence |
| Hook insertion angle and depth | Action parameters selected by the agent |
| Yarn over technique | Motor policy component |
| Frogging an entire section | Corrective action to reduce accumulated prediction error |
| Choosing sc vs. dc vs. hdc | Action selection from a policy repertoire |
| Turning the work at row end | Transition action between policy sequences |

### Craft Integrity

- Slow down the stitch to reveal its motor complexity — even a simple single crochet involves insert, yarn over, pull through, yarn over, pull through two. Each sub-movement is a decision.
- Use the language of crochet stitch abbreviations (sc, dc, hdc, tr) as natural labels for different action policies.
- Treat frogging with the seriousness it deserves — it is not failure but a sophisticated corrective strategy.
- Connect the physical action of crocheting to the Active Inference principle that agents act on the world to make it match their predictions.
