## Learning Goals

1. **Recognize** each stitch as a policy execution that transforms the fabric
2. **Analyze** hook insertion angle and yarn over technique as components of motor policy
3. **Understand** frogging as corrective action — the agent actively reshaping the world to match its model
4. **Compare** different stitch types (sc, dc, hdc, tr) as different action policies with distinct outcomes
5. **Practice** deliberate, slow-motion stitching to observe the micro-decisions within each stitch

## Key Crochet Terminology

- **Yarn over (YO)**: Wrapping the yarn around the hook — the fundamental motor action within every stitch
- **Insert hook**: Placing the hook into the target stitch of the previous row, selecting where to act
- **Pull through**: Drawing yarn through loops on the hook, completing a sub-step of the stitch
- **Turning chain**: Chain stitches worked at the beginning of a row to gain height for the new row
- **Back loop / front loop only (BLO/FLO)**: Inserting the hook into only one loop, altering texture and behavior

## Prerequisites

- Completion of Modules 01-04 or comfort with chain, single crochet, and double crochet
- Familiarity with basic pattern notation

## Materials Needed

- Crochet hook (size H/8 or 5.0mm)
- Medium-weight (worsted) yarn in a light color (to see stitch detail)
- Scissors
- Small work-in-progress for frogging practice
