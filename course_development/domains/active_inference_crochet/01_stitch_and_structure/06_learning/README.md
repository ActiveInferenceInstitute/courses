## Learning Goals

1. **Describe** muscle memory in crochet as precision tuning of the generative model's motor predictions
2. **Explain** how learning a new stitch expands the generative model to accommodate new action-outcome mappings
3. **Connect** gauge calibration to prior updating — adjusting baseline expectations through experience
