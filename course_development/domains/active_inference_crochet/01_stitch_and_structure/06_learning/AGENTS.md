## Content Guidelines

This module explores how crochet skill develops over time: muscle memory as precision tuning, learning a new stitch as model expansion, and gauge calibration as prior updating. Crochet learning is visible and tangible — you can see your skill grow across the rows of a project.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Muscle memory for basic stitches | Precision tuning — motor predictions becoming automatic |
| Learning a new stitch (e.g., popcorn, bobble) | Generative model expansion with new action-outcome mappings |
| Gauge swatch practice | Prior updating — calibrating baseline expectations |
| First project vs. tenth project | Model refinement over time |
| Watching a tutorial and then trying | Observation-based model building followed by action-based testing |
| Getting faster and more even over time | Increasing precision of motor and perceptual predictions |

### Craft Integrity

- Celebrate the learning journey — everyone starts with wobbly chains, and every expert was once a beginner.
- Use real examples of skill progression: the first swatch vs. the hundredth, the first garment vs. the project that finally fits.
- Connect muscle memory to Active Inference without diminishing it — "your hands have learned to predict" is both scientifically precise and craft-respectful.
- Gauge swatch practice is the crocheter's most explicit act of model calibration. Treat it as such.
