- **Tone**: Warm, crafty, hands-on, accessible

## Content Guidelines

This module positions the crocheter as a **free energy minimizing agent**. The pattern held in mind is the generative model; stitch counting is belief updating; frogging is prediction error correction. The crocheter is not passive — they actively shape the world to match their expectations.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| The crocheter sitting down to work | Free energy minimizing agent |
| Written or memorized pattern | Generative model |
| Stitch counting at end of row | Belief updating / state estimation |
| Frogging (rip it, rip it) | Prediction error correction |
| Deciding "that's a design feature" | Model updating (accommodation) |
| Following a new pattern for the first time | Operating with a sparse generative model |
| Tink vs. frog decision | Policy selection under Active Inference |

### Craft Integrity

- Frame the crocheter as an intelligent, adaptive agent — never as a mere instruction-follower.
- Use the crocheter's own vocabulary: frogging, tinking, WIP, FO, gauge, tension.
- Honor the two-way nature of error correction: sometimes you change the work, sometimes you change the plan. Both are valid inference strategies.
- Respect that experienced crocheters carry deep generative models built over years of practice.
