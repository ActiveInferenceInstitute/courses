Key Concepts

Topological Surfaces in Crochet +

Crochet creates genuine topological surfaces — flat discs, spheres, tori, hyperbolic planes. Each stitch increase/decrease pattern produces a surface with specific Gaussian curvature properties.

A flat circle requires exactly 6 increases per round in single crochet — too few and it cups (positive curvature, tending toward a sphere), too many and it ruffles (negative curvature, creating a hyperbolic surface). The Euler characteristic (V − E + F) classifies these surfaces: flat discs (χ=1), spheres (χ=2), tori (χ=0). Crochet is one of the few crafts that can physically realize all of these topologies.

Centrality: Foundational concept

Fabric as Network Graph +

Every crocheted fabric is a graph: stitches are nodes, yarn connections are edges. This graph structure directly mirrors neural network architecture — dense single crochet vs sparse mesh patterns.

The degree of each node (how many edges connect to it) corresponds to the stitch type: a single crochet connects to fewer neighbors than a treble crochet. Mesh patterns with chain spaces create sparse graphs with long-range connections, while solid fabric creates dense, locally-connected graphs. This directly parallels the architecture choices in neural networks: fully connected layers vs sparse, convolutional architectures.

Centrality: Structural bridge

Markov Blanket Boundaries +

The edge of a crocheted piece forms a Markov blanket — the statistical boundary that separates internal fabric structure from the external environment, mediating all interactions between inside and outside.

In Active Inference, a Markov blanket partitions a system into internal states, external states, and the blanket itself (sensory and active states). A crocheted piece's edge is precisely this: it separates the internal fabric structure from everything outside, while mediating all interactions (adding new rows, joining pieces, wearing the garment). The blanket concept maps directly onto the topological boundary.
