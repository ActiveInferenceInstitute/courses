Key Concepts

Architecture Before Stitching +

Planning a project starts with choosing topology: flat vs 3D, rows vs rounds, mesh vs solid. These architectural decisions constrain everything that follows — like choosing a neural network type before training.

Just as a neural network designer must choose between feedforward, recurrent, or convolutional architectures before writing code, a crocheter must choose between flat surfaces, spheres, tori, or hyperbolic forms. Working in rows is feedforward; working in the round is recurrent. Mesh is sparse connectivity; solid fabric is dense. Each choice constrains all downstream possibilities.

Centrality: Foundational planning principle

Euler Characteristic as Planning Tool +

The Euler characteristic (V − E + F = χ) is a concrete planning tool: it predicts the shaping requirements for flat discs (χ=1), spheres (χ=2), tori (χ=0), and hyperbolic surfaces before a single stitch is made.

For a flat single-crochet circle, 6 increases per round maintains flatness. For a sphere, increases in the first half must be exactly reversed by decreases in the second half. For a torus, positive curvature on the outer rim must cancel negative curvature on the inner rim. The Euler characteristic provides the total "curvature budget" — an architectural blueprint constraining all shaping decisions.

Centrality: Mathematical planning tool

Expected Free Energy in Project Selection +

Choosing a project involves balancing pragmatic value (will it succeed?) against epistemic value (will I learn?). This is expected free energy minimization — the core of Active Inference planning.

A familiar blanket is low uncertainty but perhaps low reward. A sculptural amigurumi is high uncertainty but high novelty. Making a gauge swatch has high epistemic value (reduces uncertainty). Starting with the hardest section has high epistemic value (fail early if it won't work). Experienced crocheters intuitively plan in sequences that minimize expected free energy at each step.
