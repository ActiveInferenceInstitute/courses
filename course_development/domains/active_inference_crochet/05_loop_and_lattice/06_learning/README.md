## Learning Goals

1. **Understand** crochet skill acquisition as analogous to neural network training — practice as training epochs, corrections as gradient steps
2. **Recognize** how prediction errors drive learning in both crochet and neural networks
3. **Map** concepts like overfitting, learning rate, and generalization to crochet experience
