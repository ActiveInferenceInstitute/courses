Key Concepts

Tactile Curvature Sensing +

Experienced crocheters perceive curvature through touch — sensing whether fabric lies flat, cups, or ruffles. This is perception of topology through the Markov blanket of the hands.

The crocheter's fingers are sensory receptors at the Markov blanket: they detect yarn tension, stitch height, fabric drape, and resistance to stretching. When fabric cups unexpectedly, the sensory evidence ("this feels wrong") generates prediction error against the generative model ("this should be flat"). The crocheter does not need to see the curvature — hands detect it through touch alone, a direct perceptual channel for topological information.

Centrality: Core perceptual mechanism

Visual Pattern Recognition +

Reading a crochet pattern is visual perception of a compressed network description — translating symbols into a mental model of the fabric's graph structure before a single stitch is made.

A written crochet pattern like "ch 3, 5 dc in ring, sl st to join" compresses a complex graph specification into a few symbols. The experienced crocheter visually parses these symbols and constructs a mental 3D model of the intended fabric structure — essentially decompressing a network architecture specification. This is learned visual perception, completely opaque to untrained eyes.

Centrality: Information processing

Error Detection as Prediction Failure +

Noticing a mistake in fabric is perceiving prediction error — the observed stitch pattern deviates from the expected pattern generated by the crocheter's internal generative model.

The crocheter's generative model continuously predicts what the next stitch should look and feel like. When actual sensory input (visual appearance, hand feel, stitch count) deviates from prediction, surprise is generated. A missed increase produces unexpected curvature; a wrong stitch count triggers a recount. This error-detection mechanism is Active Inference in its most literal form: perception driven by prediction error minimization.

Centrality: Active Inference integration
