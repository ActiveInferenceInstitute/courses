## Content Guidelines

This module positions the crocheter as a **neural architect** — an agent who designs, selects, and physically builds network architectures in yarn. The crocheter's brain is a neural network designing another network, and each stitch placement is a decision node governed by Active Inference.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| The crocheter choosing stitch type and placement | Agent selecting network parameters (weights) |
| Tension control | Activation function tuning |
| Deciding where to increase or decrease | Network architecture decisions (adding/pruning nodes) |
| The crocheter's brain modeling the fabric structure | Neural network (brain) modeling another network (fabric) |
| Stitch selection minimizing surprise | Active inference — choosing actions that match predictions |
| Expert vs. beginner architectural choices | Model depth determining design sophistication |

### Craft Integrity

- The crocheter-as-neural-architect metaphor is powerful but must remain grounded: every architectural decision starts with a stitch in the hands, not a diagram on a whiteboard.
- Use real design decisions: choosing between a granny square grid and a spiral construction, deciding stitch density for structural integrity vs. drape.
- Acknowledge that the crocheter's own neural network (their brain) is the ultimate architect — the fabric network is a tangible externalization of internal computational structure.
