## Content Guidelines

This module examines the **mental models** crocheters build of the finished piece — how they visualize the final object before stitching, predict how repeats will tile across a surface, and hold the entire project structure in mind while working one stitch at a time.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Visualizing the finished piece before starting | Running the generative model forward in imagination |
| Understanding how a pattern repeat tiles | Structural prediction across spatial dimensions |
| Holding the project plan in mind while stitching | Multi-level generative model (stitch, row, section, whole) |
| Re-reading the pattern after getting confused | Model re-loading when internal state becomes uncertain |
| Predicting how a stitch modification will change the fabric | Counterfactual inference within the generative model |
| Comparing mental image to actual work-in-progress | Comparing predictions to observations |

### Craft Integrity

- Honor the mental complexity of pattern cognition — crocheters simultaneously track where they are in the current row, how that row relates to the overall pattern, and what the finished piece should look like.
- Use sketch-before-you-stitch exercises to make the generative model's predictions visible and testable.
- Acknowledge that some crocheters are highly visual (they see the finished piece), some are sequential (they think in steps), and some are spatial (they feel the shape) — all are valid cognitive styles.
