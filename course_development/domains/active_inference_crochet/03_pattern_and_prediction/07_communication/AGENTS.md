## Content Guidelines

This module examines **pattern languages as shared code** — how crochet notation systems function as communication protocols for transmitting generative models between crafters. The pattern is a message, and its notation is the language.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Standard crochet abbreviations (sc, dc, ch) | Compressed encoding of action sequences |
| Symbol charts | Spatial communication channel for pattern structure |
| Written vs. charted patterns | Different communication modalities for the same model |
| US vs. UK terminology differences | Dialect variation in model encoding |
| Video tutorials | Multi-modal, high-bandwidth model transmission |
| Pattern testing by other crocheters | Communication verification — does the receiver reconstruct the sender's model? |

### Craft Integrity

- Treat crochet notation as a real language with grammar, conventions, and expressive power — it is not casual shorthand but a precise communication system.
- Address the US/UK terminology confusion directly (US single crochet = UK double crochet) as a concrete example of communication failure when shared codes diverge.
- Acknowledge the role of video and in-person demonstration as communication channels that convey information written patterns cannot: rhythm, tension, hand position.
