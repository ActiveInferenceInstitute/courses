## Learning Goals

1. **Explain** pattern notation systems (US vs UK terms, charts vs written) as different encoding schemes for the same generative model
2. **Identify** the standardization problem in crochet notation as a coordination challenge between communicating agents
3. **Describe** pattern sharing platforms and communities as distributed systems for model transmission and refinement
