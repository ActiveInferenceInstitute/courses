# Practice Quiz: Pattern & Prediction

**Name**: _________________________ **Date**: _________________________

## Part A: Multiple Choice

1. A crochet pattern is best described in Active Inference terms as:
A) A random collection of instructions
B) A generative model — a structured set of predictions about how inputs produce a finished object
C) The finished object itself
D) The yarn used in the project

2. When a crocheter reads "Row 3: sc2tog across," they are:
A) Passively following orders without any cognitive involvement
B) Generating a prediction about what the row will produce (decreased stitch count, narrowing fabric) and preparing to verify it
C) Ignoring the pattern
D) Constructing a new Markov Blanket

3. A pattern that produces good results for many different crocheters with different tensions is:
A) A pattern that ignores gauge
B) A robust generative model that accommodates variation in the generative process
C) A pattern with no instructions
D) A pattern that only works for the designer

4. The gauge section of a pattern serves as:
A) Decorative filler
B) A calibration specification that aligns the crocheter's generative process with the pattern's predictions
C) An optional suggestion with no practical value
D) A measure of the pattern's difficulty

5. Modifying a pattern (e.g., changing a neckline) requires the crocheter to:
A) Ignore all other parts of the pattern
B) Update the generative model and trace how the modification propagates through related instructions
C) Start the entire project over
D) Use a different yarn

6. Stitch charts and written instructions are:
A) Completely unrelated notation systems
B) Two different encodings of the same generative model, each making different aspects more accessible
C) Used only by beginners and experts respectively
D) Identical in all respects

7. Yardage estimation before starting a project is an example of:
A) Perception — updating beliefs about the current state
B) Action — changing the fabric
C) Planning — predicting future resource requirements based on the generative model
D) Communication — sharing the pattern with others

## Part B: Reflective Response

1. Choose a crochet pattern you have worked from (or find one online). Identify three specific predictions the pattern makes about the finished object. For each, describe what a violation of that prediction would look like and how you would respond.

2. Describe a time you modified a crochet pattern. What was the modification, what predictions did you have to update, and did the modification produce the result you expected? Analyze this experience in Active Inference terms.

3. Imagine you are writing a pattern for the first time. What information must you include to ensure that someone with different hands, different yarn, and different experience can reproduce your result? How does this relate to the concept of a generative model that must accommodate multiple generative processes?
