# Lab: Pattern Design Workshop — Building and Testing a Generative Model

## Introduction

In this lab, you will work with crochet patterns as generative models. You will read a pattern as inference, modify a pattern as model updating, and begin designing your own simple pattern as model construction. By the end, you will understand why pattern-writing is the most sophisticated generative modeling task in crochet.

> **Intention:** By the end of this lab, you will have analyzed a pattern's structure as a generative model, predicted outcomes before stitching, tested those predictions against reality, modified a pattern and traced the consequences, and drafted a simple original pattern.

## Materials

* A simple crochet pattern (a dishcloth, coaster, or small swatch pattern — approximately 10-20 rows)
* Crochet hook and yarn appropriate for the pattern
* Ruler or gauge tool
* Graph paper or grid paper (for charting)
* Pencil and eraser
* Notebook for reflections

### Part 3: Pattern Modification (15 minutes)

> **Intention:** Update the generative model and trace the consequences.

1. Choose one modification to make to the pattern:
   - Change the stitch (e.g., replace single crochet with half-double crochet)
   - Add a border
   - Change the dimensions (add or remove rows/stitches)
   - Add a color change

2. Before implementing: write down what you predict the modification will change about the finished object. Consider: gauge, size, texture, stitch count, yarn consumption.

3. Implement the modification for at least 3 rows.

4. Compare the result to your prediction.

{fill:textarea}
**Reflection**: Did the modification produce unexpected consequences? What "ripple effects" did you discover? In Active Inference terms, modifying one part of a generative model often requires updating other parts to maintain consistency. What parts needed updating that you did not anticipate?

1. Materials list (yarn weight, hook size)

### Part 5: Chart vs. Written (10 minutes)

> **Intention:** Compare two encodings of the same model.

1. If your pattern from Part 4 is written in text, create a stitch chart for the first 5 rows using graph paper (one square per stitch, using standard chart symbols: x for sc, T for dc, o for chain).
2. If you started with a chart, write out the text instructions.

## Discussion Questions

1. How does writing a pattern change your experience of following someone else's pattern? Do you read patterns differently now that you have tried writing one?
2. What makes a pattern "good" in Active Inference terms? Is it the one that is most detailed, the most flexible, or the one that best matches your skill level?
3. If two crocheters follow the same pattern and get different results, where does the difference come from? How does this illustrate the distinction between generative model and generative process?
