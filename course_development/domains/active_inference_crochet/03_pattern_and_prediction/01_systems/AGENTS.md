## Conventions

- **Perspective**: Pattern reading, design, mathematical structure of crochet
- **Topics**: Systems
- **Lab Style**: Pattern Design Workshop
- **Audience**: Fiber artists, crafters, crochet circle participants, and the curious
- **Tone**: Warm, crafty, hands-on, accessible

## Content Guidelines

This module presents the crochet pattern as a **complete system** — a generative model that specifies inputs (materials), transformations (stitch sequences), and predicted outputs (the finished object). The pattern is not merely instructions; it is a world-model encoded on paper.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| The complete pattern document | Generative model as a system |
| Materials list (yarn, hook, notions) | Input specification of the model |
| Row-by-row instructions | Transformation sequence (action policy) |
| Gauge specification | Precision parameters of the model |
| Finished object description | Predicted output of the model |
| Pattern errata | Model correction after prediction errors are discovered |

### Craft Integrity

- Treat the pattern as a sophisticated document worthy of careful reading — it encodes enormous amounts of craft knowledge in compressed notation.
- Use real pattern sections (materials list, gauge, stitch glossary, row instructions) to illustrate system components.
- Acknowledge that patterns vary in quality and completeness — some are precise generative models, others leave gaps that the crocheter must fill with their own knowledge.
