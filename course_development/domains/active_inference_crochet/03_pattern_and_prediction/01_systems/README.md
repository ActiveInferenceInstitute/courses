## Learning Goals

1. **Identify** the components of a crochet pattern as elements of a complete generative model
2. **Map** the inputs (yarn, hook size, gauge) and outputs (finished object) of the pattern-as-system
3. **Recognize** the pattern document itself as a system boundary — a Markov blanket separating the designer's intention from the crocheter's execution
