## Content Guidelines

This module focuses on **stitch counting and drift detection** as perception — the crocheter monitoring the state of the fabric against the pattern's predictions. Perception here is about noticing when what you see does not match what the pattern said should be there.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Counting stitches at end of row | State estimation — comparing observed count to predicted count |
| Noticing stitch drift across rows | Detecting accumulated prediction error |
| "Reading" the fabric to find where you are in the pattern | Perceptual inference from physical evidence |
| Recognizing a stitch type by looking at the fabric | Visual pattern recognition via generative model |
| Checking gauge against pattern specification | Precision calibration of perceptual predictions |
| Spotting an error several rows back | Delayed prediction error detection |

### Craft Integrity

- Use real counting scenarios: ending a row with 13 when the pattern says 14, or discovering that the shell pattern does not line up with the row below.
- Acknowledge the skill required to "read" crocheted fabric — experienced crocheters can identify stitch types, count rows, and spot errors by visual inspection alone.
- Connect the frustration of discovering a mistake several rows back to the Active Inference concept of accumulated prediction error.
