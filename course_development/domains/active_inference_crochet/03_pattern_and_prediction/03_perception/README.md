## Learning Goals

1. **Explain** stitch counting as state estimation — using discrete observations to track where you are in the pattern's predicted sequence
2. **Recognize** when row count or stitch count drifts from the pattern as a form of prediction error
3. **Describe** gauge checking as model validation — comparing your perceptual observations to the pattern's expected measurements
