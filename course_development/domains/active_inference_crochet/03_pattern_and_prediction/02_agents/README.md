## Learning Goals

1. **Describe** the pattern reader as an inference agent who parses instructions and generates predictions about what the finished piece will look like
2. **Distinguish** between passive instruction-following and active inference during pattern reading
3. **Identify** how your own expectations, experience, and mental imagery shape how you interpret a pattern before making a single stitch
