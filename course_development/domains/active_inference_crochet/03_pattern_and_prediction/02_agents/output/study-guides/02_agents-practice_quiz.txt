Practice Quiz: Agents — The Pattern-Reader's Mind

Part A: Multiple Choice

In Active Inference, a pattern-reading crocheter is best described as:
A) A passive receiver of instructions
B) An inference agent who generates predictions and updates them based on observations
C) A machine that executes commands without interpretation
D) A random decision-maker

A) Memorization without understanding
B) The generative model producing a prediction before the action occurs
C) Following instructions mechanically
D) Guessing randomly about the outcome

A) Look up the pattern in a reference book
B) Have extracted and internalized the pattern logic from previous rows
C) Start over from the beginning
D) Skip that row entirely

A beginner experiences more prediction errors than an expert because:
A) Beginners are less careful
B) The beginner's generative model is sparser and less accurate
C) Patterns are written only for experts

A) The written text of the pattern
B) The photo of the finished project
C) Deciding to frog and redo a section that does not match expectations
D) The gauge listed in the pattern header

A) Wasting time you could spend stitching
B) Running a simulation with your generative model to predict the posterior
C) Ignoring the pattern's instructions
D) Copying someone else's work

A) One of them is wrong
B) Their generative models contain different priors from different experiences
C) Only one of them can read
