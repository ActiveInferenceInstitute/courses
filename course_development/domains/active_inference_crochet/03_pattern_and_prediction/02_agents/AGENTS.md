## Conventions

- **Perspective**: Pattern reading, design, mathematical structure of crochet
- **Topics**: Agents
- **Lab Style**: Pattern Design Workshop
- **Audience**: Fiber artists, crafters, crochet circle participants, and the curious
- **Tone**: Warm, crafty, hands-on, accessible

## Content Guidelines

This module examines the crocheter as a **pattern-reading inference agent** — someone who takes compressed symbolic instructions and reconstructs a three-dimensional object through sustained inference. The crocheter is not simply following orders but actively interpreting, predicting, and adapting.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Reading a pattern and anticipating the result | Agent loading and running a generative model |
| Interpreting ambiguous pattern instructions | Inference under uncertainty |
| Experienced crocheter who can "see" the finished object | Deep generative model with rich predictions |
| Beginner following step by step without understanding | Shallow model, high reliance on external instructions |
| Pattern designer who writes instructions for others | Agent constructing a transmissible generative model |
| Test knitter/crocheter who checks a pattern | Agent validating another agent's model |

### Craft Integrity

- Respect the intellectual work of pattern reading — decoding notation, visualizing three-dimensional structure from two-dimensional instructions, and adapting to one's own gauge and materials.
- Acknowledge the pattern designer as a special kind of agent who must predict how other agents will interpret their model.
- Use real examples of pattern ambiguity (does "dc in next 3" mean three consecutive dc or one dc repeated three times?) to illustrate inference under uncertainty.
