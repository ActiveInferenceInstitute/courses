## Content Guidelines

This module traces the arc from **following patterns** to **writing them** — the crocheter's journey from model consumer to model creator. Learning to read patterns builds the generative model; learning to write patterns means the model has become rich enough to externalize.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Following a pattern for the first time | Learning by importing an external generative model |
| Mastering a pattern until you can work from memory | Model internalization — external model becomes internal |
| Modifying existing patterns to suit your preferences | Model refinement and personalization |
| Writing your first original pattern | Externalizing your generative model for others |
| Recognizing common stitch patterns across projects | Abstracting shared model components |
| Building a repertoire of pattern techniques | Expanding the generative model's action-outcome library |

### Craft Integrity

- Frame the journey from beginner to designer as one of deepening generative model complexity — not just "more skill" but "richer prediction."
- Use real milestones: first completed pattern, first modification, first original design, first pattern shared with others.
- Acknowledge that pattern writing requires a different kind of model than pattern reading — you must predict what another crocheter will understand and do.
