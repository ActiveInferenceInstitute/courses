## Learning Goals

1. **Trace** the progression from following patterns to modifying them to writing original patterns as increasing generative model complexity
2. **Explain** how each completed project updates and enriches the crocheter's generative model
3. **Describe** pattern design as the ultimate expression of generative model mastery — encoding your own predictions for others
