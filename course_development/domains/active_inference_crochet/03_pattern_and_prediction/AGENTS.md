## Active Inference Integration

This course treats the crochet pattern as the **generative model** made visible. Written patterns encode predictions, charts compress action sequences into spatial representations, and pattern modification is the crocheter acting as model-builder rather than model-follower.

| Pattern Experience | Active Inference Concept | Teaching Approach |
|---|---|---|
| Reading a pattern for the first time | Loading a generative model | Walk through a real pattern, identifying predictions at each step |
| Counting stitches and noticing drift | State estimation and prediction error detection | Practice counting exercises with deliberate errors |
| Mentally visualizing the finished piece | Running the generative model forward (internal simulation) | Sketch what you predict before you stitch |
| Modifying a pattern mid-project | Active inference — changing actions to align predicted and desired outcomes | Guided improvisation exercises |
| Writing your own pattern | Constructing a generative model from scratch | Pattern-writing workshop |
| Sharing a pattern with another crocheter | Transmitting a generative model across agents | Collaborative pattern testing |
