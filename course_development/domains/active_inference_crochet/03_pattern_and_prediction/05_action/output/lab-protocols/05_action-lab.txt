Lab: Pattern Design Workshop — Modifying the Pattern Mid-Row

Objective

Practice deliberate pattern modification and develop awareness of the decision-making processes involved in acting on your work to align it with your intentions.

Materials Needed

A simple crochet pattern (dishcloth or small accessory)
Two sets of hook and yarn in the same weight but different hook sizes (e.g., 4mm and 5.5mm)
Journal or notebook
Stitch markers

Exercise 1: Stitch Substitution Comparison (40 minutes)

Make the same pattern twice with one systematic substitution:

Version A: Follow the pattern exactly as written
Version B: Replace every double crochet with half double crochet (or vice versa)

Compare the two finished pieces:

| Property | Version A (original) | Version B (substituted) |
| --- | --- | --- |
| Width | | |
| Length | | |
| Drape | | |
| Texture | | |
| Density | | |
| Yarn used | | |

Discuss: How accurately did you predict the effects of the substitution before making it? What surprised you?

Exercise 2: The Frogging Decision Log (30 minutes)

Work a practice swatch and intentionally introduce three different types of errors:
Skip one stitch in a row (a small, hard-to-see error)
Use the wrong stitch for an entire row (a large, visible error)
Add an extra stitch in the middle of a row (a medium error)

For each error, pause and make a deliberate frogging decision. Record:

| Error | Visibility | Structural Impact | Frogging Cost | Decision | Reasoning |
| --- | --- | --- | --- | --- | --- |
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

Reflect: What factors drove your decisions? How did the precision of the error signal (how visible and structurally important the error is) affect your choice?

Exercise 3: Guided Improvisation (30 minutes)

Starting with a foundation chain of 20, crochet freely for 15 minutes. The only rule: after every 2 rows, write down:
What you predicted would happen
What actually happened
What you plan to do next and why

This exercise makes the active inference loop visible: predict, act, observe, decide.

Exercise 4: Size Modification Challenge (20 minutes)

Take a simple pattern designed for one size (e.g., a baby hat) and plan the modifications needed to make it in a different size (e.g., adult). Write out:

What numbers must change (stitch counts, row counts)
What proportions must stay the same (crown-to-brim ratio)
What new calculations are needed

Discuss: Which parts of the modification were straightforward re-parameterization, and which required deeper understanding of the pattern's structure?

Discussion Questions for the Circle

When you modify a pattern, do you plan the modifications before starting, or do you decide as you go? What drives your approach?
What is your personal frogging threshold — how much error can you tolerate before you rip it out?
Have you ever improvised something you were proud of? What made the improvisation successful?

Wrap-Up

Write a brief reflection (3-5 sentences) on your relationship with pattern modification. Are you a strict pattern follower, an eager modifier, or an improviser? How does your approach connect to your generative model's confidence?
