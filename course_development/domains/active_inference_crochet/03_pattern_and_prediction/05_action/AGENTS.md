## Content Guidelines

This module focuses on **pattern modification** as active inference — the crocheter changing the pattern mid-project to reduce the gap between intention and outcome. Stitch substitution, size adjustment, and improvisation are all forms of active inference where the agent acts to make reality match a revised model.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Modifying a pattern mid-row | Active inference — acting to align outcome with intention |
| Substituting one stitch for another | Action policy switch within the generative model |
| Adjusting pattern for different gauge | Model adaptation to local conditions |
| Improvising without a written pattern (freeform crochet) | Action selection from internalized generative model |
| The decision to frog, tink, or continue | Policy evaluation — choosing the action that best reduces prediction error |
| Adding a border or embellishment not in the pattern | Extending the model with new predictions |

### Craft Integrity

- Celebrate pattern modification as creative agency, not deviation — the crocheter who modifies is a more active inference agent, not a worse pattern-follower.
- Use real modification scenarios: changing size, substituting a stitch for texture, adapting a flat pattern to work in the round.
- Respect freeform crochet as one of the purest expressions of active inference — the crocheter generates predictions and acts on them in real time, without external instructions.
