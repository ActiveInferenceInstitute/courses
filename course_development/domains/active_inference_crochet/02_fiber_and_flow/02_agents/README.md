## Learning Goals

1. **Recognize** the crocheter's hands as embodied active inference agents that sense and act on yarn
2. **Explain** how tactile expertise develops as a refined generative model of material behavior
3. **Connect** material sensitivity to precision weighting in the Active Inference framework
