## Learning Goals

1. **Describe** color palette design as an expected free energy minimization process
2. **Explain** dye lot management and project-yarn matching as planning under uncertainty
3. **Connect** yardage estimation and material planning to the planning component of Active Inference
4. **Design** a color palette for a multi-color project and articulate the predictions driving each choice
5. **Calculate** yardage needs for a project and reflect on the uncertainty inherent in material estimation

## Key Crochet Terminology

- **Color palette**: The set of colors chosen for a project, planned to create harmony or contrast
- **Dye lot**: The specific batch in which yarn was dyed; different lots may have subtle color variation
- **Yardage estimation**: Calculating how much yarn is needed for a project based on gauge, dimensions, and stitch type
- **Colorwork**: Any crochet technique involving multiple colors (stripes, tapestry crochet, intarsia, color pooling)
- **Complementary colors**: Colors opposite each other on the color wheel, creating high visual contrast

## Prerequisites

- Completion of Modules 01-07 in this course
- Experience with at least one multi-color project or willingness to plan one

## Materials Needed

- Yarn in multiple colors for palette experimentation
- Color wheel reference (printed or digital)
- Calculator or yardage estimation chart
- Notebook, colored pencils, or digital tools for palette sketching
