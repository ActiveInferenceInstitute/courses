# Practice Quiz: Planning (Fiber & Flow)

## Part A: Multiple Choice

1. Color palette design in Active Inference terms is:
A) A random aesthetic choice
B) Expected free energy minimization — simulating color combinations and choosing the most satisfying
C) Always following a formula
D) Only relevant for professional designers

2. Dye lot management is an example of:
A) Unnecessary paranoia
B) Planning under uncertainty with buffers and contingencies
C) Something only yarn shops worry about
D) A problem that does not exist with modern manufacturing

3. Project-yarn matching requires:
A) Only matching the yarn weight
B) Evaluating fiber suitability, weight, texture, care, and budget simultaneously
C) Always using the exact yarn specified in the pattern
D) No planning at all

4. Yardage estimation improves with experience because:
A) Experienced crocheters always buy extra
B) The generative model includes predictions about yarn consumption for different stitch types
C) Math skills are not needed
D) All projects use the same amount of yarn

5. The plan-swatch-revise cycle is:
A) An unnecessary delay before starting a project
B) Active Inference in action — plan, act, observe, revise
C) Only for perfectionists
D) A one-time event at the start of a project

6. The balance between pragmatic and epistemic value in project selection means:
A) Always choosing the easiest project
B) Balancing achievable goals with opportunities to learn something new
C) Never trying new techniques
D) Always choosing the hardest project

7. Planning for a gift project differs from personal projects because:
A) Gift projects need no planning
B) The crocheter must predict another person's preferences, size, and care habits
C) Only personal projects matter
D) Gift planning uses different yarn

## Part B: Short Answer

1. Walk through the complete planning process for choosing a color palette for a striped scarf. What predictions are generated and evaluated at each step?

2. Explain why buying all the yarn for a large project from the same dye lot is a planning strategy. What risk does it manage, and what is the cost of the precaution?

3. A crocheter wants to substitute a silk-wool blend for the cotton specified in a summer top pattern. Describe the planning predictions they must make to evaluate this substitution.
