- **Perspective**: Materials, yarn properties, creative flow states

- **Tone**: Warm, crafty, hands-on, accessible

## Content Guidelines

This module focuses on how the crocheter **acts on yarn**: tension adjustment as continuous active inference, yarn feeding technique as motor policy, and switching between fibers as action adaptation. The pull-through is where intention meets material resistance.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Adjusting tension for different yarns | Active inference — continuous correction of motor output |
| Yarn feeding through tension fingers | Action policy for material flow control |
| Switching from one yarn to another mid-row | Policy switching when material context changes |
| Winding a center-pull ball | Preparatory action that shapes future interactions |
| Joining a new skein | Transition action requiring model adaptation |
| Blocking a finished piece | Post-production action to align reality with intention |

### Craft Integrity

- Emphasize the physical, embodied nature of working with yarn — the pull-through is not abstract but muscular, tactile, real.
- Acknowledge that different fibers demand different handling: cotton requires more deliberate tension, wool bounces back, silk slips.
- Respect the craft knowledge embedded in techniques like Russian join, magic knot, or weaving in ends — each is a specific action policy for a specific material challenge.
