Practice Quiz: Action (Fiber & Flow)

Part A: Multiple Choice

  1. Tension adjustment in crochet is best described as: A) A one-time setup before starting a project B) A continuous active inference process of correcting to match desired fabric C) An automatic machine process D) Something only beginners need to worry about

  2. Yarn feeding technique is an example of: A) A random habit that cannot be changed B) An action policy optimized through practice to minimize friction and maximize control C) Something determined entirely by the yarn D) A purely visual process

  3. When switching from cotton to wool mid-project, the crocheter must: A) Keep the exact same grip and tension B) Recalibrate grip, feed rate, and hook angle for the new material C) Stop crocheting entirely and start over D) Only change the hook size

  4. The pull-through in crochet is: A) A purely mechanical action with no cognitive component B) A prediction-driven micro-action where the hands expect certain resistance and loop size C) Always identical regardless of yarn type D) Only important for the first stitch of a project

  5. Easing tension when the fabric feels too tight is: A) A sign of losing control B) Active inference — acting to reduce the prediction error between desired and actual fabric C) Impossible for experienced crocheters D) Only done when frogging

  6. Different stitch types require different action policies because: A) They use different yarns B) Each stitch involves different hook movements, heights, and yarn overs C) Only professionals can tell the difference between stitches D) Stitch type does not affect the hands' actions

  7. A crocheter's grip style (pencil vs. knife grip) is: A) Purely cosmetic with no functional difference B) An action parameter that affects control, speed, and comfort C) Required to always be pencil grip D) Required to always be knife grip

Part B: Short Answer

  1. Describe the perception-action cycle of a single crochet stitch. What does the crocheter predict, what action do they take, and how do they evaluate the result?

  2. Explain why tension tends to tighten when a crocheter is anxious. How does emotional state enter the action policy?

  3. A crocheter switches from a familiar wool to an unfamiliar silk mid-row. Describe what happens to their action parameters and how the hands recalibrate.
