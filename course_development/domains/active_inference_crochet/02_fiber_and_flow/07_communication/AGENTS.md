## Content Guidelines

This module examines how fiber knowledge is **communicated**: color theory as a shared language, yarn weight classification as a standardized generative model, and fiber content labeling as a system of encoded predictions about material behavior.

### Key Mappings

| Crochet Concept | Active Inference Concept |
|---|---|
| Color theory (complementary, analogous, triadic) | Shared generative model for visual prediction |
| Yarn weight classification (fingering to super bulky) | Standardized encoding of material properties |
| Fiber content labeling (100% wool, acrylic blend) | Communicating system internal states |
| Color charts and mood boards | External representations of predictive models |
| Dye lot numbers | Precision markers for color matching |
| Yarn reviews and recommendations | Distributed model sharing in the craft community |

### Craft Integrity

- Treat color theory as genuinely useful craft knowledge, not abstract art theory — crocheters use color relationships to predict how their projects will look.
- Respect the standardization systems (CYC yarn weight, fiber labeling) as real communication infrastructure that enables prediction across contexts.
- Acknowledge that color communication is hard — what looks "teal" on screen may not match the yarn in hand. This mismatch is a prediction error built into the communication channel.
- Invite learners to build their own color palettes and notice how prediction shapes color choice.
