# Learning Pathways: Active Inference: Crochet Circles

> Suggested routes through the curriculum for fiber artists, crafters, crochet circle participants, and the curious.

## Pathway 1: Hook to Circle (Sequential — Recommended for Beginners)

Complete one course fully before starting the next, moving from individual skill to community practice:

1. **Stitch & Structure** — Learn how Active Inference works at the level of your hook and yarn
2. **Fiber & Flow** — Expand to materials, sensation, and creative flow
3. **Pattern & Prediction** — Move into symbolic representation and design thinking
4. **Circle & Community** — Bring it all together in the social context of the crochet circle

5. **Loop & Lattice** — Discover the deep topology and neural network structure hidden in every piece of crochet

This pathway mirrors the typical crocheter's journey: learn the stitches, explore materials, master patterns, share with others, then discover the mathematical depths.

## Pathway 2: Topic Spiral (Parallel — Recommended for Conceptual Depth)

Study the same module across all 5 courses before moving to the next topic:

1. Read **Systems** in all 5 courses (hook-yarn boundary → fiber systems → pattern structure → the circle as system → topological surfaces)
2. Read **Agents** in all 5 courses (you the crocheter → your sensing hands → the pattern reader → each maker at the table → the neural architect)
3. Continue through Perception, Cognition, Action, Learning, Communication, Planning

This pathway reveals how one Active Inference concept manifests at every scale — from a single stitch to a community gathering to the topology of surfaces and networks.

## Pathway 3: The Maker's Path (Interest-Driven)

Start wherever your craft interest is strongest:

- **"I want to improve my stitching"** → Start with Stitch & Structure, focus on Modules 3 (Perception), 5 (Action), and 6 (Learning)
- **"I'm a yarn enthusiast"** → Start with Fiber & Flow, focus on Modules 1 (Systems), 3 (Perception), and 8 (Planning)
- **"I love designing patterns"** → Start with Pattern & Prediction, focus on Modules 2 (Agents), 4 (Cognition), and 6 (Learning)
- **"I run a crochet group"** → Start with Circle & Community, focus on Modules 1 (Systems), 5 (Action), and 7 (Communication)
- **"I love math and geometry"** → Start with Loop & Lattice, focus on Modules 1 (Systems — topology), 3 (Perception — curvature), and 5 (Action — manifold shaping)
- **"I'm interested in neural networks"** → Start with Loop & Lattice, focus on Modules 2 (Agents — neural architect), 4 (Cognition — hidden layers), and 8 (Planning — network design)

## Pathway 4: The Science Path (For Active Inference Enthusiasts)

If you already know Active Inference and want to see it in craft:

1. Start with the [Glossary](./glossary.md) and [Notation Table](./notation_table.md) to see the full mapping
2. Read Module 1 (Systems) across all courses for the Markov blanket interpretation
3. Read Module 5 (Action) across all courses for the active inference loop in practice
4. Read Module 6 (Learning) across all courses for model updating and skill acquisition
5. Read Loop & Lattice for the topology and neural network connections
6. Finish with Circle & Community for collective active inference

## Pathway 5: The Circle Study Group

For crochet circles that want to learn together:

**Weekly Structure (8 weeks):**

| Week | Topic | Read Together | Do Together |
| --- | --- | --- | --- |
| 1 | Systems | Course 4, Module 1 (What Makes a Circle a Circle) | Discuss: What are the boundaries of our circle? |
| 2 | Agents | Course 1, Module 2 (You Are the Crocheter) | Each person describes their crochet "style" as a generative model |
| 3 | Perception | Course 2, Module 3 (How Yarn Speaks Through Touch) | Blind yarn identification exercise |
| 4 | Cognition | Course 3, Module 4 (Mental Models of the Finished Piece) | Visualize a project before starting — draw what you expect |
| 5 | Action | Course 1, Module 5 (Every Stitch Changes the Fabric) | Stitch together in silence, noticing the action-perception loop |
| 6 | Learning | Course 4, Module 6 (How Circles Preserve and Pass On Craft) | Teach each other one stitch you know well |
| 7 | Communication | Course 4, Module 7 (Stories Told Over Stitches) | Share the story of your current project |
| 8 | Planning | Course 4, Module 8 (Organizing a Crochet-Along) | Plan a group project using Active Inference concepts |
