# AGENTS: Shared Resources

> **Quick Navigation**: [Resources README](./README.md) | [Curriculum AGENTS](../AGENTS.md)

## Purpose

These shared resources serve as the single source of truth for terminology, notation, and references across all courses in Active Inference: Crochet Circles.

## Maintenance Rules

1. Update the glossary when new crochet-AI terms are introduced in any module.
2. Keep the notation table synchronized with all courses — every crochet abbreviation used in module content must appear here.
3. Verify cross-course map links after any structural changes.
4. All tables must use proper MD060-compliant formatting (spaces around pipes).
5. When adding glossary entries, always include both the crochet definition and the Active Inference mapping.
6. References must include both foundational Active Inference sources and craft-specific sources.
