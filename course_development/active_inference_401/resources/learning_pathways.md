# Learning Pathways: Active Inference 401: Advanced PhD Seminar

> Suggested routes through the curriculum for PhD students and researchers.

## Pathway 1: Sequential by Unit (Recommended for first pass)

Complete one unit fully before starting the next. This builds depth in each perspective before integrating:

1. **Philosophical Foundations** (8 modules) — Establish conceptual clarity about what the FEP claims and why it matters
2. **Neuroscientific Frontiers** (8 modules) — Ground the formalism in neural mechanisms and empirical evidence
3. **Advanced Theory** (8 modules) — Develop the mathematical foundations rigorously
4. **Research Methods** (8 modules) — Learn to design studies that test active inference models

**Best for**: Students who prefer depth-first learning and come from a single disciplinary background.

## Pathway 2: Parallel by Topic (Recommended for comparative analysis)

Study each module topic across all 4 units before moving to the next topic:

For each topic (Systems → Agents → Perception → ... → Planning):
1. Read the Philosophical Foundations module (conceptual framing)
2. Read the Neuroscientific Frontiers module (empirical grounding)
3. Read the Advanced Theory module (formal derivation)
4. Read the Research Methods module (experimental design)

**Best for**: Students preparing for interdisciplinary research who want to see how the same concept is treated from four perspectives.

## Pathway 3: Theory-First (For mathematics/physics students)

1. **Advanced Theory** Units 1-8 (establish the formalism)
2. **Philosophical Foundations** Units 1-8 (understand what the formalism is claimed to mean)
3. **Neuroscientific Frontiers** Units 1-8 (see where the formalism contacts empirical data)
4. **Research Methods** Units 1-8 (learn to test the formalism)

**Best for**: Students with strong mathematical backgrounds who want formal foundations first.

## Pathway 4: Empirical-First (For neuroscience students)

1. **Neuroscientific Frontiers** Units 1-8 (neural mechanisms and evidence)
2. **Research Methods** Units 1-8 (experimental design and model fitting)
3. **Advanced Theory** Units 1-8 (mathematical underpinnings)
4. **Philosophical Foundations** Units 1-8 (conceptual and epistemological analysis)

**Best for**: Students with neuroscience backgrounds who want to ground theory in data.

## Pathway 5: Research-Problem Focused

Pick a specific research question and trace it across units:

- **"Is the FEP falsifiable?"** → Phil M1, Phil M2, Phil M8, Methods M1, Methods M8
- **"How does predictive coding work in cortex?"** → Neuro M3, Theory M3, Methods M3, Neuro M4
- **"Can we build active inference agents?"** → Theory M2, Theory M5, Methods M2, Methods M5, Methods M8
- **"What is the relationship between action and perception?"** → Phil M3, Phil M5, Theory M5, Neuro M5

## Prerequisites Between Modules

Within each unit, modules are designed to be studied in order (1→8). The key dependencies:

- **Module 2** (Agents) requires **Module 1** (Systems): agents are defined as particular systems
- **Module 3** (Perception) requires **Module 2** (Agents): perception is what agents do
- **Module 5** (Action) requires **Module 3** (Perception): action completes the perception-action cycle
- **Module 7** (Communication) requires **Module 2** (Agents): communication is multi-agent
- **Module 8** (Planning) requires **Modules 4-6**: planning builds on cognition, action, and learning
