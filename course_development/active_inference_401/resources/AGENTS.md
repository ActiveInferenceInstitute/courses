# AGENTS: Shared Resources

> **Quick Navigation**: [Resources README](./README.md) | [Curriculum AGENTS](../AGENTS.md)

## Purpose

These shared resources serve as the single source of truth for terminology, notation, references, and cross-course structure across all 4 units (32 modules) of Active Inference 401: Advanced PhD Seminar.

## Resource Files

| File | Purpose | Update Frequency |
| ---- | ------- | ---------------- |
| `notation_table.md` | Canonical symbols and LaTeX | Update when new notation is introduced in any module |
| `glossary.md` | Formal definitions of all technical terms | Update when new terms are introduced; ensure definitions are formal, not circular |
| `references.md` | Complete reference list with full citations | Update when new works are cited in any module |
| `cross_course_map.md` | How each topic is treated across all 4 units | Update after any structural changes; ensure unit differentiation is maintained |
| `learning_pathways.md` | Suggested routes through the curriculum | Update if prerequisites or module dependencies change |
| `faq.md` | Frequently asked questions at PhD level | Update as needed |

## Maintenance Rules

1. **Notation table**: Every symbol used in any module must appear in the notation table with its LaTeX, formal meaning, and defining equation. No symbol may be used without an entry here.
2. **Glossary**: Every technical term must have a formal definition with at least one citation. Definitions must NOT be circular ("X is a concept related to X") — this is the single most important rule for the glossary.
3. **References**: All citations in all modules must have a corresponding entry in the reference list with full bibliographic details. Use numbered entries. Include DOI or arXiv ID where available.
4. **Cross-course map**: Every module row must show DIFFERENT subtitles and key concepts for each unit. If two units show the same subtitle for a module, the map is wrong — the entire point is that units provide different perspectives.
5. **Learning pathways**: Must reflect actual prerequisite dependencies between modules. Update if module content changes significantly.
6. **FAQ**: Must be written at PhD level. No pop-science explanations. Define terms formally. Include citations.
7. **Formatting**: All tables must use proper Markdown formatting with spaces around pipes for MD060 compliance.
