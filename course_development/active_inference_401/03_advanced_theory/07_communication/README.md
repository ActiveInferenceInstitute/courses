## Learning Goals

1. **Derive** the formal framework for multi-agent Active Inference, showing how interacting agents form a composite system with nested Markov blankets, where each agent's generative model includes a model of the other agent's generative model
2. **Analyze** shared generative models as emergent structures arising from reciprocal inference: formalize the conditions under which coupled agents converge to aligned beliefs and show that alignment minimizes a joint free energy functional
3. **Examine** collective intelligence as group-level inference, proving that multi-agent systems under Active Inference can be described as a single meta-agent performing inference on a collective generative model (the "Markov blankets all the way up" thesis)
4. **Evaluate** the category-theoretic formulation of multi-agent systems using optics and polynomial functors, showing how compositional structure in multi-agent interaction can be formalized as morphisms in an appropriate category (cf. St. Clere Smithe, 2020)

## Prerequisites

- Multi-agent systems theory (game theory, mechanism design, social choice)
- Category theory (monoidal categories, string diagrams, lenses and optics)
- Familiarity with the single-agent Active Inference formalism at the mathematical level
