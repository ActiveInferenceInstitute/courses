## Learning Goals

1. **Analyze** the renormalization group (RG) as a mathematical framework for multi-scale description, deriving how coarse-graining transformations map fine-grained dynamics to effective theories at larger scales while preserving essential structure
2. **Evaluate** how Active Inference can be formulated as scale-free, showing that the same variational principle (free energy minimization) applies at molecular, cellular, organismic, and social scales, with the generative model structure determined by the scale of description
3. **Derive** the formal connections between RG coarse-graining and hierarchical Bayesian model reduction, proving that marginalization over fast variables in a hierarchical generative model is mathematically equivalent to a Kadanoff block-spin transformation under appropriate conditions
4. **Examine** the concept of universality classes in Active Inference: investigate whether different generative model architectures converge to the same macroscopic behavior under RG flow, and what this implies for the typicality of cognitive architectures

## Prerequisites

- Statistical mechanics (partition functions, phase transitions, critical phenomena, Kadanoff block-spin transformation)
- Renormalization group theory (Wilsonian RG, momentum-shell integration, fixed points and flows)
- Hierarchical Bayesian modeling and marginalization
