# Active Inference 401: Advanced PhD Seminar — Pedagogical Overview

## Vision

This curriculum makes Active Inference accessible to Advanced PhD students and researchers through four complementary lenses. Each course covers the same 8 foundational topics but from a different disciplinary perspective.

## Tone & Style

Research-level. Dense mathematical formalism. Open questions. Paper discussions.

## Course Map

**Perspective**: Epistemology, phenomenology, 4E cognition

Modules: [Systems](./01_philosophical_foundations/01_systems/README.md), [Agents](./01_philosophical_foundations/02_agents/README.md), [Perception](./01_philosophical_foundations/03_perception/README.md), [Cognition](./01_philosophical_foundations/04_cognition/README.md), [Action](./01_philosophical_foundations/05_action/README.md), [Learning](./01_philosophical_foundations/06_learning/README.md), [Communication](./01_philosophical_foundations/07_communication/README.md), [Planning](./01_philosophical_foundations/08_planning/README.md)

- **Sequential**: Work through one course start to finish.
- **Parallel**: Study the same module across all 4 courses.
