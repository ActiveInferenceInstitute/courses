## Learning Goals

1. **Map** the cortical hierarchical architecture onto the generative model structure, identifying how feedforward connections carry prediction errors (epsilon) and feedback connections carry predictions (mu)
2. **Analyze** the canonical microcircuit as the computational unit of Active Inference, specifying roles of superficial pyramidal cells, deep pyramidal cells, spiny stellate cells, and inhibitory interneurons
3. **Evaluate** empirical evidence for Active Inference implementations in cortex, including laminar fMRI, intracranial recordings, and optogenetic manipulations
4. **Integrate** subcortical structures (basal ganglia, cerebellum, thalamus) and neuromodulatory systems (dopamine, norepinephrine, acetylcholine, serotonin) into a unified neural Active Inference architecture

## Prerequisites

- Graduate-level neuroanatomy (cortical lamination, thalamocortical loops, neuromodulatory pathways)
- Understanding of the predictive coding hierarchy and its mathematical formulation
- Familiarity with neural network modeling and dynamic causal modeling (DCM)
