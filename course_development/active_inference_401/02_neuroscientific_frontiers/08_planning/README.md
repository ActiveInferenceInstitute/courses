## Learning Goals

1. **Analyze** how psychiatric conditions can be formalized as disorders of Active Inference: aberrant precision weighting (anxiety, autism), model misspecification (delusions in schizophrenia), and inference failure (depression as learned helplessness with low expected epistemic value)
2. **Evaluate** the computational psychiatry approach to specific conditions, deriving the parameter perturbations that account for symptom profiles in schizophrenia, depression, anxiety, and addiction
3. **Design** a computational phenotyping study that uses Active Inference model parameters as biomarkers, specifying behavioral task, generative model, model inversion procedure, and clinical validation strategy
4. **Synthesize** the Neuroscientific Frontiers track by evaluating the translational pipeline from computational models to clinical interventions, identifying bottlenecks for personalized medicine based on Active Inference

## Prerequisites

- Graduate-level psychopathology and diagnostic classification (DSM/ICD frameworks, dimensional approaches)
- Understanding of computational modeling of behavior (model fitting, parameter recovery, model comparison)
- Familiarity with Active Inference accounts of specific conditions (Friston, Adams, Montague)
