# Neuroscientific Frontiers

> Part of **Active Inference 401: Advanced PhD Seminar** | [Curriculum Home](../README.md)

## Overview

**Neuroscientific Frontiers** explores Active Inference through the lens of predictive processing, precision, neural dynamics. This course is designed for Advanced PhD students and researchers.

**Tone**: Research-level. Dense mathematical formalism. Open questions. Paper discussions.
