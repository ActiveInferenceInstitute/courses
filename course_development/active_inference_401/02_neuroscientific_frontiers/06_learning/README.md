## Learning Goals

1. **Analyze** how synaptic plasticity (LTP, LTD, STDP) implements parameter learning under Active Inference, showing that Hebbian-like rules approximate gradient descent on variational free energy under specific neural coding assumptions
2. **Evaluate** the evidence for Bayesian model reduction in the brain, connecting synaptic pruning during development, offline replay during sleep, and memory consolidation to structure learning in generative models
3. **Derive** the relationship between memory consolidation (systems-level transfer from hippocampus to neocortex) and hierarchical model updating, formalizing complementary learning systems theory within Active Inference
4. **Design** an experiment to test whether sleep-dependent consolidation implements Bayesian model reduction, specifying neural predictions that differentiate BMR from alternative accounts

## Prerequisites

- Graduate-level neuroscience of synaptic plasticity (molecular mechanisms, induction protocols, computational rules)
- Understanding of memory systems (hippocampal-neocortical interactions, consolidation, reconsolidation)
- Familiarity with Bayesian model reduction and its mathematical formulation
