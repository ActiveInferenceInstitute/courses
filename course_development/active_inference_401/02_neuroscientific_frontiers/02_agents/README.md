## Learning Goals

1. **Identify** the neural substrates of the self-model across interoceptive (insular cortex, anterior cingulate), proprioceptive (somatosensory cortex, cerebellum), and narrative (default mode network, medial prefrontal cortex) dimensions
2. **Analyze** the default mode network as the neural basis for the hierarchical generative model of self, including its anti-correlation with task-positive networks and its role in self-referential processing
3. **Evaluate** interoceptive inference as the foundation of subjective experience, connecting insular cortex function to allostatic regulation, emotional awareness, and the sense of embodiment
4. **Connect** self-model neuroscience to the philosophical treatment of selfhood as inference (Track 1, Module 02), assessing what neural evidence supports or challenges philosophical claims about the self

## Prerequisites

- Graduate-level knowledge of default mode network architecture and function
- Understanding of interoceptive processing and allostatic regulation
- Familiarity with the philosophical self-model framework (Metzinger, Seth)
