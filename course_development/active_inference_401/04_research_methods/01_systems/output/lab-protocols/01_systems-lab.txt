Part 2: Model Inversion Walkthrough

> Learning Goal: Understand the variational Laplace algorithm.

Exercise: Trace through the variational Laplace algorithm for a simplified version:

Initialize: Set q(θ) = N(μ₀, Σ₀) with prior values
E-step: Compute expected log-likelihood Eq[ln p(y | θ)]
Gradient: Compute ∂F/∂μ and ∂²F/∂μ²
Update: μnew = μold - (∂²F/∂μ²)⁻¹ · ∂F/∂μ (Newton step)
Covariance update: Σnew = -( ∂²F/∂μ²)⁻¹
Convergence check: Has F changed less than threshold? If not, return to step 2

For a model with one parameter θ (a single connection strength), with:

Prior: p(θ) = N(0, 1)
Likelihood: p(y | θ) = N(θ, 0.5)
Observed y = 2

Compute the analytical posterior p(θ | y) and verify it matches the VL estimate.

Part 3: Model Comparison Exercise

> Learning Goal: Compare competing DCM models using Bayesian Model Selection.

Exercise: After inverting 4 models of a language network, you obtain these free energies:

| Model | Connectivity Hypothesis | Free Energy (F) | Relative F |
|-------|------------------------|-----------------|-----------|
| M1 | Broca → Wernicke, feedforward only | -1250.3 | 0 (reference) |
| M2 | Broca ↔ Wernicke, reciprocal | -1242.1 | +8.2 |
| M3 | Wernicke → Broca, feedforward only | -1255.7 | -5.4 |
| M4 | Broca ↔ Wernicke + STS mediation | -1238.5 | +11.8 |

Which model wins? (M4 — lowest F, highest evidence)
Compute Bayes factors: BF₄₁ = exp(11.8) ≈ 133,000 — very strong evidence
Does model M4's added complexity (STS involvement) pay for itself? Yes — the BF is decisive.

Part 4: Study Design

> Learning Goal: Design a complete DCM study from hypothesis to interpretation.

Exercise: Design a DCM study investigating how medication (e.g., an SSRI) changes effective connectivity in a depression network:

Hypothesis: SSRIs restore PFC→amygdala inhibition (top-down control)
Participants: 30 patients scanned before and after 8 weeks of SSRI treatment + 30 controls
Task (for task-based DCM) or Resting state (for spectral DCM): Specify and justify
Regions: PFC (dlPFC), amygdala, ACC, insula — justify inclusion
Models: Specify at least 3 competing models with different hypothesized connectivity changes
Analysis plan: Individual DCM → PEB group analysis → BMS → parameter inference
Expected results: If hypothesis is correct, B matrix for "medication" should show strengthened PFC→amygdala
