## Learning Goals

1. **Apply** computational phenotyping to characterize individuals by their generative model parameters (precision of likelihood, prior volatility, policy depth, learning rate), implementing parameter estimation from behavioral data using variational Laplace or sampling methods
2. **Analyze** parameter recovery as a validation methodology: design and execute simulation-recovery studies demonstrating that model parameters can be uniquely identified from behavioral data, reporting identifiability landscapes and correlation matrices
3. **Evaluate** the use of Active Inference parameters as clinical biomarkers, assessing test-retest reliability, discriminant validity across diagnostic categories, and predictive validity for treatment response
4. **Design** a computational phenotyping study including task selection, model specification, inversion pipeline, and statistical analysis plan suitable for a clinical population

## Prerequisites

- Graduate-level computational modeling (maximum likelihood, Bayesian estimation, model comparison)
- Understanding of psychometric principles (reliability, validity, sensitivity, specificity)
- Proficiency in a scientific computing environment (Python/pymdp, MATLAB/SPM, or Julia/RxInfer.jl)
