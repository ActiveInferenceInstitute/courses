# YouTube Transcript Archive — Agent Guidelines

> **Quick Navigation**: [Course Development AGENTS.md](../AGENTS.md) | [Root AGENTS.md](../../AGENTS.md) | [README](./README.md)

## Overview

This directory contains structured transcripts from **38 playlists** (~821 videos, per `youtube_courses.json`) from the Active Inference Institute YouTube channel. These are source materials — not hand-authored course content.

---

## Critical Rules

Run all commands below from `software/`, where the pipeline scripts and `pyproject.toml` live. From the repository root, run `cd software` first.

### 1. Transcripts Are Auto-Generated

Transcript files are produced by `software/scripts/transcribe_youtube.py` and scaffolded into playlist/video directories by `software/scripts/render_youtube_courses.py`. They may contain transcription artifacts (misspellings, missing punctuation, speaker misattributions). When using transcripts as source material:

- Do not treat transcript text as authoritative for technical terms
- Cross-reference technical claims against published papers
- Use the course's `resources/glossary.md` for canonical terminology

### 2. Do Not Hand-Edit Transcripts

Transcripts should be regenerated via the transcription pipeline rather than manually corrected. Manual edits will be lost on the next transcription run. This applies to every generated playlist and video directory, including `module.md`, `dashboard.html`, and `output/`.

### 3. Playlist Metadata

The `youtube_courses.json` file at this directory level contains playlist metadata and mappings. It is generated by playlist enumeration. Do not modify this file unless updating playlist configurations.

### 4. Rendering

To render transcripts as course materials, run from `software/`:

```bash
cd software
uv run python scripts/render_youtube_courses.py
```

Rendered outputs go to `published/youtube/`.

## Directory Structure

The archive is generated in two levels. Each subdirectory corresponds to one YouTube playlist; each video in that playlist has a numbered subdirectory:

```text
youtube/
├── youtube_courses.json
├── active-inference-livestreams-paper-discussions/
│   ├── 01_actinf-livestream-001-1-narrative-as-active-inference/
│   │   ├── module.md
│   │   ├── dashboard.html
│   │   └── output/
│   └── ...
├── gueststreams/
├── mathstreams/
└── ...  (38 playlist directories)
```

### Parent contract for generated directories

Every playlist and video directory below this hub is generated. This `AGENTS.md` and the hub `README.md` are their parent contract; do not add per-playlist or per-video `README.md`/`AGENTS.md` files. The repository's "AGENTS.md at every level" rule applies to authored directories; generated archive directories are the documented exception. If a generated directory needs a change, change the pipeline or `youtube_courses.json` and regenerate.
