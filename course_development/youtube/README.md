## Directory Structure

The archive is generated in two levels. Each playlist has its own directory; each video in that playlist has a numbered directory containing the generated transcript and its rendered output:

```text
youtube/
├── youtube_courses.json              # playlist + video metadata (generated)
├── active-inference-livestreams-paper-discussions/
│   ├── 01_actinf-livestream-001-1-narrative-as-active-inference/
│   │   ├── module.md                 # transcript with source front-matter
│   │   ├── dashboard.html
│   │   └── output/                   # rendered formats
│   ├── 02_actinf-livestream-002-1-is-the-free-energy/
│   └── ...
├── gueststreams/
├── mathstreams/
└── ...                               # 38 playlist directories total
```

Every playlist directory and numbered video directory below this hub is generated by the pipeline. Do not hand-edit those directories; change the playlist metadata or the pipeline and regenerate. This README and `AGENTS.md` are the parent contract for all of them.

## Regenerating the archive

Run these from `software/`, where the scripts and `pyproject.toml` live. From the repository root, run `cd software` first.

```bash
cd software

# Download new transcripts
uv run python scripts/transcribe_youtube.py

# Translate transcripts
uv run python scripts/translate_youtube.py

# Render as course materials
uv run python scripts/render_youtube_courses.py
```

Do not run these from the repository root: `scripts/` resolves only inside `software/`.
