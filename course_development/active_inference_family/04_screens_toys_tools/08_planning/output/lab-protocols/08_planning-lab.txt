Lab: Scratch Jr. (My First Code)

Goal

To write a real computer program using blocks.

What You Need

 A tablet with Scratch Jr. (Free App).
 Or use MIT Scratch on a computer.

Steps

Choose a Sprite

Pick a character (Cat, Dog, Rocket).

Make it Move

Drag the "Move Right" block.
Drag the "Jump" block.
Connect them like Lego.
Tap the flag. Does it move?

Add a Loop

Put the "Repeat Forever" red block at the end.
Now your character dances forever!

Discussion

 Did the computer do exactly what you told it?
 What happens if you put the blocks in the wrong order?
You just wrote code!

What We Learned

Coding is creative. It is like painting with logic.
