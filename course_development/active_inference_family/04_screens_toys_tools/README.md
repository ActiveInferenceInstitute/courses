## What This Course Is About

This course applies Active Inference to the questions every modern parent faces: **How much screen time is okay? Which toys actually matter? How does technology shape my child's developing brain?** Instead of simple rules ("no screens before 2!"), this course gives you a framework for thinking about media, toys, and technology as tools that shape your child's generative model.

## The Core Insight

Every toy, screen, app, and tool is a source of **data** for your child's developing brain. The question is not "good or bad?" but "what kind of model is this building?" A wooden block and a tablet both provide input — but they build very different predictions, and the brain develops differently depending on which inputs dominate.

## How to Use This Course

This course is designed for the parent standing in a toy store, staring at a screen, or fielding a toddler's demand for "more tablet." It gives you thinking tools — not rigid rules — for making decisions about media and technology in your family.
