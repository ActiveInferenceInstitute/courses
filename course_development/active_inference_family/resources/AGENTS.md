# Resources — AGENTS

## Purpose

This directory holds the shared reference materials for the Active Inference for Families curriculum.

## Maintenance Rules

1. **Glossary**: Add new terms alphabetically. Every term must include both a 🧠 (neuroscience) definition and a 👶 (parenting) translation.
2. **Notation**: This curriculum uses minimal notation. Only add symbols that appear in diagrams or concept cards.
3. **References**: Follow APA 7th edition format. Include a parenthetical note explaining what each reference contributes.
4. **Cross-Course Map**: Update links whenever modules are renamed or restructured.
5. **FAQ**: Add questions as they emerge from real parent feedback. Keep answers conversational.
6. **Learning Pathways**: Each pathway must include specific module links in a weekly table format.
