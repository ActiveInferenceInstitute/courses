# AGENTS: Course 2 — Tiny Bodies, Big Brains

## Identity

- **Course**: Tiny Bodies, Big Brains
- **Course Number**: 2 of 4
- **Perspective**: Developmental milestones and neuroscience
- **Lab Type**: Development Tracker
- **Audience**: Parents wanting to understand the science behind milestones

## Content Conventions

- Every module connects one Active Inference concept to developmental neuroscience
- Tone balances warmth with scientific depth — accessible but not dumbed down
- Milestone ranges are always given (e.g., "typically 6–10 months") to avoid anxiety
- Development is framed as model refinement, never as a race

## Module–Topic Mapping

| Module | Topic | Developmental Focus |
|---|---|---|
| 01 | Systems | Neural circuit formation, brain as self-organizing system |
| 02 | Agents | Self/other distinction, mirror neurons, emerging self-awareness |
| 03 | Perception | Visual, auditory, and cross-modal sensory development |
| 04 | Cognition | Piaget stages, working memory, causal reasoning |
| 05 | Action | Motor cortex maturation, motor planning, body schema |
| 06 | Learning | Synaptic pruning, myelination, sensitive periods |
| 07 | Communication | Broca/Wernicke development, phoneme discrimination, syntax |
| 08 | Planning | Prefrontal cortex maturation, inhibitory control, temporal reasoning |
