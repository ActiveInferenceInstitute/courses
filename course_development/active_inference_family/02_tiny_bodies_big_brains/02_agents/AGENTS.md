# AGENTS: Module 02 — Agents

## Conventions
- **Perspective**: Developmental neuroscience
- **Topic**: Agents
- **Subtitle**: The Emergence of Self
- **Course**: Tiny Bodies, Big Brains
- **Lab Type**: Development Tracker — The Mirror Test at Home
- **Key Concepts**: self-awareness, mirror test, mirror neurons, imitation, self-other distinction

## Content Guidelines

### Audience
- Families with children ages 3-12
- Parents and children exploring what it means to be a "little scientist"
- No prior science background assumed

### Tone
- Curious, encouraging, and experimental
- Present each child as a scientist who tests ideas about the world
- Use experiment language: hypothesis, test, result, surprise
- Celebrate curiosity and questioning as the most important skills

### Active Inference Integration
- **Agent** is each child as an active experimenter — not passively receiving the world, but testing it
- **Hypothesis testing** maps to the Active Inference cycle: predict, act, observe, update
- **Self-awareness** is when the agent's generative model includes a model of itself
- **Imitation** is a way agents learn by copying another agent's policy (actions)
- **Mirror neurons** help us understand other agents by simulating their actions in our own brain

### Activity Design
- Activities should involve simple experiments children can run at home
- Include prediction-making ("What do you think will happen?") before each experiment
- Use mirrors, shadows, and recordings to explore self-awareness
- Younger children observe and play; older children record hypotheses and results
- Encourage repeated trials and noticing when results surprise us

### Key Connections
- Link back to Module 01 (Systems): The agent lives inside the body system
- Link forward to Module 03 (Perception): The little scientist uses senses to gather data
