# AGENTS: Module 04 — Cognition

## Conventions
- **Perspective**: Developmental neuroscience
- **Topic**: Cognition
- **Subtitle**: How Thinking Develops
- **Course**: Tiny Bodies, Big Brains
- **Lab Type**: Development Tracker — The Cognitive Stage Spotter
- **Key Concepts**: Piaget stages, working memory, causal reasoning, categorization, object permanence

## Content Guidelines

### Audience
- Families with children ages 3-12
- Parents and children exploring how the brain develops thinking abilities
- No prior science background assumed

### Tone
- Warm, curious, and empowering
- Present the brain as "under construction" — always building new pathways
- Use construction metaphors: building, wiring, connecting, upgrading
- Celebrate each stage of cognitive development as an achievement, not a limitation

### Active Inference Integration
- **Generative model** is the brain's internal picture of how the world works, built through experience
- **Object permanence** demonstrates model development — the brain learns that hidden objects still exist
- **Categorization** is how the brain organizes its model — sorting things into groups to make predictions easier
- **Causal reasoning** is the brain learning "if I do X, then Y happens" — building a predictive model of causes and effects
- **Working memory** is the brain's workspace where it holds and manipulates its current model

### Activity Design
- Activities should involve sorting, matching, hiding, and problem-solving
- Include age-appropriate cognitive challenges (puzzles, memory games, sorting tasks)
- Use tangible objects children can manipulate (blocks, cards, household items)
- Younger children sort by one feature (color); older children sort by multiple features or create their own categories
- Include "trick" activities where expectations are violated to demonstrate prediction

- Link back to Module 03 (Perception): We think about what we perceive
- Link forward to Module 05 (Action): Thinking guides our movements and choices
