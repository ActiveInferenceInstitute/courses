    B) To know where obstacles and goals are

3. What happens if the path is blocked?

5. What is an Obstacle?

6. Can you change your plan?

    B) Yes, if the situation changes
    C) Only on birthdays
    D) Never

7. How does a robot know where it is?
    A) It guesses
    B) It uses sensors and its map (Localization)
    C) It asks a bird
    D) It is magic
