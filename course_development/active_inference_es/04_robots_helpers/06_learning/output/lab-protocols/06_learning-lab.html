Lab: The Training Game

Goal

To experience how Machine Learning feels (Guessing and getting Feedback).

What You Need

  • A hidden object (The "Pattern").
  • A partner (The "Model").
  • A teacher (You).

Steps

1. The Setup

The Teacher chooses a secret rule.

  • Rule Example: "I only like RED things."
  • Rule Example: "I only like ROUND things."

2. The Training data

The Teacher holds up objects.

  • Teacher holds up a Red Apple. -> "YES."
  • Teacher holds up a Blue Pen. -> "NO."
  • Teacher holds up a Red Sock. -> "YES."

3. The Learning

The Partner must guess the rule. "Do you like Red things?" If they guess right, the generic model is trained!

What We Learned

Robots don't just "know" things. They have to see many examples (Data) to figure out the rules. This is called Machine Learning.
