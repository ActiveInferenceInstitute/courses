Course — Module 02 — Think About It

  1. If a robot has no battery, is it still an agent? (It's a sleeping agent!).
  2. Why don't we have robots that do everything yet? (It's hard to program them!).
  3. Is a dog a robot? (No, it's alive. But it is an Agent!).
  4. Can a robot change its mind? (Only if its code says so).
  5. What if a robot makes a mistake? Who is responsible? (The human who coded it!).
  6. Would you want a robot teacher?
  7. Can a robot be an artist? (Some can draw, but do they feel it?).
  8. Do robots have names? (We give them names, like Curiosity Rover).
  9. Is a self-driving car a robot? (Yes, a very big one).
  10. What is the most important rule for a robot? (Be Safe).
