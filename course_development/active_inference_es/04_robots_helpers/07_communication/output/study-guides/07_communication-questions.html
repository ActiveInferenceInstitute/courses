Course — Module 07 — Think About It

  1. Can a robot understand a whisper? (Only if its microphone is sensitive enough).
  2. Why do we need Wi-Fi? (To send data without wires).
  3. Can robots talk to each other underwater? (Radio waves don't work well; they use Sound/Sonar!)
  4. Do robots have a secret language? (Yes, Binary!).
  5. If the internet breaks, can robots still talk? (Only if they have a local network).
  6. Can a robot understand French? (If you install the French Language Pack!).
  7. Why do computers use 0s and 1s? (Because electricity is either ON or OFF).
  8. Can a robot lie to another robot? (Only if a human programs it to be tricky).
  9. How far can a robot signal go? (To Mars! It just takes a few minutes).
  10. Is your remote control a robot communicator? (Yes, it uses invisible infrared light).
