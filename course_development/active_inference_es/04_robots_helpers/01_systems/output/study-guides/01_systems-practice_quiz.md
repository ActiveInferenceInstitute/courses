# Practice Quiz: The Robot Factory

## Part A: Pick the Best Answer

1. What is a Robot?
    A) A magic rock
    B) A System made of parts to do a job
    C) An animal
    D) A sandwich

2. Which part is like the Robot's Eyes?
    A) The Wheels
    B) The Sensors (Camera)
    C) The Battery
    D) The Paint

3. Which part is like the Robot's Brain?
    A) The Computer (Controller)
    B) The Foot
    C) The Wire
    D) The Screw

4. What do Actuators (Motors) do?
    A) Make the robot Move
    B) Make the robot Sleep
    C) Make the robot invisible
    D) Nothing

5. If a robot has no battery (Power), what happens?
    A) It runs fast
    B) It stops working (System failure)
    C) It eats
    D) It dances

6. Why do we build robots?
    A) To help us do work (Dangerous or boring jobs)
    B) To be scary
    C) To weigh paper
    D) To use up metal

7. Is a bicycle a robot?
    A) Yes
    B) No, it doesn't have a computer or sensors! (It is a machine, but not a robot).
    C) Maybe
    D) Only if it talks

## Part B: Tell Us What You Think

1. Draw a robot face. Give it sensors (eyes).
2. If you could build a robot helper, what would it do? (Clean my room? Do my homework?)
3. Name one machine in your house. Is it a system?
