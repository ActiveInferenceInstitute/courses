## Learning Goals

1. **Understand** that an Agent is something that can feel the world and make choices.
2. **Tell the difference** between an Agent (like a cat or a person) and an Object (like a rock or a shoe).
3. **Name** a goal -- something an agent wants to happen.
4. **Describe** how agents take actions to reach their goals.
5. **Pretend** to be an agent and make choices in a fun maze game!

## Key Vocabulary

| Word | What It Means |
| :--- | :--- |
| **Agent** | Something that can feel the world and make choices |
| **Goal** | What an agent wants to happen (like finding food or having fun) |
| **Action** | What an agent does to reach its goal (like running or digging) |
| **Choice** | Picking one thing instead of another |

## Parent/Teacher Notes

This module introduces the concept of an **Agent** -- something that senses the world and makes choices. The story of Squeaky the Squirrel shows how an agent feels hunger, considers options, and chooses an action. The key distinction for children is between things that can choose (agents) and things that cannot (objects). Play the "Agent or Object?" jumping game to make this distinction physical and fun. In Active Inference, agents are systems that have preferred states (goals) and take actions to minimize the gap between where they are and where they want to be.
