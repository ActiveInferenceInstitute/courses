# Story Time

> Part of **Active Inference for Elementary School** | [Curriculum Home](../README.md)

## Overview

**Story Time** explores Active Inference through the lens of narrative & imagination. This course is designed for Grades K-5.

**Tone**: Wonder, play, storytime. No formulas. Drawings and songs.
