# Station: Systems (Counting & Patterns)

> **Quick Navigation**: [Module README](./README.md) | [Course AGENTS](../AGENTS.md)

## Conventions

- **Perspective**: Shapes, sorting, counting
- **Topics**: Systems
- **Lab Style**: Hands-On Puzzle
- **Audience**: Grades K-5
- **Tone**: Wonder, play, storytime

## Content Guidelines

- Use the "Kingdom of Numbers" metaphor: numbers live in a system where everyone has a place and nobody cuts in line.
- A System is a group of parts that work together (body, car, math).
- Order is the big rule: 1, 2, 3, 4... always the same. Without order, chaos!
- Introduce Sets (groups): a Set of Red Apples, a Set of Blue Cars.
- Counting tells us how big the set is.

## Active Inference Integration

- **Systems** are organized groups with rules that make prediction possible. The number system is predictable because of its order.
- For K-5: "Numbers always stay in the same order. That is what makes them a System! If numbers jumped around, we could never predict what comes next."

## Lab Design Principles

- Labs should involve number lines (jumping in order), sorting objects into groups, and discovering that order helps us count.
- Materials: chalk, tape, buttons, blocks.
- Focus on the feeling of order vs. chaos: "What if numbers jumped around?"

## Question Design Standards

- Questions 1-10: "What is your favorite number?" "Is Zero a number?" "Can you count backward?"
- Questions 11-20: "Draw the Kingdom of Numbers." "Sort a pile of objects into sets." "Make a number line on the floor."
