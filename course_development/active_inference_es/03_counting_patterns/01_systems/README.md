## Learning Goals

1. **Understand** that numbers live in a System with rules and order.
2. **Learn** that every number has a special place (1, 2, 3...).
3. **Discover** that a System helps us keep track of things and predict what comes next.
4. **Practice** sorting objects into groups called Sets.
5. **Experience** how order feels different from chaos.

## Key Vocabulary

| Word | What It Means |
| :--- | :--- |
| **System** | A group of parts that work together following rules |
| **Order** | When things go in a line that makes sense (1, 2, 3...) |
| **Set** | A group of things that belong together (like all the red apples) |
| **Number Line** | A line with numbers in order, like a path through the Kingdom |

## Parent/Teacher Notes

This module introduces **Systems** through the metaphor of the "Kingdom of Numbers" -- a place where everything has a fixed order and follows rules. Children learn that numbers form a system because they are predictable: you always know what comes next. The activities involve jumping on number lines and sorting objects into sets, reinforcing the idea that organization helps us count and understand the world. In Active Inference, a system is any organized structure whose regularities enable prediction.
