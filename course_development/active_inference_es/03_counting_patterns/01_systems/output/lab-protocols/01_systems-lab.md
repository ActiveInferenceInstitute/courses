# Lab: The Sorting Detective

## Goal

To practice making **Systems** (Groups/Sets) by sorting messy things.

## What You Need

* A messy pile of small toys (Lego, cars, beads, buttons).
* 3 Bowls (or circles drawn on paper).

## Steps

### 1. The Chaos

Dump the toys on the floor.
It is a mess! It has no System.

### 2. The Rule

Captain Brain needs to make a rule.
**Rule**: "Sort by Color."

* Bowl 1: Red things.
* Bowl 2: Blue things.
* Bowl 3: Yellow things.

### 3. The Sort

Use your Agent Hands to move the items.
Are there any "Tricky" ones? (Maybe a green one?)
Put them in a "Mystery Pile."

### 4. New Rule

Dump them out again.
**New Rule**: "Sort by Size." (Big vs. Small).
Does the System look different now?

## My System Log

| Rule Used | How many piles? | Was it easy? |
| :--- | :--- | :--- |
| **Color** | 3 (Red, Blue, Yellow) | Easy |
| **Size** | 2 (Big, Small) | Harder |

## What We Learned

We can create Systems just by making Rules! Sorting helps us organize the world so we can count it.
