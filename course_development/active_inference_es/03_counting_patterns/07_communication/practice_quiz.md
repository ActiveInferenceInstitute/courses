# Practice Quiz: The Secret Code

## Part A: Pick the Best Answer

1. What is a Symbol?
    A) A picture that means something else
    B) A loud noise
    C) A type of sandwich
    D) Just a scribble

2. Why do we write the number "5" instead of drawing 5 cats?
    A) It is faster and easier
    B) We hate cats
    C) Drawing is illegal
    D) To be mean

3. If you speak English and I speak Spanish, can we understand "2 + 2 = 4"?
    A) No
    B) Yes! Math is a Universal Language.
    C) Only on Sunday
    D) Only if we shout

4. What message does a Stop Sign send?
    A) "Go fast!"
    B) "Stop moving!"
    C) "Eat pizza"
    D) "Hello"

5. Why is writing things down helpful?
    A) It lets us remember later (Message to the Future)
    B) It uses up ink
    C) It makes paper heavy
    D) It is boring

6. If you write a secret code, what do you need?
    A) A friend who knows the Key (Rules)
    B) Invisible ink only
    C) A funny hat
    D) A dark room

7. Which is a communication signal?
    A) Waving hello
    B) Writing a note
    C) Speaking
    D) All of the above!

## Part B: Tell Us What You Think

1. Invent a new symbol for the number "One". Draw it.
2. Write your age. Draw that many stars next to it.
3. If you couldn't speak or write, how would you ask for 2 cookies? (Show me!)
