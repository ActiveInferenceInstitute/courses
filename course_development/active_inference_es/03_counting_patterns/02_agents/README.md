## Learning Goals

1. **Understand** that YOU are an Agent who can count.
2. **Learn** that numbers are tools to help Agents reach goals.
3. **Practice** One-to-One Correspondence (one touch = one number).
4. **Discover** Cardinality -- the last number you say tells you "how many."
5. **Experience** being a detective who solves mysteries with counting.

## Key Vocabulary

| Word | What It Means |
| :--- | :--- |
| **Agent** | Something that senses, thinks, and acts to reach a goal |
| **Counter** | An Agent who counts things to understand the world |
| **One-to-One** | Touching one thing for each number you say |
| **Cardinality** | The last number tells you how many are in the whole group |

## Parent/Teacher Notes

This module introduces **Agents** through the "Counter" detective metaphor. Children learn that counting is an active skill performed by an Agent (them!) to gather information about the environment. The key math concepts are One-to-One Correspondence (touching each item while saying a number) and Cardinality (the last number spoken represents the total). The Cookie Mystery activity makes subtraction tangible. In Active Inference, an Agent actively samples and organizes information to update its model of the world.
