## Learning Objectives

1. **Differentiate** between pragmatic action (getting what you want) and epistemic action (learning something new).
2. **Define** a "policy" as a planned sequence of actions, not just a single choice.
3. **Explain** how action fulfills predictions rather than merely responding to stimuli.
4. **Analyze** the explore-exploit trade-off in everyday decisions using expected free energy.
5. **Evaluate** how self-fulfilling prophecies emerge when actions shape the environment to match predictions.

## Prerequisites

- Completed Modules 01-04 (Systems, Agents, Perception, Cognition)
- Understanding that the brain maintains a generative model of the world

## Key Concepts

| Term | Definition |
|------|-----------|
| Pragmatic Action | Action aimed at achieving preferred outcomes (exploitation) |
| Epistemic Action | Action aimed at reducing uncertainty (exploration) |
| Policy | A planned sequence of actions the agent can select |
| Expected Free Energy | The quantity minimized when choosing among policies, balancing reward and information gain |
