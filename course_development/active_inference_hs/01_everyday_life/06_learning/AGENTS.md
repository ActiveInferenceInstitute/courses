# Station: Learning (Everyday Life)

> **Quick Navigation**: [Module README](./README.md) | [Course AGENTS](../AGENTS.md)

## Conventions

- **Perspective**: Real-world intuition -- skill acquisition, changing opinions, and growing up
- **Topics**: Bayesian Updating, Priors, Likelihoods, Posteriors, Precision, Prediction Error as Teacher
- **Lab Style**: Self-tracking, journaling, and teaching exercises (no coding required)

## Content Guidelines

- Frame learning as model updating, not memorization. The brain gets better by correcting its predictions.
- Use skills students are actively developing (sports, music, gaming, cooking) as primary examples.
- Introduce Bayesian language gently: "what you believed before" = prior, "new evidence" = likelihood, "what you believe now" = posterior.
- Connect precision to stubbornness and open-mindedness in relatable terms.

## Active Inference Integration

- Learning is the long-term updating of generative model parameters in response to accumulated prediction errors.
- Distinguish learning (parameter updates) from perception (state estimation) -- both minimize free energy, but on different timescales.
- Precision-weighting determines how much the agent updates: high-precision evidence causes larger updates.
- Prediction errors are not failures -- they are the signal that drives all learning.

## Lab Design Principles

- Include a personal skill-tracking exercise so students see their own learning curve.
- The prior-strength experiment should use concrete examples with clear contrasts.
- Teaching exercises test understanding more deeply than recall and build communication skills.
- Prediction error diaries should span multiple days to capture real updating.

## Question Design Standards

- Questions should distinguish between learning (model parameter updates) and perception (state estimation).
- Include questions about precision: "Why might a person with very strong priors learn more slowly?"
- At least one question should ask students to map the Bayesian update process onto a personal experience.
