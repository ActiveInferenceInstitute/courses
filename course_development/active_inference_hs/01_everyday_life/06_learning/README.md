## Learning Objectives

1. **Explain** learning as the process of updating internal model parameters through accumulated prediction errors.
2. **Define** priors, likelihoods, and posteriors using everyday language and personal examples.
3. **Distinguish** learning (long-term parameter updating) from perception (moment-to-moment state estimation).
4. **Analyze** the role of precision in determining how much a person updates their beliefs given new evidence.
5. **Evaluate** why prediction errors, though uncomfortable, are essential for all learning.

## Prerequisites

- Completed Modules 01-05 (Systems through Action)
- Understanding of generative models and prediction error

## Key Concepts

| Term | Definition |
|------|-----------|
| Prior | The belief held before new evidence arrives |
| Likelihood | How probable the new evidence is under different hypotheses |
| Posterior | The updated belief after combining the prior with new evidence |
| Precision | The confidence or reliability assigned to a belief or signal |
| Model Update | Changing the parameters of the generative model based on experience |
