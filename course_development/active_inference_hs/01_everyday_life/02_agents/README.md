## Learning Objectives

1. **Define** what makes a system an "agent" in the Active Inference framework (preferred states and surprise minimization).
2. **Classify** everyday entities as agents or non-agents, providing justification based on their ability to maintain preferred states.
3. **Explain** how agents act to minimize surprise by matching sensory inputs to predictions.
4. **Compare** biological agents (humans, animals) with mechanical agents (thermostats, Roombas) in terms of model complexity.
5. **Design** a simple agent on paper by specifying its preferred states, sensors, and actions.

## Prerequisites

- Completed Module 01: Systems (understanding of boundaries and Markov blankets)
- Everyday observation skills

## Key Concepts

| Term | Definition |
|------|-----------|
| Agent | A system that acts to maintain preferred states |
| Preferred States | The set of conditions the agent "wants" to remain in |
| Surprise | Encountering sensory states the agent did not predict |
| Generative Model | The agent's internal theory of how causes produce sensory effects |
