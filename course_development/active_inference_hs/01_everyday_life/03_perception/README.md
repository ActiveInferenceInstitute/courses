## Learning Objectives

1. **Explain** perception as "controlled hallucination" -- the brain predicts sensory input before receiving it.
2. **Define** prediction error as the mismatch between what the brain expects and what it receives.
3. **Analyze** why optical illusions trick the brain by exploiting prior expectations.
4. **Demonstrate** that removing one sensory channel changes how the brain compensates using predictions from other channels.
5. **Apply** the concept of priors to explain why two people can perceive the same event differently.

## Prerequisites

## Key Concepts

| Term | Definition |
|------|-----------|
| Perception | The brain's process of inferring the causes of sensory data |
| Prediction Error | The difference between expected and actual sensory input |
| Prior | A pre-existing belief or expectation that shapes how data is interpreted |
| Top-down Processing | Using internal models (predictions) to interpret raw sensory signals |
