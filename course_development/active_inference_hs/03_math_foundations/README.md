# The Math Behind Active Inference

> **Quick Navigation**: [Curriculum Home](../README.md) | [Syllabus](./syllabus.md) | [Agent Guidelines](./AGENTS.md) | [Resources](../resources/)

## Overview

Why does the brain work the way it does? While biology provides the "hardware," **Mathematics** provides the "logic." To truly understand Active Inference, we must speak the language of probability, sets, and graphs.

**Course 3: Math Foundations** strips away the stories and the cells to look at the equations. You will learn how survival is a calculation, how perception is an update, and how action is an optimization. No high-level calculus is required—just a curious mind and an eye for patterns.

### Course Learning Goals

- **Speak the Greek**: Master the core symbols ($\mu, \eta, \sigma, \alpha$) used to define life.
- **Think in Distributions**: Shift from "Correct/Incorrect" to "Probability and Confidence."
- **Master Bayes' Rule**: Learn the universal formula for updating beliefs in the face of new evidence.
- **Calculate Intelligence**: See how curiosity and decision-making are driven by Expected Free Energy.
