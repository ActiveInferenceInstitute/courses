## Learning Objectives

1. **Compute** running averages and observe how estimates stabilize as data accumulates.
2. **Apply** a learning rate update rule and compare fast vs. slow adaptation.
3. **Fit** a line to data points and compute the sum of squared prediction errors.
4. **Distinguish** overfitting from generalization using the training-error vs. prediction tradeoff.
5. **Connect** the accuracy-complexity tradeoff to free energy minimization in Active Inference.

## Prerequisites

- Completed Module 05: Action (expected value, optimization)
- Averages, basic algebra, plotting on graph paper

## Key Concepts

| Term | Definition |
|------|-----------|
| Running Average | An estimate that updates incrementally as each new data point arrives |
| Learning Rate | A parameter (alpha) controlling how much new data shifts the current estimate |
| Prediction Error | The difference between a model's prediction and the actual observation |
| Overfitting | When a model memorizes training data but fails to predict new data |
| Generalization | The ability of a model to make good predictions on unseen data |
