## Learning Objectives

1. **Compute** expected values for decision problems with multiple strategies and outcomes.
2. **Reframe** reward maximization as loss minimization and verify both yield the same optimal action.
3. **Analyze** the explore-exploit tradeoff by comparing information gain with expected reward.
4. **Apply** intuitive gradient descent to find the minimum of a simple function.
5. **Connect** expected free energy minimization to action selection in Active Inference.

## Prerequisites

- Completed Module 04: Cognition (Bayes' theorem, prior-posterior updating)
- Weighted averages and basic algebra

## Key Concepts

| Term | Definition |
|------|-----------|
| Expected Value | E[X]: the probability-weighted average of all possible outcomes |
| Expected Loss | Probability-weighted average gap between desired and actual outcomes |
| Optimization | Finding the action that maximizes reward or minimizes cost |
| Explore-Exploit Tradeoff | Tension between gathering new information and using what you already know |
| Gradient Descent | Iterative optimization by repeatedly stepping in the direction of improvement |
