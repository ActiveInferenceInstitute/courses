## Learning Objectives

1. **Derive** Bayes' theorem from a counting table and verify it matches the formula.
2. **Apply** Bayes' theorem to compute posterior probabilities given priors and likelihoods.
3. **Compute** the marginal likelihood P(D) using the law of total probability.
4. **Perform** sequential Bayesian updating across multiple rounds of evidence.
5. **Explain** how prior strength (precision) affects the rate of belief change in Active Inference.

## Prerequisites

- Completed Module 03: Perception (conditional probability, likelihood)
- Fraction multiplication and division

## Key Concepts

| Term | Definition |
|------|-----------|
| Bayes' Theorem | P(H\|D) = P(D\|H) * P(H) / P(D): the rule for updating beliefs with evidence |
| Prior | P(H): the agent's belief before observing new data |
| Posterior | P(H\|D): the agent's updated belief after observing data |
| Marginal Likelihood | P(D): the total probability of the data across all hypotheses |
| Precision | Confidence in a belief; strong priors resist updating, weak priors change easily |
