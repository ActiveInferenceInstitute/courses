# Station: Agents (Math Foundations)

> **Quick Navigation**: [Module README](./README.md) | [Course AGENTS](../AGENTS.md)

## Conventions

- **Perspective**: Mathematical reasoning -- probability distributions, expected values, and formal notation
- **Topics**: Random Variables, Probability Distributions, Joint/Marginal Probabilities, Expected Value, Preferred Distributions
- **Lab Style**: Guided worksheet with computation exercises and worked examples

## Content Guidelines

- Start with concrete scenarios (dice, weather, grades) before abstract notation.
- Every formula should have a numerical example students can compute by hand.
- Emphasize that distributions must sum to 1.
- Connect expected value to everyday decision-making.

## Active Inference Integration

- An agent's beliefs are probability distributions over hidden states.
- Preferred distributions encode what the agent "wants."
- Free energy minimization means making actual distributions closer to preferred ones.
- Expected value is the basis for policy evaluation.

## Lab Design Principles

- Include bar-chart drawing exercises to visualize distributions.
- Joint probability tables should use 2x2 layouts for simplicity.
- Expected value exercises should use small, computable numbers.
- Connect preferred distributions to Active Inference motivation explicitly.

## Question Design Standards

- Computational questions should have definite numerical answers.
- Include questions testing the sum-to-1 constraint.
- At least one question should test independence of variables.
