## Learning Objectives

1. **Define** random variables and construct discrete probability distributions that sum to 1.
2. **Compute** joint and marginal probabilities from a two-variable table.
3. **Calculate** expected values for simple scenarios with chance and payoffs.
4. **Represent** agent preferences as probability distributions over desired states.
5. **Connect** preferred distributions to Active Inference's free energy minimization.

## Prerequisites

- Completed Module 01: Systems (Math Foundations)
- Arithmetic with fractions and decimals

## Key Concepts

| Term | Definition |
|------|-----------|
| Random Variable | A variable whose value is determined by a probability distribution |
| Probability Distribution | P(X): assigns a probability to each outcome, totaling 1 |
| Expected Value | E[X]: the probability-weighted average of all outcomes |
| Preferred Distribution | P*(X): the distribution the agent acts to achieve |
