# Station: Systems (Math Foundations)

> **Quick Navigation**: [Module README](./README.md) | [Course AGENTS](../AGENTS.md)

## Conventions

- **Perspective**: Mathematical reasoning -- formal notation, worked examples, and guided derivations
- **Topics**: Set Notation, Variables, State Spaces, Graphs, Markov Blanket (formal definition)
- **Lab Style**: Guided worksheet with structured computation tasks and fill-in derivations

## Content Guidelines

- Introduce mathematical notation gently: define every symbol before using it.
- Each concept should have a worked example followed by a practice exercise.
- Use concrete systems (thermostat, weather, traffic light) to ground abstract notation.
- Target HS-level math: algebra, basic set theory, and graph concepts. No calculus required.

## Active Inference Integration

- Systems are formally defined by their state spaces (sets of possible states).
- The Markov blanket is a graph-theoretic concept: the blanket states are the only path between internal and external states.
- Variables represent quantities that the system tracks or controls.
- Graphs (directed, possibly cyclic) represent causal relationships between variables.

## Lab Design Principles

- Every exercise should have a clear mathematical task with a fill-in area for student work.
- Include at least one graph-drawing exercise.
- Build from simple (set definition) to complex (Markov property verification).
- Provide worked examples before asking students to solve similar problems.

## Question Design Standards

- Questions should require students to write set notation or draw graphs, not just select answers.
- Include computational questions with definite right answers (e.g., "How many states in this space?").
- At least one question should ask students to verify the Markov property on a given graph.
