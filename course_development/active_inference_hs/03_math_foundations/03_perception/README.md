## Learning Objectives

1. **Compute** conditional probabilities P(A|B) from frequency data and Venn diagrams.
2. **Distinguish** between P(A|B) and P(B|A), recognizing the base rate fallacy.
3. **Calculate** likelihoods P(data|hypothesis) for competing hypotheses.
4. **Interpret** likelihood ratios as a measure of relative evidence.
5. **Connect** conditional probability tables to the generative model in Active Inference.

## Prerequisites

- Completed Module 02: Agents (probability distributions, expected value)
- Arithmetic with fractions and decimals

## Key Concepts

| Term | Definition |
|------|-----------|
| Conditional Probability | P(A\|B): the probability of A given that B is known to be true |
| Likelihood | P(data\|hypothesis): how probable observed data is under a given hypothesis |
| Likelihood Ratio | The ratio of likelihoods under two competing hypotheses |
| Generative Model | P(observation\|state): a model specifying how hidden states produce observations |
