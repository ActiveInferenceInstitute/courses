## Learning Objectives

1. **Explain** mirror neurons as a biological mechanism for predicting others' actions by simulating them internally.
2. **Describe** empathy as the brain's process of predicting another agent's internal states using shared neural circuits.
3. **Identify** key social hormones (oxytocin, cortisol, dopamine) and their roles in modulating social prediction precision.
4. **Compare** communication at multiple biological scales (cell-to-cell, hormonal, behavioral, microbiome-host).
5. **Connect** biological social communication to the Active Inference concept of model synchronization between agents.

## Key Concepts

| Term | Definition |
|------|-----------|
| Mirror Neurons | Neurons that fire both when performing and observing an action |
| Empathy Circuits | Shared neural networks that activate for both self and other |
| Oxytocin | Hormone that promotes social bonding and trust |
| Social Prediction | Inferring another agent's internal states from observable behavior |
