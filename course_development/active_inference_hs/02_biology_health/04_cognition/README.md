## Learning Objectives

1. **Map** key brain regions (prefrontal cortex, hippocampus, amygdala, cerebellum, thalamus) to their roles in the generative model.
2. **Explain** how the cortical hierarchy implements multi-level prediction from simple features to complex concepts.
3. **Describe** how neurotransmitters (dopamine, serotonin, norepinephrine) serve as biological precision-weighting signals.
4. **Analyze** cognitive disorders (ADHD, depression, schizophrenia) as disruptions in the generative model or its precision-weighting.
5. **Connect** the biological implementation of cognition to the formal Active Inference framework.

## Prerequisites

- Completed Module 03: Perception (Biology & Health)
- Basic knowledge of brain anatomy (lobes, major structures)

## Key Concepts

| Term | Definition |
|------|-----------|
| Cortical Hierarchy | Layered brain architecture processing from simple to complex features |
| Neurotransmitter | Chemical messenger that modulates neural signaling |
| Precision-Weighting | Biological mechanism adjusting the influence of predictions vs. sensory data |
| Cognitive Disorder | Condition arising from disrupted generative model or precision signals |
