Part 2: The Hierarchical Brain

Goal: Understand how the brain builds models at multiple levels simultaneously.

The brain processes information hierarchically -- from simple features to complex concepts. Map the hierarchy for recognizing a friend's face:

  1. V1 (primary visual cortex): What features does it extract?
  2. V2/V4: What patterns does it assemble?
  3. Fusiform face area: What does it recognize?
  4. Prefrontal cortex: What context and memory does it integrate?
  5. Hippocampus: What associations and memories does it retrieve?

How does this hierarchy relate to the Active Inference idea that the generative model has multiple layers, with each layer predicting the layer below?
