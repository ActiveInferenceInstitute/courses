## Learning Objectives

1. **Explain** how organisms from bacteria to humans qualify as Active Inference agents that maintain preferred states.
2. **Describe** bacterial chemotaxis as the simplest biological implementation of prediction-error minimization.
3. **Identify** nested agents within the human body (immune system, gut microbiome, autonomic nervous system).
4. **Analyze** disease and disorder as failures of biological agency -- breakdowns in the prediction-action loop.
5. **Compare** agent complexity across species by examining model sophistication, sensory range, and action repertoire.

## Prerequisites

- Completed Module 01: Systems (Biology & Health)
- Familiarity with basic microbiology (bacteria, cell receptors)

## Key Concepts

| Term | Definition |
|------|-----------|
| Biological Agent | Any living system that acts to maintain preferred physiological states |
| Chemotaxis | Movement of an organism in response to chemical concentration gradients |
| Nested Agency | Agents (e.g., immune cells) operating within larger agents (the body) |
| Agent Failure | Disease or disorder resulting from breakdown of the prediction-action loop |
