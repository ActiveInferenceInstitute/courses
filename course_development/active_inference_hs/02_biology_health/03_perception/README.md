## Learning Objectives

1. **Trace** the pathway of a sensory signal from receptor cell to cortex, naming key structures at each stage.
2. **Explain** predictive coding as the biological architecture in which higher cortical areas send predictions downward and lower areas send prediction errors upward.
3. **Demonstrate** sensory precision through hands-on experiments (afterimages, two-point discrimination).
4. **Analyze** sensory disorders (phantom limb, tinnitus) as cases of persistent, unresolvable prediction error.
5. **Connect** sensory transduction to the Active Inference concept of encoding observations for the generative model.

## Prerequisites

## Key Concepts

| Term | Definition |
|------|-----------|
| Sensory Transduction | Conversion of a physical stimulus into an electrical neural signal |
| Predictive Coding | Cortical architecture where predictions flow down and errors flow up |
| Sensory Precision | Signal reliability determined by receptor density and neural noise |
| Phantom Perception | Sensation perceived without an external stimulus, due to prediction error |
