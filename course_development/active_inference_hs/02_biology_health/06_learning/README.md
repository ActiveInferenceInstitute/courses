## Learning Objectives

1. **Describe** Long-Term Potentiation (LTP) as the synaptic mechanism by which the brain updates its generative model parameters.
2. **Compare** memory systems (working, episodic, procedural, semantic) and their corresponding brain regions.
3. **Explain** why adolescence is a critical period for learning, connecting synaptic pruning and prefrontal cortex development to model optimization.
4. **Analyze** how health behaviors (sleep, exercise, stress, nutrition) affect synaptic plasticity and learning capacity.
5. **Connect** sleep-dependent memory consolidation to offline model optimization in Active Inference.

## Prerequisites

- Completed Module 05: Action (Biology & Health)
- Basic knowledge of synapse structure and neurotransmitter release

## Key Concepts

| Term | Definition |
|------|-----------|
| Long-Term Potentiation (LTP) | Strengthening of synapses through repeated activation |
| Synaptic Pruning | Removal of unused neural connections during development |
| Memory Consolidation | Transfer of learning from short-term to long-term storage, often during sleep |
| Critical Period | Developmental window of heightened neural plasticity |
