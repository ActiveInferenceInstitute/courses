# Shared Resources

> **Quick Navigation**: [Curriculum Home](../README.md) | [Agent Guidelines](./AGENTS.md)

## Overview

This directory contains all shared resources used across the 4 courses in the Active Inference for High School curriculum. These files define the canonical notation, terminology, references, and cross-course navigation used by all 32 modules.

---

## Contents

| Resource | Description |
|----------|-------------|
| [notation_table.md](./notation_table.md) | Key symbols with plain-English explanations and formal definitions |
| [glossary.md](./glossary.md) | 50+ terms with student-friendly definitions and per-course usage |
| [references.md](./references.md) | Curated references including videos, textbooks, and key papers |
| [cross_course_map.md](./cross_course_map.md) | Complete cross-course navigation map for all 32 modules |
| [learning_pathways.md](./learning_pathways.md) | Suggested study orders by student interest and background |
| [faq.md](./faq.md) | Common questions about Active Inference for HS students and teachers |

---

## Usage

All courses reference these shared resources to ensure consistency:

- **Before writing any formula**: Check [notation_table.md](./notation_table.md)
- **Before defining any term**: Check [glossary.md](./glossary.md)
- **Before citing any source**: Check [references.md](./references.md)
- **Before cross-referencing**: Check [cross_course_map.md](./cross_course_map.md)
