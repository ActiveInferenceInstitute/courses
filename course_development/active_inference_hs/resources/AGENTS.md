## Content Conventions

- **Notation**: Define symbols with plain English first, then formal meaning
- **Glossary**: Give everyday explanation before technical definition
- **References**: Include accessible resources (videos, interactive sites) alongside papers
- **All resources must be consistent** with each other and with module content
