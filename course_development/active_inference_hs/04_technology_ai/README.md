## Overview

Course 4 of the Active Inference for High School curriculum. This course approaches Active Inference from a **computational thinking** perspective, using guided coding lab activities to build understanding.

## Introduction

Welcome to the **Technology & AI** track. This course transforms the theoretical and biological insights of previous modules into functional software agents. You will learn to use Python, NumPy, and the `pymdp` library to build, simulate, and analyze Active Inference agents in digital environments.

## Course Overview

Active Inference provides a unique, first-principles approach to Artificial Intelligence. Unlike standard "black-box" machine learning, Active Inference agents are explainable, curious, and autonomous. This course walks you through the entire implementation pipeline: from setting up a Python loop to building deep, hierarchical minds and coordinating multi-agent swarms.

## Learning Goals

- **Master** the Python tools (NumPy, pymdp) for Active Inference.
- **Translate** mathematical matrices (A, B, C, D) into functional code.
- **Build** autonomous agents that perceive, plan, and act in real-time.
- **Design** ethical AI systems centered on human-aligned preferred states.
