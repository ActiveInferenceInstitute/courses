## Learning Objectives

By the end of this module, you should be able to:

1. **Derive** the Expected Free Energy `G(π) = risk + ambiguity` decomposition from first principles
2. **Compute** softmax policy selection `P(π) = σ(-γG(π))` and analyze the effect of precision `γ` on explore-exploit tradeoffs
3. **Distinguish** pragmatic value (risk: divergence from preferred outcomes) from epistemic value (ambiguity: expected observation entropy)
4. **Apply** the EFE framework to the T-maze and two-armed bandit, computing `G(π)` for competing policies
