Lab 04: Preferences, Priors, and Precision Tuning

Objective

Explore how C, D, E vectors and precision γ shape agent behavior.

Prerequisites

Completed Labs 01–03
Understanding of EFE decomposition (risk + ambiguity)

Part 1: C-Vector Effects

Goal: Compare agent behavior with different preference vectors.

Create a T-maze GenerativeModel (4 states, 3 obs, 3 actions).
Run the perception-action loop for 15 steps with three C-vectors:
   - Cneutral = [0, 0, 0] (no preferences)
   - Creward = [0, 3, -3] (prefer reward)
   - Cexplore = [0, 0, 0] with a noisy A-matrix (epistemic drive)
Record and compare the action sequences and states visited.

Part 2: D-Vector Effects

Goal: Investigate how the initial state prior affects early behavior.

Fix C and E. Create two agents with:
   - Dcertain = [1, 0, 0, 0] (confident at center)
   - Duncertain = [0.25, 0.25, 0.25, 0.25] (uniform)
Run 5 steps. Compare the first action selected and the VFE trajectory.

Part 3: E-Vector and Habit Formation

Goal: Demonstrate how habits bias action selection.

Create an agent with E = [0.8, 0.1, 0.1] (strong stay habit) and γ = 0.5.
Create an agent with E = None and the same γ.
Run both for 20 steps. Count how often each agent selects action 0 (stay).
Visualize habits using plotEhabits().
