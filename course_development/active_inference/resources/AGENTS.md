## Overview

This directory contains the **canonical resources** for the entire Active Inference curriculum. The files here (`notation_table.md`, `glossary.md`, `references.md`, `cross_course_map.md`) serve as the **single source of truth** for all 32 modules.

## Critical Rules for Resources

1. **Single Source of Truth**: Do not define notation or terms locally in course modules. Define them here, then reference them.
2. **Consistency**: Any change here affects all 4 courses. Verify impact before modifying `notation_table.md` or `glossary.md`.
3. **Completeness**: If a new term or symbol is used in a module, it **must** be added here.

## File Responsibilities

| File | Responsibility |
| ------ | ---------------- |
| `README.md` | Resource directory overview and usage guide |
| `notation_table.md` | Defines all mathematical symbols (`F`, `G`, `A`, `B`, etc.) |
| `glossary.md` | Defines all technical terms (Markov Blanket, Epistemic Value, etc.) |
| `references.md` | Lists all 82+ canonical citations |
| `cross_course_map.md` | Maps the 8 topics across the 4 disciplines |
| `learning_pathways.md` | Guides students through the curriculum based on background |
| `faq.md` | Common questions about Active Inference and this curriculum |
