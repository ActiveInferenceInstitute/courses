# Module 06: Learning

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## Synaptic Plasticity and Model Updating

Part of **Computational Neuroscience** -- this module maps learning onto synaptic plasticity, hippocampal function, and sleep consolidation.

## Learning Objectives

By the end of this module, students will be able to:

1. **Explain** how synaptic plasticity (LTP/LTD) implements parameter learning in the generative model
2. **Analyze** the hippocampal-cortical complementary learning system: fast hippocampal encoding and slow cortical consolidation
3. **Evaluate** the role of sleep in Bayesian model reduction, connecting synaptic downscaling to structure learning
4. **Synthesize** Hebbian learning ("neurons that fire together wire together") with Active Inference parameter updates
5. **Apply** the neural learning framework to predict the effects of sleep deprivation on learning and memory

## Prerequisites

- Computational Neuroscience Module 03: Perception (predictive coding circuits)
- Cognitive Science Module 06: Learning (parameter learning, BMR, sleep)

## Key Concepts

- **Synaptic plasticity**: The ability of synapses to strengthen (LTP) or weaken (LTD) over time
- **Hebbian learning**: The principle that co-active neurons strengthen their connections
- **Long-term potentiation (LTP)**: Persistent synaptic strengthening, the cellular mechanism of memory
- **Hippocampus**: Fast-learning buffer for episodic memory and spatial navigation
- **Sleep consolidation**: Hippocampal replay and synaptic downscaling during sleep that consolidates and simplifies the model
