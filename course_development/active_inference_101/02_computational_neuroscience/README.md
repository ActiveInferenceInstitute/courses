# Computational Neuroscience

> Part of **Active Inference 101: College First Semester** | [Curriculum Home](../README.md)

## Overview

**Computational Neuroscience** explores Active Inference through the lens of neural circuits & bayesian brain. This course is designed for College 1st semester undergraduates.

**Tone**: Rigorous but accessible. Full mathematical notation. Python/NumPy. Textbook-quality.
