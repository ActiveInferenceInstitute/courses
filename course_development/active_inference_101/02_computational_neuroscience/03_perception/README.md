## Predictive Coding in the Brain

Part of **Computational Neuroscience** -- this module grounds predictive processing in neural circuits, with evidence from electrophysiology and neuroimaging.

## Learning Objectives

By the end of this module, students will be able to:

1. **Explain** predictive coding as a neural algorithm with predictions flowing top-down and prediction errors flowing bottom-up through cortical layers
2. **Analyze** mismatch negativity (MMN) and repetition suppression as neural evidence for predictive coding
3. **Evaluate** how neuromodulators (acetylcholine, dopamine) implement precision weighting at the neural level
4. **Apply** the predictive coding framework to interpret specific neuroimaging and electrophysiology findings
5. **Compare** the neural implementation of perception with the mathematical formalism from the Math Frameworks course

## Prerequisites

- Computational Neuroscience Module 02: Agents (cortical hierarchy, canonical microcircuit)
- Cognitive Science Module 03: Perception (predictive processing, precision)

## Key Concepts

- **Predictive coding**: Neural implementation where cortical areas generate predictions about input and receive prediction errors
- **Mismatch negativity (MMN)**: An ERP component reflecting violated predictions, evidence for predictive coding
- **Repetition suppression**: Decreased neural response to repeated stimuli, reflecting successful prediction
- **Neural precision**: Gain modulation of prediction error units via neuromodulators
- **Acetylcholine**: Boosts sensory precision; **Dopamine**: Boosts prior precision
