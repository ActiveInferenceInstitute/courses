## Neural Systems as Dynamical Systems

Part of **Computational Neuroscience** -- this module introduces the brain as a dynamical system with neural populations, oscillations, and attractors.

## Learning Objectives

By the end of this module, students will be able to:

1. **Describe** the brain as a dynamical system whose state evolves over time according to neural interaction rules
2. **Analyze** neural oscillations (alpha, beta, gamma, theta) as self-organized coordination mechanisms
3. **Evaluate** attractor dynamics as an explanatory framework for memory, perception, and decision-making
4. **Apply** the Markov blanket concept at neural scales, identifying sensory states (dendrites), active states (axon terminals), and internal states (membrane potential)
5. **Compare** different types of attractors (fixed-point, limit-cycle, strange) and their neural correlates

## Prerequisites

- Cognitive Science Module 01: Systems (general systems concepts, Markov blankets)
- Basic familiarity with neurons and synapses (high school biology level)

## Key Concepts

- **Dynamical system**: A system whose state evolves over time according to deterministic or stochastic rules
- **Neural population**: A group of neurons whose collective activity encodes information
- **Neural oscillation**: Rhythmic patterns of neural firing that coordinate activity across brain regions
- **Attractor**: A stable pattern of neural activity that the system tends to settle into
- **State space**: The space of all possible neural activity patterns, within which the brain traces trajectories
