## Motor Circuits and Active Inference

Part of **Computational Neuroscience** -- this module maps action selection and motor control onto motor cortex, basal ganglia, and cerebellum.

## Learning Objectives

By the end of this module, students will be able to:

1. **Explain** motor control as active inference: the motor cortex generates proprioceptive predictions that spinal reflexes fulfill
2. **Analyze** the basal ganglia as the neural substrate for policy selection via expected free energy evaluation
3. **Evaluate** the cerebellum's role as a forward model predicting the sensory consequences of actions
4. **Compare** habitual action (dorsolateral striatum) with goal-directed action (dorsomedial striatum) using Active Inference concepts
5. **Apply** the active inference model of motor control to explain Parkinson's disease and other movement disorders

## Prerequisites

- Computational Neuroscience Module 02: Agents (cortical hierarchy)
- Cognitive Science Module 05: Action (EFE, exploration vs. exploitation)

## Key Concepts

- **Motor cortex**: Generates proprioceptive predictions (not direct muscle commands)
- **Basal ganglia**: Evaluate competing action policies via EFE, selecting the best policy
- **Cerebellum**: Maintains a forward model for rapid prediction of action consequences
- **Spinal reflex arc**: The simplest active inference loop, minimizing proprioceptive prediction error
- **Dopamine and action**: Dopaminergic signals weight competing policies in the basal ganglia
