## Neural Substrates of Belief Updating

Part of **Computational Neuroscience** -- this module maps cognitive processes onto prefrontal cortex, dopamine, attention networks, and the default mode network.

## Learning Objectives

By the end of this module, students will be able to:

1. **Identify** the neural substrates of belief updating: prefrontal cortex (hypothesis evaluation), anterior cingulate (error monitoring), insula (interoceptive prediction)
2. **Analyze** the roles of dopamine, acetylcholine, and noradrenaline in implementing precision weighting across neural circuits
3. **Evaluate** the default mode network as the neural substrate of the generative model running in "offline" mode
4. **Synthesize** computational neuroscience accounts of psychiatric conditions (schizophrenia, ADHD, depression) as aberrant precision weighting
5. **Apply** the salience network concept to explain how the brain detects and redirects attention to surprising events

## Prerequisites

- Computational Neuroscience Module 03: Perception (predictive coding, neuromodulation)
- Cognitive Science Module 04: Cognition (VFE, accuracy-complexity, cognitive biases)

## Key Concepts

- **Prefrontal cortex (PFC)**: Maintains abstract beliefs and evaluates competing hypotheses
- **Dopaminergic system**: Signals precision of prior beliefs and expected reward
- **Default mode network (DMN)**: Active during rest and mental simulation, linked to the generative model
- **Salience network**: Detects surprising events and redirects attention (insula, ACC)
- **Aberrant precision**: Miscalibrated confidence that produces psychiatric symptoms
