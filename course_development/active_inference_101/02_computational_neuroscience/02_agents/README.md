## Neural Architecture of Active Inference Agents

Part of **Computational Neuroscience** -- this module maps the agent concept onto cortical hierarchy and neural architecture.

## Learning Objectives

By the end of this module, students will be able to:

1. **Explain** how the cortical hierarchy implements a generative model with predictions flowing top-down and errors flowing bottom-up
2. **Analyze** the canonical microcircuit as the basic computational unit of predictive processing in the brain
3. **Evaluate** how different levels of brain complexity (insect to human) implement increasingly sophisticated generative models
4. **Synthesize** the concept of a neural self-model by connecting interoceptive cortex, proprioception, and metacognition
5. **Distinguish** superficial pyramidal cells (prediction errors) from deep pyramidal cells (predictions) in cortical columns

## Prerequisites

- Computational Neuroscience Module 01: Systems (neural populations, attractors)
- Cognitive Science Module 02: Agents (generative models, self-models)

## Key Concepts

- **Cortical hierarchy**: The layered cortical organization where each level predicts activity at the level below
- **Top-down processing**: Predictions flowing from higher to lower cortical areas
- **Bottom-up processing**: Prediction errors flowing from lower to higher cortical areas
- **Canonical microcircuit**: The cortical column as the basic unit of Active Inference computation
- **Interoceptive cortex**: Brain regions (insula) that maintain the self-model through internal body sensing
