## Neural Circuits for Prospection

Part of **Computational Neuroscience** -- the capstone module maps planning, imagination, and habit formation onto hippocampal replay and prefrontal prospection.

## Learning Objectives

By the end of this module, students will be able to:

1. **Explain** hippocampal replay as neural implementation of planning as inference, simulating possible future trajectories
2. **Analyze** place cells and grid cells as the spatial generative model used for navigation and planning
3. **Evaluate** the distinction between goal-directed (dorsomedial striatum) and habitual (dorsolateral striatum) neural circuits for action selection
4. **Synthesize** the relationship between imagination and perception at the neural level, showing that both use overlapping neural populations
5. **Apply** the neural planning framework to explain prefrontal damage, impulsivity, and prospection deficits

## Prerequisites

- Computational Neuroscience Module 05: Action (basal ganglia, motor circuits)
- Cognitive Science Module 08: Planning (planning as inference, deep temporal models)

## Key Concepts

- **Place cells**: Hippocampal neurons encoding spatial location, forming a spatial generative model
- **Grid cells**: Entorhinal cortex neurons providing a coordinate system for spatial planning
- **Hippocampal replay**: Reactivation of sequential place cell patterns during rest, simulating future paths
- **Prefrontal prospection**: PFC-mediated simulation of future scenarios using the generative model
- **Goal-directed vs. habitual**: Two neural systems for action selection with different precision profiles
