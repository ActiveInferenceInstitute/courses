Module 08: Planning — Deep Temporal Models and Planning as Inference

Course: Active Inference 101 | Unit: Mathematical Frameworks | Audience: First-semester undergraduates

Learning Objectives

  1. Formalize planning as inference over policies using Expected Free Energy.
  2. Introduce deep temporal models — hierarchical models that plan across multiple timescales.
  3. Explain how habits emerge mathematically as strong policy priors.

Introduction

Planning is the capstone of Active Inference's formal framework. This module shows how the machinery developed throughout this unit — generative models, variational inference, EFE, and learning — combines to produce planning, habit formation, and hierarchical decision-making.

Key Concepts

1. Planning as Inference

Traditional AI treats planning as a search problem. Active Inference treats planning as inference:

  • Define policies π as sequences of actions: π = [a₁, a₂, ..., a_T]
  • Evaluate each policy using Expected Free Energy: G(π)
  • Select policies via posterior: P(π | o) ∝ P(π) × exp(-G(π))
  • The policy prior P(π) encodes habits — the default tendency toward certain action sequences

Planning is not separate from inference — it's the same variational inference machinery applied to the policy dimension.

2. Tree Search via Policy Evaluation

Each policy generates a predicted future trajectory:

For policy π = [a₁, a₂, a₃]:

  • t=1: q̃(s₁) = Σ B(:,:,a₁) × q(s₀) → q̃(o₁) = A × q̃(s₁)
  • t=2: q̃(s₂) = Σ B(:,:,a₂) × q̃(s₁) → q̃(o₂) = A × q̃(s₂)
  • t=3: q̃(s₃) = Σ B(:,:,a₃) × q̃(s₂) → q̃(o₃) = A × q̃(s₃)

The agent mentally simulates each policy's consequences, then selects the policy with lowest total expected free energy.

3. Deep Temporal Models

Real planning involves multiple timescales simultaneously:

  • Fast timescale: "Which finger movement do I make?" (milliseconds)
  • Medium timescale: "Which sentence do I say?" (seconds)
  • Slow timescale: "Which career do I pursue?" (years)

Deep temporal models are hierarchical POMDPs where higher levels operate on slower timescales:

  • Higher level: Sets goals (C vectors) for the level below
  • Lower level: Selects policies to achieve those goals
  • Transitions at higher levels are slower (B matrix with fewer state changes per unit time)

This creates a hierarchy: abstract plans at the top, concrete actions at the bottom.

4. Habit Formation — Strong Policy Priors

Habits emerge when the policy prior P(π) becomes very strong:

  • Initially: P(π) is relatively flat → the agent evaluates all policies (goal-directed behavior)
  • With experience: Successful policies accumulate evidence → P(π) sharpens
  • Eventually: P(π) is so strong that EFE evaluation is bypassed → habitual behavior

Mathematically: P(π | o) ∝ P(π) × exp(-G(π)). When P(π) dominates, the posterior follows the prior regardless of EFE.

5. The Complete Active Inference Algorithm

Bringing everything together — what the agent does at each time step:

  1. Observe: o_t
  2. Infer states: q(s_t) ← minimize F with respect to states
  3. Evaluate policies: G(π) ← compute EFE for each policy
  4. Select policy: P(π | o) ∝ P(π) × exp(-γG(π))
  5. Act: Execute a_t from the selected policy
  6. Learn: Update parameters (A, B, C, D) via Dirichlet updates
  7. Sleep: Perform BMR to simplify model structure
  8. Repeat

This is the complete mathematical specification of an Active Inference agent.

Summary

Planning is inference over policies, evaluated using Expected Free Energy. Deep temporal models extend this to hierarchical planning across multiple timescales. Habits emerge as strong policy priors that bypass evaluation. The complete Active Inference algorithm integrates perception, cognition, action, learning, communication, and planning into a single mathematical framework.
