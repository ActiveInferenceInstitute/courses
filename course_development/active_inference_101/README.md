## Overview

Welcome to **Active Inference 101** — your first semester introduction to one of the most powerful unifying theories in cognitive science. Active Inference proposes that all living systems work by constantly predicting and acting to minimize surprise.

This curriculum assumes no prior knowledge of the Free Energy Principle and builds understanding progressively through four complementary lenses.

## Core Topics

| # | Topic | 01 CogSci | 02 CompNeuro | 03 Math | 04 Implementation |

| 1 | **Systems** | Cognitive systems | Neural architectures | Dynamical systems | System design |
| 2 | **Agents** | Embodied agents | Neural agents | Agent formalism | Agent classes |
| 3 | **Perception** | Perceptual inference | Predictive coding | Bayesian inference | Sensor models |
| 4 | **Cognition** | Belief updating | Cortical hierarchies | Variational methods | Inference engines |
| 5 | **Action** | Active inference loop | Motor control | Expected free energy | Control loops |
| 6 | **Learning** | Model learning | Synaptic plasticity | Parameter estimation | Training algorithms |
| 7 | **Communication** | Social cognition | Neural communication | Information theory | Message passing |
| 8 | **Planning** | Goal-directed behavior | Prefrontal planning | Policy optimization | Planning agents |

## Design Principles

1. **Spiral learning**: The same 8 topics repeat across all 4 courses at increasing depth
2. **Multiple perspectives**: Each course teaches the same framework through a different lens
3. **Active engagement**: Every module includes a lab for hands-on practice
4. **Self-assessment**: Practice quizzes provide immediate feedback
5. **Accessibility**: Assumes motivated undergraduates with no prior FEP knowledge
