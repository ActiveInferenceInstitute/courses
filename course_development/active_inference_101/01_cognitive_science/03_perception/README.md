> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## How Agents Make Sense of the World

Part of **Cognitive Science** -- this module reframes perception as active, prediction-driven construction rather than passive reception.

## Learning Objectives

By the end of this module, students will be able to:

1. **Explain** the predictive processing framework: the brain generates top-down predictions and compares them with bottom-up sensory data
2. **Define** prediction error and describe how it drives Bayesian belief updating (prior + likelihood = posterior)
3. **Analyze** visual illusions and perceptual phenomena as evidence for the constructive nature of perception
4. **Evaluate** the role of precision weighting in determining whether priors or sensory data dominate perception
5. **Compare** predictive processing with traditional "bottom-up" theories of perception

## Prerequisites

- Module 01: Systems (Markov blankets)
- Module 02: Agents (generative models, prediction error)

## Key Concepts

- **Predictive processing**: The framework in which the brain generates predictions and compares them with sensory data
- **Prediction error**: The difference between predicted and actual sensory input
- **Precision**: The confidence assigned to a prediction or sensory signal, acting as a "volume knob"
- **Bayesian inference**: Updating beliefs by combining prior expectations with new evidence
- **Prior**: What the brain expected before receiving sensory data
- **Posterior**: The updated belief after combining prior and data
