# Module 07: Communication

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## How Agents Interact

Part of **Cognitive Science** -- this module extends Active Inference to multi-agent interaction, communication, and culture.

## Learning Objectives

By the end of this module, students will be able to:

1. **Explain** communication as shared inference -- agents aligning their generative models to predict each other
2. **Analyze** Theory of Mind as hierarchical inference: modeling another agent's beliefs, desires, and intentions
3. **Evaluate** how language, cultural norms, and institutions function as shared priors that enable efficient inter-agent prediction
4. **Synthesize** an Active Inference account of echo chambers, misinformation, and polarization
5. **Apply** the concept of coupled inference to analyze a specific real-world communication scenario

## Prerequisites

- Module 02: Agents (generative model, self-model)
- Module 03: Perception (prediction error, Bayesian inference)
- Module 04: Cognition (precision weighting)

## Key Concepts

- **Shared inference**: The alignment of generative models between communicating agents
- **Theory of Mind (ToM)**: Modeling another agent's hidden states within one's own generative model
- **Cultural norms**: Large-scale shared priors that enable efficient prediction across communities
- **Echo chamber**: A social environment where priors are reinforced rather than challenged
- **Coupled dynamics**: The reciprocal process where each agent models the other modeling them
