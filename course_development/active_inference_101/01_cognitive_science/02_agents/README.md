> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## What Makes Something an Agent?

Part of **Cognitive Science** -- this module introduces agency as a special property of systems that possess generative models.

## Learning Objectives

By the end of this module, students will be able to:

1. **Distinguish** an agent from a non-agent system using the criterion of possessing a generative model
2. **Describe** the components of a generative model: beliefs (estimates of hidden states) and preferences (expected sensory outcomes)
3. **Analyze** the predict-compare-update cycle as the core process driving all agents
4. **Evaluate** examples across the spectrum of agency, from minimal (bacteria) to reflective (humans)
5. **Synthesize** the connection between self-models, subjective experience, and Active Inference

## Prerequisites

- Module 01: Systems (Markov blankets, open systems, homeostasis/allostasis)

## Key Concepts

- **Agent**: A system that possesses a generative model and acts to minimize prediction error
- **Generative model**: A probabilistic model specifying how hidden states cause observations, written as p(observations, states)
- **Self-model**: The agent's internal representation of its own body, position, and mental states
- **Prediction error**: The mismatch between expected and actual sensory input
- **Spectrum of agency**: The continuum from minimal agency (bacteria) through reflective agency (humans)
