# Station: Agents (Cognitive Science)

> **Quick Navigation**: [Module README](./README.md) | [Course AGENTS](../AGENTS.md)

## Conventions

- **Perspective**: Mind, brain, behavior
- **Topics**: Agency, generative models, self-models, predict-compare-update cycle, spectrum of agency
- **Lab Style**: Essay & Discussion
- **Audience**: College 1st semester undergraduates
- **Tone**: Rigorous but accessible

## Content Guidelines

This module transitions from systems to agents, introducing the generative model as the defining feature of agency. Content should:

1. **Build on Module 01**: Students already know what systems and Markov blankets are. Now show that agents are a special kind of system -- one whose internal states encode a model of the environment.
2. **Define key terms precisely**:
   - **Agent**: A system that possesses a generative model and acts to minimize prediction error
   - **Generative model**: A probabilistic model specifying how hidden states cause observations, written as p(observations, states)
   - **Self-model**: The agent's internal representation of its own boundaries and states
   - **Prediction error**: The discrepancy between expected and actual sensory input
3. **Use the spectrum of agency**: Emphasize that agency ranges from minimal (bacteria) through basic (insects), rich (mammals), to reflective (humans). This prevents the common misconception that Active Inference only applies to conscious beings.
4. **Highlight the predict-compare-update cycle** as the core engine of all agents.

## Active Inference Integration

- The generative model is the central formal object in Active Inference (Parr et al., 2022, Chapter 3)
- Connect to the two ways of minimizing prediction error: perception (updating beliefs) and action (changing the world)
- Introduce the concept of preferences as prior expectations about sensory outcomes

## Assessment Alignment

Questions should test the ability to:
- Distinguish agents from non-agent systems using the generative model criterion
- Identify the components of a generative model in everyday examples
- Explain the predict-compare-update cycle in a novel scenario
