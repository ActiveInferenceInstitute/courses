# Module 08: Planning

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## How Agents Think Ahead

Part of **Cognitive Science** -- the capstone module shows how planning uses the same inferential machinery as perception.

## Learning Objectives

By the end of this module, students will be able to:

1. **Explain** planning as inference about the future: evaluating possible policies by simulating their expected outcomes
2. **Analyze** deep temporal models as hierarchical predictions across timescales from milliseconds to years
3. **Evaluate** imagination and counterfactual reasoning as offline inference using the generative model
4. **Compare** habits (strong policy priors) with deliberate planning (full EFE evaluation) and explain when each is adaptive
5. **Synthesize** the concept of bounded rationality with Active Inference, explaining how agents cope with computational limits

## Prerequisites

- Module 04: Cognition (free energy, epistemic value)
- Module 05: Action (Expected Free Energy, policy selection)
- Module 06: Learning (parameter learning, habituation)

## Key Concepts

- **Planning as inference**: Evaluating possible action sequences by simulating expected outcomes and minimizing expected free energy
- **Deep temporal model**: A hierarchical generative model with predictions at multiple timescales
- **Counterfactual reasoning**: Running the generative model in "what if" mode
- **Habit**: A policy with a strong prior, selected efficiently without full deliberation
- **Bounded rationality**: Rational decision-making under computational and informational constraints
