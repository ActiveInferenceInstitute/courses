# Station: Action (Cognitive Science)

> **Quick Navigation**: [Module README](./README.md) | [Course AGENTS](../AGENTS.md)

## Conventions

- **Perspective**: Mind, brain, behavior
- **Topics**: Action as prediction fulfillment, expected free energy, exploration vs. exploitation, motor control as inference
- **Lab Style**: Essay & Discussion
- **Audience**: College 1st semester undergraduates
- **Tone**: Rigorous but accessible

## Content Guidelines

This module completes the perception-action loop by showing how agents change the world to match predictions. Content should:

1. **Contrast with reward-based views**: Traditional psychology explains action through reward and punishment. Active Inference offers an alternative: action fulfills predictions rather than seeking reward. Present both views and explain the Active Inference advantage.
2. **Define key terms precisely**:
   - **Action**: The process of changing sensory input to match predictions, the complement of perception
   - **Expected Free Energy (EFE)**: The quantity minimized when selecting policies, combining pragmatic and epistemic value
   - **Pragmatic value**: The degree to which an action brings preferred outcomes
   - **Epistemic value**: The degree to which an action reduces uncertainty
   - **Policy**: A sequence of planned actions evaluated via EFE
3. **Solve the exploration-exploitation dilemma**: Show that EFE naturally balances curiosity and goal achievement.
4. **Connect motor control to inference**: Even basic movement is the body fulfilling the brain's proprioceptive predictions.

## Active Inference Integration

- Action selection minimizes EFE = pragmatic value + epistemic value (Friston et al., 2015)
- Motor control as active inference: reflex arcs as prediction error minimizers (Adams, Shipp, & Friston, 2013)
- Policies are evaluated probabilistically; the agent does not always choose the single best policy

## Assessment Alignment

Questions should test the ability to:
- Explain action as prediction fulfillment using a concrete scenario
- Distinguish pragmatic from epistemic value in a decision-making example
- Describe how the exploration-exploitation balance shifts with uncertainty
