# Module 05: Action

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## How Agents Change the World

Part of **Cognitive Science** -- this module completes the perception-action loop, showing how agents act to fulfill predictions.

## Learning Objectives

By the end of this module, students will be able to:

1. **Explain** action as prediction fulfillment: agents change the world to match their predictions, not to seek reward
2. **Analyze** Expected Free Energy (EFE) as the quantity guiding action selection, combining pragmatic and epistemic value
3. **Distinguish** epistemic actions (exploring to reduce uncertainty) from pragmatic actions (exploiting to achieve goals)
4. **Evaluate** how Active Inference naturally resolves the exploration-exploitation dilemma
5. **Apply** the concept of motor control as active inference to understand movement, reflexes, and motor disorders

## Prerequisites

- Module 03: Perception (prediction error, belief updating)
- Module 04: Cognition (free energy, epistemic value)

## Key Concepts

- **Action as prediction fulfillment**: The complement of perception -- changing the world to match the model
- **Expected Free Energy (EFE)**: The expected surprise under a given policy, guiding action selection
- **Pragmatic value**: The degree to which an action brings preferred outcomes
- **Epistemic value**: The degree to which an action reduces uncertainty about hidden states
- **Policy**: A sequence of planned actions evaluated via EFE
