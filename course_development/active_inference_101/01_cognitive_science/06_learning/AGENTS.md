## Conventions

- **Perspective**: Mind, brain, behavior
- **Topics**: Parameter learning, structure learning, Bayesian model reduction, skill acquisition, sleep and consolidation
- **Lab Style**: Essay & Discussion
- **Audience**: College 1st semester undergraduates
- **Tone**: Rigorous but accessible

## Content Guidelines

This module distinguishes learning from perception by timescale. Content should:

1. **Clarify the two timescales**: Perception updates beliefs about current states (fast); learning updates model parameters (slow). Use the analogy of adjusting a thermostat setting (perception) versus rewiring the thermostat (learning).
2. **Define key terms precisely**:
   - **Parameter learning**: Updating the matrices (A, B, D) of the generative model based on accumulated experience
   - **Structure learning**: Simplifying the model by pruning unnecessary states or connections (Bayesian model reduction)
   - **Bayesian Model Reduction (BMR)**: A process that evaluates whether parts of the model are doing useful work and removes those that are not
   - **Habituation**: The transition from effortful, error-prone performance to automatic, low-error performance
3. **Connect to everyday learning**: Skill acquisition (learning to drive), category learning (learning animal types), and memory consolidation (why sleep helps studying).
4. **Introduce the role of sleep**: BMR may occur primarily during sleep, connecting Active Inference to sleep research.

## Active Inference Integration

- Learning is inference on a slower timescale: updating hyperparameters of the generative model (Friston et al., 2017)
- BMR during sleep explains consolidation and the "insight after sleep" phenomenon
- Habituation corresponds to increasing precision of action policies through repeated success

## Assessment Alignment

Questions should test the ability to:
- Distinguish parameter learning from structure learning with examples
- Explain why sleep is important for learning using Active Inference concepts
- Trace the trajectory from novice to expert using prediction error and precision
