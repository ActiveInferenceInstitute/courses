# Module 06: Learning

> **Quick Navigation**: [Course Home](../README.md) | [Curriculum Home](../../README.md)

## How Agents Improve Over Time

Part of **Cognitive Science** -- this module distinguishes learning from perception by timescale and introduces structure learning.

## Learning Objectives

By the end of this module, students will be able to:

1. **Distinguish** perception (fast: updating beliefs about current states) from learning (slow: updating model parameters)
2. **Explain** parameter learning as the accumulation of experience that refines the generative model's A, B, and D matrices
3. **Analyze** structure learning (Bayesian Model Reduction) as the process of pruning unnecessary model complexity
4. **Evaluate** the role of sleep in memory consolidation and model simplification using Active Inference concepts
5. **Synthesize** the trajectory from novice to expert in terms of prediction error reduction and precision increase

## Prerequisites

- Module 02: Agents (generative model)
- Module 03: Perception (belief updating)
- Module 04: Cognition (accuracy-complexity trade-off)

## Key Concepts

- **Parameter learning**: Updating the matrices of the generative model based on accumulated experience
- **Structure learning**: Simplifying the model by removing unnecessary complexity (Bayesian Model Reduction)
- **Bayesian Model Reduction (BMR)**: Evaluating whether parts of the model contribute to model evidence and pruning those that do not
- **Habituation**: The transition from effortful, high-error performance to automatic, low-error performance
- **Two timescales of inference**: Fast (perception) and slow (learning) inference on the same generative model
