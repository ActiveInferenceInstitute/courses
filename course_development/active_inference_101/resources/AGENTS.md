# AGENTS: Shared Resources

> **Quick Navigation**: [Resources README](./README.md) | [Curriculum AGENTS](../AGENTS.md)

## Purpose

These shared resources serve as the single source of truth for terminology, notation, and references across all four courses in Active Inference 101: College First Semester. Every module in the curriculum references these resources, making consistency and accuracy critical.

## Maintenance Rules

1. **Update the glossary** when new terms are introduced in any module. Every bolded key term in a module.md should have a corresponding glossary entry.
2. **Keep the notation table synchronized** with all four courses. Mathematical symbols introduced in Mathematical Frameworks (Course 3) must be cross-referenced here with their plain-language equivalents from Cognitive Science (Course 1).
3. **Verify cross-course map links** after any structural changes. The map should accurately reflect which modules in different courses cover related topics.
4. **All tables must use proper MD060-compliant formatting** (spaces around pipes, consistent column alignment).
5. **References must follow APA 7th edition** format consistently. Include DOIs where available.

## Content Guidelines

- **Audience**: College 1st semester undergraduates. Resources should be usable by students coming from any of the four course perspectives.
- **Tone**: Clear, precise, and neutral. Resources are reference materials, not narrative content.
- **Accessibility**: The glossary and notation table should bridge the gap between informal (Cognitive Science) and formal (Mathematical Frameworks) terminology. Each entry should include both plain-language and formal definitions.
- **Scope**: Resources cover only terms, symbols, and references that appear in the Active Inference 101 curriculum. External references should be limited to foundational texts and high-quality open-access materials.

## Cross-Course Consistency

The resources directory enforces consistency across the four courses:

| Resource | Ensures Consistency Of |
| --- | --- |
| glossary.md | Term definitions across all modules |
| notation_table.md | Mathematical symbols and their meanings |
| references.md | Citation format and reading recommendations |
| cross_course_map.md | Conceptual connections between parallel modules |
| learning_pathways.md | Recommended sequencing of courses |
| faq.md | Common student questions and misconceptions |

## Quality Checks

Before any resource file is modified:

- Verify that changes are reflected in all four courses that reference the term/symbol
- Ensure no contradictions between the glossary definition and in-module definitions
- Check that new references are accessible to undergraduates (not behind paywalls where possible)
- Confirm that learning pathways still work after structural changes
