# Shared Resources: Active Inference 101: College First Semester

> **Quick Navigation**: [Curriculum Home](../README.md)

## Overview

This directory contains centralized reference materials shared across all four courses in the Active Inference 101 curriculum. These resources provide a single source of truth for terminology, notation, citations, and curriculum structure, ensuring consistency whether students approach Active Inference from cognitive science, computational neuroscience, mathematical, or implementation perspectives.

## Contents

| File | Description | Primary Use |
| --- | --- | --- |

| [notation_table.md](./notation_table.md) | Mathematical symbols, plain-language equivalents, and formal definitions | Decode equations and formulas |
| [references.md](./references.md) | Comprehensive reading list organized by topic and difficulty | Find primary sources and further reading |
| [cross_course_map.md](./cross_course_map.md) | Shows how modules connect across the four courses | Understand parallel topics |

## How to Use These Resources

**While studying a module**: Keep the glossary and notation table open as quick references. If a module introduces a term in bold, its definition appears in the glossary.

**When planning your studies**: Consult the learning pathways to choose between sequential, parallel, or interest-driven approaches to the four courses.

**When making connections**: Use the cross-course map to see how the same Active Inference concept (e.g., precision weighting) is treated differently in cognitive science vs. computational neuroscience vs. mathematical frameworks vs. implementation.

**When going deeper**: The references file organizes readings by topic and indicates which are most accessible for undergraduates vs. which require more mathematical background.

## Key Principles

- **Consistency**: Every term defined in the glossary should be used identically across all four courses
- **Accessibility**: All resources should be understandable to first-semester undergraduates regardless of which course they are taking
- **Bridging**: Resources explicitly connect informal descriptions (Course 1) with neural mechanisms (Course 2), mathematical formalism (Course 3), and code implementations (Course 4)
